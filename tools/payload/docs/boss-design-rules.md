# 보스 설계 규칙

모든 보스(기존 포함)에 적용합니다. 규칙 번호는 테스트와 PR 리뷰에서 그대로 인용합니다.

## A. 연출

- **A1** 보스 연출(등장·전환·변신·종결)에는 건너뛰기 버튼과 Esc 건너뛰기를 두지 않는다. 정리용 내부 `dispose`/`skip()` 호출은 플레이어가 쓰지 못하므로 허용한다.
- **A2** 일시정지와 소리 끄기는 유지한다.

## B. 패턴 동작

- **B1** 모든 패턴은 준비동작, 시전동작, 복귀동작을 갖는다.
- **B2** 각 동작은 보간으로 이어진다. 포즈가 뚝뚝 끊기면 안 된다.
- **B3** 플레이어가 현재 단계(준비/시작/진행/완료/복귀)를 알아볼 수 있게 표시한다. 배서준은 `src/blood-stage.mjs`가 기준 구현이다.

## C. 가시성

- **C1** 공격 범위는 실제 판정과 같은 모양의 예고로 미리 보여준다.
- **C2** 위험 표시는 색만으로 구분하지 않고 윤곽선이나 모양으로도 구분한다.
- **C3** 연출은 판정보다 먼저 켜지지 않고, 판정이 끝난 뒤에만 판정 영역 밖으로 퍼질 수 있다.

## D. 제작 품질

- **D1** 맵, 모델, 이펙트를 구·원기둑·토러스 같은 기본 도형(`SphereGeometry`, `CylinderGeometry` 등)을 그대로 조합해 만들지 않는다.
- **D2** 하나하나 직접 설계한 고품질 폴리곤을 조합한다.
- **D3** 보스·맵마다 폴리곤 예산을 정하고 문서에 기록한다.
- 상태: D1~D3은 기존 보스에도 소급 적용한다. 현재 코드는 대부분 위반이므로 위반 목록(baseline) 테스트로 새 위반을 막고, 보스별 교체를 진행하며 목록을 줄여 간다. 교체 순서는 배서준, 나머지 보스, 맵·이펙트이다.

## E. 지원하지 않는 것

- **E1** 저사양 모드와 움직임 줄이기 모드는 의도적으로 지원하지 않는다. 설정 화면에서 선택할 수 없고, 저장된 값이나 운영체제의 동작 줄이기 설정도 읽지 않는다. 이 때문에 동작 줄이기를 쓰는 사용자에게도 흔들림과 깜빡임 연출이 그대로 나간다는 점을 알고 정한 방침이다.
- 터치 기기용 해상도·입자 등급(`coarse`)은 사용자 설정이 아니라 기기 특성이므로 유지한다.
- 남아 있는 정리 작업: 죽은 `reduced` 인자·분기와 `INTRO_DURATION_REDUCED` 같은 데이터 상수를 파일별로 삭제한다.
