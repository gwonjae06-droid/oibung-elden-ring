# 배서준 공격 동작 — 준비·타격·반동·복귀 정교화

## 목표와 범위
기존 혈익 모델·14개 기술은 유지하면서 공격이 캐릭터 전체에서 이어지게 하는 순수 시각 모션을 개선한다.

- **준비 / Anticipation:** 상체가 반대로 힘을 싣고, 양손은 고유한 자세로 들어 올리며 손가락을 굽힌다.
- **발동 / Release:** 실제 `blood.hazards[].warn` 시각을 기준으로 체중을 실어 공격한다. 타격 범위·피해량·실제 경고 시간은 변경하지 않는다.
- **반동 / Follow-through:** 어깨 → 팔꿈치 → 손목, 혈익의 첫 관절 → 손목 → 피막, 몸통 → 망토로 지연된 움직임이 이어진다.
- **복귀 / Recovery:** 공격 종료 직전에 시각 포즈를 정리하고, 복귀 중에도 이전 자세에서 점진적으로 돌아온다.
- **다단 공격:** 같은 기술의 두 번째·세 번째 공격도 각자의 실제 위험 발동 타이밍을 사용한다. 전투 엔진에서 이전 hazard 객체가 소멸한 이후에도 시작 시 보관한 타이밍을 사용해 동작이 리셋되지 않는다.
- **일시정지:** 별도의 실시간 타이머를 두지 않는다. 전투 시간이 멈추면 모션도 멈춘다.
- **모바일/저모션:** 기존 메시 분할 수준 및 모션 감소 설정 유지, 프레임마다 메시를 새로 만들지 않음.

## 수정 파일
`src/blood-attack-motion.mjs`: 이벤트별 타임라인과 일관된 자세 보간을 담당하는 render-only director.
`src/blood-wings.mjs`: 타격 순간 접힘·관절 반동과 뒤늦은 피막 떨림.
`src/blood-regalia.mjs`: 손가락 관절, 몸통 축·망토 후속 동작.
`src/blood-view.mjs`: 상태 지속성을 갖는 director 생성·초기화.
`spider-combat.html`: 브라우저 버전 캐시 갱신.
`tests/blood-motion-followthrough.test.mjs`: 14개 공격 타이밍, 다단 히트 프루닝, 상태 연결, 일시정지, 메시 수 검사.

## 변경하지 않은 항목
`src/blood-combat.mjs`, `src/blood-data.mjs`의 전투 판정, 난이도, 피해량, 회피 및 보스 체력은 수정하지 않는다.

## 수동 확인 체크
혈익 강하와 혈익 추격의 날개 접힘, 붉은 날개 베기의 비대칭 몸통/날개 베기, 피의 분수·혈우·혈조의 연속 동작, 2페이즈 전환 직후 복귀 포즈, 모바일 발열 및 FPS를 실제 WebGL 브라우저에서 확인한다.
