# 최규원 — 패턴별 위험 이펙트 스타일 프로파일

2026-11-08. 지금까지 모든 패턴의 위험 이펙트는 같은 파편 메시에 색만 다르게 입혔다. 이번에 패턴마다 서로 다른 움직임 언어를 갖도록 `src/gyuwon-hazard-vfx.mjs`를 재설계했다. 시각 전용이며 피해 판정, 타이밍, 히트박스, 드로콜 수, `stats()` 키는 바꾸지 않았다.

## 스타일 필드

- `h`: 파편 높이 배율. 스톱(stop)·심판(verdict)처럼 높이 솟는 것부터 백지(blank)처럼 낮은 것까지.
- `jitter`: 충전 중에만 위치가 떨리는 정도(최대 0.08). 타격 순간에는 0이 되어 파편이 실제 판정 영역에 정확히 놓인다.
- `spin`: 원·링 형태의 회전 속도(rad/s). 직선·부채꼴은 판정 방향(yaw)이 있어 회전시키지 않는다.
- `pulse`: 충전 중 빛이 맥동하는 빠르기.
- `snap`: 타격 순간 솟아오르는 세기와 번쩍임.

## 패턴별 의도

| 단계 | 패턴 | 표현 의도 |
|---|---|---|
| 1 | 명제의 선 | 정확한 직선, 높고 깔끔한 절단 |
| 1 | 오답 노트 | 낙서처럼 떨리며 빠르게 맥동 |
| 1 | 다시 풀어 | 약한 떨림과 빠른 맥동(반복되는 메아리) |
| 1 | 객관식의 함정 | 느린 맥동의 부채꼴 |
| 1 | 모순의 형상 | 큰 떨림(둘로 갈라진 느낌) |
| 1 | 시간표 | 높고 규칙적인 느린 맥동 |
| 1 | 백지 | 낮고 천천히 회전하며 타격이 가장 강한 번쩍임 |
| 2 | 존재의 부정 | 떨리며 빠르게 맥동 |
| 2 | 인과 역전 | 반대로 회전하는 링 |
| 2 | 사유의 중단 | 가장 높고 거의 정지한 느린 맥동 |
| 2 | 영원의 판결 | 높이 솟고 타격이 무겁다 |
| 2 | 대칭의 형벌 | 미세한 떨림과 중간 맥동 |
| 2 | 공리의 붕괴 | 정방향으로 회전하는 링 |
| 2 | 참과 거짓의 역습 | 반대 회전과 떨림을 함께 |
| 2 | 기억의 소거 | 낮고 빠르게 맥동하며 강한 번쩍임 |
| 2 | 반례의 그림자 | 높게, 가장 빠르게 회전하는 링 |
| 3 | 천지절단 | 가장 높고(2배) 타격이 가장 강하다 |
| 3 | 마지막 대공연 | 큰 떨림과 빠른 맥동 |
| 3 | 천상의 도박장 | 회전하는 원과 중간 맥동 |
| 3 | 세계라는 칠판 | 약한 떨림 |

`tsunami`의 물 메시는 기존 기억 무대가 그리고, 통로 단서는 이전 작업(`gyuwon-corridor-cue.md`) 그대로다. 백색 공간의 기록 연출(`preview`)과 암흑 공간의 실현 연출(`inkFinger`)은 유지하며, 두 모드에도 높이 배율만 약하게 반영했다. 타격 순간 기본 모드의 색은 흰색 쪽으로 35% 밝아진다.

## 한계와 확인할 것

- 모두 같은 파편 지오메트리를 쓰므로 "모양" 자체를 바꾼 것은 아니다. 높이·떨림·회전·맥동·충격으로 구분했다. 패턴마다 서로 다른 모양(종이 조각, 유리, 분필 가루 등)이나 별도 입자를 쓰는 전면 재설계는 하지 않았다.
- 자동 테스트와 브라우저 렌더링은 실행하지 못했다. 위험 시각 효과가 `scale.y`나 위치를 엄격히 검사하는 테스트가 있다면 실패할 수 있다.
- 수치(`STYLE` 표)는 감으로 정한 값이다. 실제 플레이에서 어떤 패턴이 구분되지 않거나 과한지 보고 조정해야 한다.
- 떨림이 가독성을 해치지 않는지(특히 모바일), 회전하는 링이 실제 판정 범위와 다르게 읽히지 않는지 확인이 필요하다.
