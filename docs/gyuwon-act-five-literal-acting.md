# 5수: 원곡의 말이 직접 보이는 연기

추상적인 대형 장식 대신 최규원 자신의 몸과 손으로 기존 32개 가사 구간을 표현한다. 음악·대사 시간표, 원곡 전체 재생, 사진 구 얼굴, 낙서 재질, 파티·부위 선택·전투 기능은 유지한다.

| 원곡 구간 | 직접 보여 주는 동작과 소품 |
| --- | --- |
| 인사·환영 | 관객을 향한 인사와 팔 벌리기 |
| 어디서 시작할까 | 생각하며 손을 턱 근처에 대기 |
| 문·길 | 양손으로 여는 동작, 문 하나와 바닥 길 |
| 하늘·바다·꿈 | 하늘을 향해 팔 벌리기, 수평으로 물결짓는 손, 관자놀이 근처의 손 |
| 왕·기사 | 머리 위에 왕관을 얹는 동작, 손에 든 실제 검 |
| 눈물·슬픔 | 뺨의 눈물을 닦아 내고 고개 젓기 |
| 막을 올려라·트럼펫 | 두 팔로 막 끌어 올리기, 입 근처로 가져가는 실제 트럼펫 |
| 춤·달리기 | 상체의 춤과 번갈아 움직이는 팔 |

| 67.64–70.04초: 날갯짓 | 등 관절에 붙은 깃털 날개 한 쌍을 펼치고 양팔과 함께 날갯짓 |
| 70.16–73.36초: 내 손을 잡아 | 오른팔을 관객 쪽으로 뻗고 열린 손바닥 내밀기 |

| 반주·마무리 | 소품 순환 없이 조용한 지휘 동작과 인사 |

## 고정되던 팔의 원인과 수정

이전에는 아군의 행동 또는 어느 부위의 공격이든 진행 중이면 양손의 가사 동작을 모두 중단했다. 손의 기본 위치도 무대 바닥 근처여서 손을 조금 올려도 가슴을 감싸는 자세가 되지 않았다. 부위가 파괴되면 손을 무대 뒤로 빼 연기에서 제외했다.

손목 위치를 가슴·어깨 기준으로 다시 작성하고, 몸통·허리의 회전을 거쳐 실제 세계 좌표로 바꾼다. 부위의 실제 충돌 위치도 같은 좌표를 사용한다. 팔꿈치는 두 뼈의 길이와 굽힘 방향으로 계산한다. 직접 접촉 공격을 하는 손 하나만 그 공격 경로를 따르고, 반대 손은 계속 노래를 연기한다. 아군이 공격하거나 조명 부위가 공격하거나 손 부위의 HP가 0이 되어도 몸의 손·팔은 계속 움직인다.

날개 → 손 내밀기 → 껴안기의 연결 구간과 직전에는 새 보스 공격을 시작하지 않는다. 이미 시작한 공격은 원래 접촉·회복 과정을 끝낸다. 움직이는 부위를 향한 아군 투사체와 도약은 실제 손 위치를 따라가고, 눈에 보이는 접촉 뒤에 피해를 준다. 전투가 끝난 마지막 반주에서도 양손의 연기를 계속한다.

## 덜어 낸 효과

별무리, 궤도 고리, 커다란 심장 파동, 빛기둥, 팡파르 고리, 종이 폭죽, 가짜 댄서, 빙빙 도는 이야기 페이지와 나침반을 제거했다. 앙코르 부위의 여러 고리·광선도 제거하고 실제 공격 대상 물체 하나를 남겼다. 공격 적중 효과는 짧고 작은 크기로 제한했다. 실제 공격의 투사체와 준비 동작, 방어 응답 표시는 유지한다.

가사 자막은 최규원의 가슴과 손을 덮지 않도록 5수에서만 무대 위쪽으로 옮긴다. 필수 버튼과 기존 입력은 바꾸지 않는다.

## 확인

- 동작과 실제 충돌이 같은 위치를 쓰는지, 움직이는 손을 파티 네 명이 모두 맞힐 수 있는지, 파괴된 부위가 복구되지 않는지, 반주와 마지막 장면에서 팔이 멈추지 않는지 검사했다.
- Edge 1280×800 및 터치 설정 844×390에서 날개·손 내밀기·껴안기, 일시정지, 실제 공격 적중, 원곡 종료 뒤 6수 진입을 확인했다. 긴 곡의 위치 이동을 사용했다. 실제 휴대전화는 확인하지 않았다.
- 같은 원곡 구간에서 이전 버전과 화면의 실제 3D 그리기 수를 비교했다. 각 버전 기본 카메라, 렌더 1280×720 기준: 날갯짓 약 528→517회, 손 내밀기 약 503→357회, 껴안기 약 519→435회. 날개 깃털 30개는 묶어서 총 8회 그리기로 처리한다. CPU/GPU 시간과 실제 휴대전화 FPS는 측정하지 않았다.
- 전체 Node 검사에서 작업 전의 30개 실패와 비교해 신규 실패가 없음을 확인했다.
