# 배서준 피 이펙트: 5단계 연출

피 패턴마다 아래 다섯 단계가 순서대로 보입니다. 화면 상단의 단계 표시줄과 보스의 팔 동작, 바닥의 피 표현이 같은 단계를 따릅니다.

| 단계 | 시점 | 화면에서 보이는 것 |
| --- | --- | --- |
| 준비 | 경고 예고선이 차오르는 동안 | 바닥에서 피방울이 솟고 안쪽으로 모이는 파문이 생기며, 보스가 팔을 천천히 듭니다. |
| 시작 | 판정이 처음 켜진 직후 약 0.3초 | 피가 한꺼번에 터지고 바깥으로 퍼지는 파문이 둘 생기며, 보스 팔이 빠르게 뻗습니다. |
| 진행 | 판정이 유지되는 동안 | 피 덩어리가 젤리처럼 일렁이고 0.6초마다 파문과 방울이 이어집니다. |
| 완료 | 판정이 끝나는 마지막 구간 | 피 형태가 가라앉으며 바닥에 얼룩이 남고, 얼룩은 천천히 더 넓게 번집니다. |
| 복귀 | 보스 빈틈 구간 | 바닥의 얼룩이 보스 쪽으로 미끄러지며 줄어들어 흡수되고, 팔이 천천히 내려옵니다. |

## 느리게 번지는 피

- 방울은 느린 시간(약 0.62배)으로 움직이고 중력이 약해 천천히 떨어집니다.
- 얼룩은 약 6초 동안 남고 지수 곡선으로 서서히 넓어지며 가장자리가 출렁입니다.
- 파문은 가산 혼합 고리로 그려지고 바깥으로(준비 단계는 안쪽으로) 번집니다.

## 변하지 않는 것

판정 범위, 피해량, 경고 시간, 보스 행동 시간은 그대로입니다. 단계 계산(`src/blood-stage.mjs`)은 전투 상태를 읽기만 하며, 테스트가 이를 확인합니다. 붉은 경고 영역이 실제 판정 범위이므로, 번짐 연출은 판정이 끝난 뒤에만 경고 영역 밖으로 퍼질 수 있습니다.

움직임 줄이기·저사양 모드는 지원하지 않습니다(docs/boss-design-rules.md).
