# 배서준 — 성혈 대성당

2026-11-04 구현. 네 번째 보스로 이권재 → 오슬우 → 박성원 → 배서준을 연결한다. 최규원과 엔딩은 아직 추가하지 않았다.

## 전투

- 1페이즈: 피의 파도, 피의 분수, 피폭발, 피의 구체, 피의 사슬, 혈류 회전, 피의 소용돌이.
- 2페이즈: 혈익 강하, 피의 일식, 혈우, 붉은 날개 베기, 심장 파동, 혈익 추격, 종말의 혈조.
- 50% 이하에서 현재 패턴을 마친 뒤 한 번만 변신한다. 전환 중 공격과 피해를 멈추고 체력을 회복하지 않는다. 변신은 건너뛸 수 있다.
- 피의 사슬은 잠깐 보행 속도만 줄인다. 회피 속도와 무적은 유지하고 후속 분수까지 1.25초를 둔다.
- 공중 공격 뒤 2.4~3초 착지한다. 지상에서 보스가 접근해 근접 공격 기회를 만들며, 2페이즈 회복 중 붉은 구체의 피해 배율은 1.6이다. 공중에서는 원거리 피해가 0.65배다.
- 공격 예고, 원·고리·직사각형·부채꼴 판정과 화면 메시가 같은 데이터를 사용한다. 공격 목표는 예고 시 고정한다.

## 화면과 수명주기

원형 바닥, 외곽 수로, 기둥과 아치, 스테인드글라스, 촛불, 매달린 심장, 혈익과 붉은 머리 구체를 절차적 메시로 구성했다. 피의 분수·구체·파도를 입체 메시로 표현하고 처치하면 날개와 조명이 사그라들며 피가 떨어진다. 카메라를 가리는 배경 장식은 숨긴다.

공통 플레이어·무기·스킬·회피·기력·회복 코드를 사용한다. 키보드, 마우스, 터치, 차징, 록온, 일시정지, 포커스 상실 및 종료 처리를 연결했다. 공격 시간은 전투 시뮬레이션에만 의존한다. 종료 시 프레임, 이벤트, 음원, 메시, 재질, 렌더러와 대화상자를 정리한다.

## 여정과 저장

무기 진화는 이권재와 오슬우 뒤 두 번만 선택한다. 박성원 뒤에는 기억을 읽고 진화를 유지한 채 배서준으로 간다. 네 번째 토벌 뒤 완수 기록과 배서준 기억을 남기며 메인 혈액 문양을 밝힌다.

스키마 v3는 v1/v2 기록을 유지한다. 기존 3보스 기록에 `bossCount: 3`, 신규 4보스 기록에 `bossCount: 4`를 넣고 최고 기록 비교를 분리한다. 옛 완수 기록으로 배서준 토벌을 추정하지 않는다. 기존 규칙대로 진행 중인 도전은 저장하지 않는다.

## 구현의 범위

전투 가능한 프로토타입이다. 셰이더·곡면·방울을 결합한 유체 근사, 입체 혈익, 4.6초 변신 카메라와 실제 업로드된 BGM·독창·종을 연결했다. 자세한 구현과 검증은 [시네마틱 고도화 기록](blood-cinematic-quality.md)을 참고한다. 실제 유체 시뮬레이션, 고해상도 인체 모델, 유리 파편·성당 붕괴와 독립적인 머리 조준 판정은 포함하지 않는다. 구체 약점은 기존 보스 중심 판정과 착지 배율로 유지한다.

검증은 로직과 Three.js 메시 수명주기, 실제 Edge의 진입·변신·일시정지·승리·재도전·종료 및 작은 가로 화면을 포함한다. 네 무기의 실제 피해 처리는 검사했으며, 모든 무기와 진화 조합으로 자연 플레이 완수하거나 실기기 30~60FPS를 보장한 것은 아니다.

브라우저 검사: 기존 Playwright 설치 경로를 `PLAYWRIGHT_PATH`, 필요하면 Edge 실행 경로를 `EDGE_PATH`로 지정한 뒤 `node scripts/blood-browser-smoke.cjs`를 실행한다. 로컬 `node_modules/three`에는 0.180.0의 브라우저 모듈이 필요하다. 스크립트는 로컬 서버만 열고 저장소 원격 상태를 변경하지 않는다.
