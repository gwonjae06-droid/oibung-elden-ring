# 최규원 기본 전투

최신 갱신: 3페이즈·백색/암흑 공간·다섯 황금 기억·승천 구현 범위는 [gyuwon-three-phases.md](gyuwon-three-phases.md)를 따른다. 아래 설명은 초기 기반 제작 당시 기록이다.


2026-11-06. 다섯 번째 보스의 플레이 가능한 기반이다. 기존 `odenring-clarity` 작업본의 전투·정화의 불꽃·영구 강화 규칙을 유지한다.

- 배서준 토벌 뒤 최규원으로 진행한다. 다섯 번째 승리에서만 새 완수 기록을 만들며 이전 3/4보스 기록은 유지한다.
- 숨겨진 이동 메뉴에서도 최규원을 선택할 수 있다. 기존과 같이 이동 전투는 완수/기억 기록과 구분하고 불꽃만 지급한다.
- 벽과 천장이 없는 심야 공간에 연속된 바닥과 책상·문제집이 사방으로 반복된다. 원경은 안개와 수평선에 녹아들고 머리 위에는 별빛이 펼쳐진다. 원형 이동 경계 안에는 가구를 두지 않는다. 반복 가구는 인스턴싱하여 그린다.
- 명제의 선: 세 직선 구역에 분필색 예고 후 참격.
- 오답 노트: 시전 순간의 플레이어 주변 세 위치에 순차 공격.
- 다시 풀어: 직전 패턴의 위치를 기억해 두 번 공격. 두 번째 단계에서는 두 공격 사이 간격이 줄어든다.
- 체력 절반 이하에서 현재 공격을 마친 뒤 3초 전환. 머리가 지워지고 별빛이 선명해지며 빈 원형 문양이 나타난다. 전환 중 플레이어 행동과 피해를 막는다.
- 공유 네 무기, 충전 공격, 스킬, 회피, 회복, 일시정지, 모바일 조작과 종료 정리를 사용한다. 전용 BGM은 아직 없다.

무두의 도서관 변형, 이전 네 보스의 기억 공격, 최종 증명, 정교한 얼굴·등장 애니메이션, 두 가지 선택 엔딩은 후속 범위다. 현재 결말은 간단한 기억과 완수 화면이다.

검증: 집중 검사 29개 통과. 추가한 전투 검사는 네 무기 적중/두 단계 승리, 공격 위치 재현, 예고·회피·연속 피해, 사망 정리, 다섯 보스 진행과 공유 피해 라우팅을 확인한다. 전체 검사는 1,328개 중 1,289개 통과, 39개 실패. 수정 전 소스의 별도 비교 실행으로 이번 변경에 새로 생긴 실패가 없음을 확인했다. 기존 실패는 다른 보스와 무기 수치 및 예전 기대값에 걸쳐 있다. 전체 검사가 모두 통과한 상태는 아니다.

브라우저 확인: `PLAYWRIGHT_PATH=playwright-core node scripts/gyuwon-browser-smoke.cjs`. Edge의 소프트웨어 렌더링에서 전투 진입, 일시정지/재개, 단계 전환, 844×390 화면 배치, 승리 후 재도전과 종료를 검사한다. 실제 휴대폰 성능 및 정상 조작으로 다섯 보스 연속 클리어는 미검증이다.
