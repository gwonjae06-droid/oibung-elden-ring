# 4수의 끝에서 상상 속 5수로 — 2026-11-09

정규 최규원전의 4수 종료와 5수 음악 사이에 58초의 인게임 3D 컷씬을 삽입한다. 사수까지 했지만 답을 찾지 못한 최규원이 알바와 학교를 반복하다가 자기 방에서 원하는 일을 묻고, 머리 위에 생긴 상상구름 속으로 들어가며 거대 최규원의 뮤지컬이 시작된다.

| 시간 | 장면과 카메라 |
| --- | --- |
| 0–9초 | 방금 싸운 사수의 실제 전장에서 최규원의 지친 얼굴로 천천히 접근. ‘사수까지 했는데…’라는 속말 자막. |
| 9–17초 | 앞치마를 입은 편의점 알바. 계산대와 상품을 스캔하는 손, 가격 표시와 계산 소리. |
| 17–25초 | 학교 교실로 걸어 들어와 책상에 앉는 최규원. 수식이 적힌 칠판과 노트. |
| 25–31초 | 밤의 편의점으로 짧게 되돌아가는 반복된 일상. |
| 31–39초 | 침대·책더미·책상등·달력이 있는 자기 방. 구부정한 자세로 노트 앞에 앉아 있다. |
| 39–44초 | 카메라가 얼굴로 접근하며 고개를 든다. ‘내가 진짜 하고 싶은 일은 뭘까?’ |
| 44–50초 | 머리 위의 작은 생각 방울에서 입체적인 상상구름이 자란다. 카메라는 인물에서 구름 쪽으로 올라간다. |
| 50–58초 | 카메라가 구름의 내부로 직접 들어간다. 방이 옅어지고 따뜻한 백색으로 화면을 채운다. |
| 이후 | 구름의 빛이 걷히며 최신 main의 손그림 5수 거대 레이드 무대가 나타나고 원곡 Welcome to My World!이 0초부터 시작된다. |

## 진행과 음악

- 정규 4수의 HP 경계에 도달한 뒤 현재 공격을 마치는 기존 흐름에서 한 번만 시작한다. 1–3수의 시험, 5–12수의 곡과 기존 레이드 규칙을 바꾸지 않는다.
- 컷씬 전체 동안 연차는 4수, 전체 보스 HP는 6,000이다. 이동·공격·치유·차지·카메라 조작과 잔여 공격체를 멈춘다. HUD는 숨기고 일시정지만 남긴다.
- 사용자용 건너뛰기 기능은 없다. 일시정지와 창 비활성화는 컷씬의 진행과 효과음을 함께 정지한다. 멈춘 동안의 시간이 나중에 한꺼번에 반영되지 않는다.
- 재생 길이는 활성 상태의 실제 시간 기준이다. 렌더링이 느리다고 물리 시뮬레이션의 제한된 시간 간격에 묶여 수 분으로 늘어나지 않는다.
- 컷씬이 끝나기 전에는 5수 음악 상태를 만들지 않는다. 원본 MP3를 편집하거나 배속하거나 중간으로 탐색하지 않는다. 구름에서 무대로 넘어가는 마지막 백색 잔상은 1.4초 동안 사라진다.
- 대사는 화면의 속말 자막이다. 신규 음성 녹음을 생성한 것은 아니며 기존 소품 효과음을 조용히 사용한다.

최신 main의 5수 전용 손그림 효과를 보존한다. 현실을 보여주는 4수 컷씬에는 적용하지 않으며, 상상구름 통과가 끝난 실제 5수부터 적용한다. 두 효과의 사전 준비와 종료 시 자원 정리를 함께 유지한다.

## 제작과 자원

최규원의 기존 얼굴 사진·메시와 어깨→팔꿈치→손목 계층을 복제하여 일상 인물로 사용한다. 사수 무기, 연차 장비, 후반 신격화 장식은 제거한다. 얼굴과 인체의 원본 기하 데이터는 공유하고 의복 재질만 별도로 보유한다. 앉은 다리는 엉덩이·무릎·발목 사이를 실제 메시로 연결한다.

편의점·학교·방은 서로 다른 3D 세트다. 구름은 40³ 밀도 텍스처를 사용하는 체적 셰이더이며, 카메라 밖의 흰 평면을 확대하는 방식이 아니다. 밀도 텍스처와 세트의 GPU 자원은 로딩 단계에서 준비한다. 데스크톱 20단계 / 작은 기기 품질 12단계의 제한된 레이 진행을 사용하고, 닫을 때 복제 재질·텍스처·효과음·셰이더를 정리한다.

## 검증

- 관련 자동 검사 85개 통과. 실제 4→5 경계, 58초 이전의 조기 진입 금지, HP·입력 동결, 외부 시계의 정지, 직접 5수 개발 장면 및 기존 연차 모드, 일상 인물의 무기 제거를 검사했다.
- 최신 main의 손그림 변경을 합친 전체 2,186개 중 2,156개 통과, 30개 실패. 직전 커밋의 2,176개 중 2,146개 통과 결과와 실패 이름을 대조했으며 같은 30개다. 이번 변경으로 추가된 실패는 없다.
- 브라우저에서 58초 전체를 자연 재생하고 아홉 시점의 실제 장면, 일시정지·재개, 입력 차단, HUD 숨김, 원곡이 0초에서 출발하는 연결을 확인한다. 844×390 화면의 질문 자막과 구름 내부도 별도로 확인한다. 장면 시각 조정용 내부 검사와 정규 자연 재생 검사는 구분한다.
- 관측 성능: 1280×800 Edge 브라우저의 아홉 표본에서 15~174 draw call, 3,094~132,766개 삼각형이었다. 알바·학교·방 장면은 약 6.2만~6.9만 삼각형, 구름 진입 이후는 약 0.3만~0.7만 삼각형이었다. 최근 프레임 간격의 중앙값은 약 5.6ms였으나 이는 자동 검사 환경의 관측값이며 실제 기기의 FPS 보장이 아니다. CPU/GPU 시간의 별도 프로파일은 미측정이다.
- 실제 휴대전화의 발열·프레임과 오디오 출력 지연, 기기별 GPU 성능은 미측정이다. 현재 캐릭터의 기존 형상과 사진 매핑을 재사용한 결과이며 새로운 실사 인물 촬영이나 완전한 포토리얼 모델을 만든 것으로 표현하지 않는다.
