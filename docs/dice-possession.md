# 박성원 2페이즈 — 운명의 찬탈자

사용자 통합 기획안 2단계를 기존 박성원 전투에 연결했습니다. 기존 MP3 경로와 1페이즈의 격자·주사위 압사·사진 면 판정은 유지합니다.

## 전환과 공략

- 실제 플레이 전투(createDicePlayerGame)는 체력 50% 이하에서 한 번만 육체 강탈로 전환합니다. 남은 체력을 회복하지 않습니다.
- 진행 중인 구르기·바닥 공격·투사체를 취소하고, 5초간 피해·공격·이동을 멈춥니다. 주사위가 손님에게 날아가고 기존 머리가 튕겨 나간 뒤, 빼앗은 상반신이 일어섭니다. 연출은 건너뛸 수 있습니다.
- 양손의 경직 게이지는 각각 190입니다. 손에 준 기본 피해량만큼 게이지가 줄고 실제 보스 체력에는 30%를 줍니다.
- 한 손이 경직되면 진행 공격이 취소되고 머리가 내려옵니다. 11초 동안 사진 면에 2.8배 피해를 줄 수 있습니다. 다른 면은 기존처럼 막힙니다.
- 머리가 들리면 손 게이지가 복구되고 3초 회복 구간 뒤 다음 패턴을 시작합니다. 머리·손의 위치와 공격 교차 판정은 같은 상태 데이터를 사용합니다.

## 패턴

| 패턴 | 예고와 대응 |
|---|---|
| 거인의 손가락 | 위치를 미리 고정한 다섯 경고 원이 순서대로 찍힙니다. |
| 판돈 쓸어 담기 | 연속된 띠 모양 예고를 보고 휩쓸기 경로에서 벗어납니다. |
| 카지노 칩 폭격 | 원형 예고 위로 칩이 떨어집니다. |
| 주먹 강타 | 큰 원의 착지와 확장되는 고리 충격파를 따로 피합니다. |
| 운명의 룰렛 | 붉은 세로 구역 사이에 안전한 통로가 남습니다. |
| 양손 압박 | 양손 사이 또는 앞뒤로 빠질 수 있는 공간이 남습니다. |
| 최후의 올인 | 손가락·칩·휩쓸기를 순서대로 연결하고 회복 구간을 제공합니다. |

1페이즈 압사와 달리 새 페이즈 공격은 일반 피해이며 회피 무적이 적용됩니다. 경고 도중 목표가 플레이어를 계속 따라다니지 않습니다. 패턴별 예고는 1.1~1.6초가 기본이며, 주먹 충격파는 착지 뒤 별도 예고를 둡니다.

## 연출·정리

거인용 카메라, 양손 게이지, 머리 반격 안내를 추가했습니다. 선택된 배경 손님은 거인으로 교체되고 다른 손님은 뒤로 물러납니다. 카지노 조명은 붉어지고 외곽 칩과 룰렛 숫자가 흔들립니다. 죽으면 공격이 즉시 사라지고, 상반신이 무너지며 주사위가 탁자에 떨어져 숫자 없는 윗면으로 멈춥니다. 사망 연출 뒤 기존 기억·기록 흐름으로 돌아갑니다.

일시정지·백그라운드에서는 전환과 사망 연출의 시간이 진행되지 않습니다. 재도전은 체력·페이즈·게이지를 초기화합니다. 거인의 예고 메시와 재사용하지 않은 기하·재질까지 종료 시 정리합니다.

## 검증 범위

네 무기의 실제 공격 경로로 손 경직과 내려온 사진 면 피해를 검증합니다. 패턴별 안전 위치, 예고 전 무피해, 회피 무적, 동결, 승리 후 정리, 사망 위치 연속성을 자동 검증합니다. 브라우저에서는 검증용 버튼으로 체력과 경직을 변경해 전환·카메라·약점·사망·재도전을 확인합니다. 자연 플레이로 네 무기를 모두 연속 클리어하거나 실기기 모바일 성능을 검증했다는 의미는 아닙니다.

저수준 주사위 물리 테스트용 createDiceGame의 구형 패턴 계약은 보존하고, 실제 플레이를 생성하는 createDicePlayerGame에서 새 거인 페이즈를 활성화합니다. 구형 phase2PendingDesign 표시는 실제 플레이에서는 사용하지 않습니다.

배포 화면 확인 후 거인 페이즈 시야각을 넓히고, 카메라와 플레이어 사이를 가리는 팔만 옅게 표시하도록 보완했습니다. 손과 바닥의 위험 예고·판정은 유지합니다.

## 2026-11-04 개편: 점잖은 지배자 → 광기 붕괴

### 육체 강탈 컷씬

기존 5초 컷씬을 7초로 연장했습니다. 0.6~3.6초에 주사위가 공중에서 3초간 가속 회전하고, 3.6~3.85초에 손님 머리로 발사됩니다. 3.85~4.5초에는 머리 찬탈, 이후 거인 기립과 관객 도주·카지노 조명 전환이 이어집니다. 컷씬 좌표와 회전은 `dice-giant-cinematic-data.mjs`의 시뮬레이션 시간 함수에서 산출됩니다. 컷씬 건너뛰기는 동일한 최종 상태로 이동합니다.

### 양손의 전투 위치

양손 기본 위치를 테이블 가장자리(대략 x=±64,z=22)로 옮겼습니다. 기본 자세에서는 중앙을 가리지 않고, 물리 공격을 할 때 경고 대상에 맞춰 뻗어 나와 회수됩니다. 공격 판정과 화면의 손 좌표는 모두 `giantHandPose`에서 읽습니다. 기존 양손 경직 190, 머리 약점 2.8배, 경직 11초 구조는 보존됩니다.

### 성격 변화와 공격

- 2-A 점잖은 지배자: 기존 공격 스케줄을 유지하면서 칩·다이스·코인·체스말 형상의 공용 메시를 위험 구역에 배치합니다.
- 2-B 광기 붕괴: 전체 보스 체력이 최대치의 27.5% 이하일 때 한 번만 전환합니다. 보스 체력을 회복하지 않고, 기존 페이즈 2를 유지합니다. 쓸기·난타·머리 박기·양손 압박 등 7종의 별도 공격 구성을 사용합니다.
- 카지노 손님은 변신 후 순차적으로 도주하며, 좌석은 남습니다. 네온·샹들리에 및 몸체 움직임은 상태에 따라 반응합니다.

### 범위와 검증

`tests/dice-giant-overhaul.test.mjs`에서 컷씬 길이, 모델 위치, 가장자리 손 판정, 광폭화 한 번만 발생, 머리 박기, 안전 구역 및 카지노 반응을 검증합니다. 기존 보스전과 음악 파일은 유지합니다. 자동 테스트는 Three.js 브라우저 렌더링의 실제 품질이나 GPU 성능을 보증하지 않으므로 별도 플레이 테스트가 필요합니다.

### 다음 품질 개선 후보

체스말별 고유 행마(룩·비숍·나이트)와 동전 앞·뒷면의 실제 공격 분기를 확장하고, 거인 손을 더 세밀한 관절 리깅 또는 glTF 모델로 교체할 수 있습니다. 현재 단계는 프로시저럴 3D 렌더링과 결정적 위험 구역을 우선합니다.
