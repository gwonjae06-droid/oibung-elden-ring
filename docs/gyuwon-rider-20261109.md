# 최규원 오토바이·킥보드 주행 개편

현역과 재수의 탈것이 잠깐 멈췄다가 짧게 직진하던 흐름을 바꾼다. 일반 공격과 두 전용 필살기 모두 반경 25의 외곽을 빠르게 한 바퀴 돌고, 감속하며 앞바퀴를 든 뒤 플레이어에게 돌진한다. 통과 후 곡선으로 외곽에 복귀해 다시 선회한다. 필살기는 오토바이 4회·킥보드 5회의 준비와 돌진을 반복한다.

- 오토바이 외곽 속도는 초당 48.75, 킥보드는 53.75 게임 거리 단위다. 회전 구간에 매번 정지하는 보간을 쓰지 않는다.
- 반경 25 이내의 일반 공격 경로 표본에서 최고 속도는 오토바이 약 26.8→75.3, 킥보드 약 18.7→75.1로 측정됐다. 이는 시뮬레이션의 이동 속도이며 FPS 측정이 아니다.
- 각 돌진 전 0.78초 동안 감속·조향·앞바퀴 들기를 보여준다. 그 준비가 시작될 때 실제 플레이어 위치를 겨냥하고 이후에는 추적하지 않는다. 옆으로 이동하면 피할 수 있다.
- 준비·회전·외곽 복귀에는 충돌 피해를 추가하지 않는다. 기존 피해량과 돌진 횟수는 유지한다. 돌진 피해는 렌더러와 같은 이동 궤적에서 발생한다.
- 탑승자와 탈것은 같은 뒷바퀴 축을 중심으로 기울며, 탑승한 보스의 피격 부위도 높이와 기울기를 반영한다. 바퀴 살은 실제 이동 거리에 따라 회전한다.
- 공격 종료 시각은 전체 경로를 포함한다. 기존의 짧은 일반 공격 타이머로 외곽 복귀가 끊기지 않는다. 하차 후 기존 반격 시간을 유지한다.

검증은 실제 피해·측면 회피, 준비 시점의 현재 목표 고정, 외곽 속도와 경로 연속성, 탑승 모델과 피격 부위 및 하차 복구를 포함한다. 관련 회귀 검사 155개가 통과했다. `scripts/gyuwon-rider-smoke.cjs`는 실제 PC·터치 전투에서 네 탈것 공격의 16개 장면, 자연 시간으로 진행되는 선회→돌진→복귀, 일시정지·종료를 검사하고 이미지와 진단 자료를 저장한다. 터치 검사는 브라우저 에뮬레이션이며 실물 휴대전화 검사는 아니다.
