# 최규원 공연 구성과 단체 커튼콜

기존 7수의 군대 게임과 10수의 슈팅 게임을 정규 진행에서 제외한다. 남은 원곡은 편집하거나 도중에 끊지 않는다. 수 표시는 연속으로 정리한다.

| 표시 | 공연 | 형식 | 원본 녹음 ID |
| --- | --- | --- | --- |
| 1–4수 | 기존 수능 전투와 상상 진입 컷씬 | 3D | 음악 없음 |
| 5수 | Welcome to My World! | 거대 최규원과 4인 파티, 3D | 5 |
| 6수 | Run Into Tomorrow! | 달리기, 2D | 6 |
| 7수 | Dance Until the Morning! | Backup Spotlight 기반 리듬, 2D | 8 |
| 8수 | Give Me One More Round! | 두 버튼 격투, 2D | 9 |
| 9수 | The Greatest Show of My Life | 보스 소개와 단체 춤, 3D | 11 |
| 10수 | When the Music Ends | 헌정과 마지막 장면 | ending |

원본 녹음 ID는 자막·동작·비트 자료의 식별자로 유지한다. 제거한 두 곡과 독립 개발 자료는 보관하지만 정규 진행과 다음 곡 미리 불러오기에는 포함하지 않는다. 남은 여섯 원곡은 합계 약 18분이며, 앞의 네 수 전투와 상상 진입 컷씬 시간은 별도다.

## 장면 연결

- 5→6: 거대 무대에서 실제 출구와 길을 열고, 같은 기사 캐릭터를 따라가며 달리기 화면으로 옮긴다.
- 6→7: 마지막 달리기 화면의 길과 색을 리듬 무대 첫 장면에 이어 붙인다.
- 7→8: 마지막 춤 화면을 유지한 채 격투 무대로 옮긴다.
- 8→9: 곡 끝의 붉은 손그림 커튼이 닫히고, 보스 소개 무대에서 다시 열린다.
- 9→10: 단체 공연을 커튼으로 마무리한 뒤 헌정 장면으로 연결한다. 이전 곡의 종료 상태가 새 곡을 가리지 않게 한다.

곡의 원래 종료 이벤트와 일시정지 상태가 전환을 제어한다. 실제 음악이 멈추면 전투·공연 시간도 멈춘다.

## 색 있는 낙서 표현

1–4수, 생활 회상, 상상 진입, 5수, 모든 2D 장르와 엔딩까지 최규원전 전체에 같은 색 있는 잉크 처리를 적용한다. 2D 장르는 기존 Canvas2D에서 그린 화면을 한 장의 텍스처로 처리한다. 3D 모델로 바꾸지 않는다. 모델 색과 어두운 옷의 명암을 유지하고, 사진 얼굴의 정체성을 보존한다. 기본 HUD·곡 진행도·터치 버튼·일시정지 기능을 유지하면서 종이와 불규칙한 선 표현을 공통 적용한다.

## 기존 11수의 새로운 커튼콜

새 표시는 9수다. 원곡 앞 55% 동안 이권재, 오슬우, 박성원, 배서준, 최규원이 순서대로 등장한다. 오슬우는 실제 두 페이즈를, 나머지 출연자는 세 장면을 보여준다. 이권재의 목·머리검과 사진 투영, 오슬우의 원래 광대/인형 조종자 모델, 박성원의 주사위/정장 몸체와 관절 손, 배서준의 원래 왕복과 3페이즈 세라핌, 최규원의 사진 구 얼굴과 거대 공연 모델을 재사용한다.

소개를 마친 보스들은 무대 양옆에 남는다. 최규원의 마지막 소개가 끝날 때 최종 대형으로 이동한다. 뒤에 보스 5명, 앞에 기사 플레이어 4명이 함께 카메라를 바라보며 춤춘다. 제자리 박자 밟기, 팔 벌리기, 팔 올리기, 발차기, 인사로 구성한 독자적인 16박 동작이며 해당 곡의 142 BPM 자료에 맞춘다. 공격 판정이나 새로운 조작 과제는 없다. 원작 애니메이션의 영상·음악·안무 자산은 복제하지 않는다.

출연자 소개 뒤에는 춤이 계속되는 동안 화면 옆으로 크레딧이 흐른다. 마지막 곡의 헌정 문구와 원곡 전체 재생은 유지한다.

## 검증과 범위

- 전체 Node 검사: 2,250개 중 2,220개 통과. 변경 전부터 있던 30개 실패와 비교해 신규 실패 없음. 최규원 관련 검사는 모두 통과.
- Edge 브라우저: 유지된 다섯 공연의 원래 음원 종료 이벤트, 곡별 HP 정산, 제거 음원의 미리 불러오기 제외, 보스별 장면, 9명 단체 춤, 일시정지, 844×390 가로 화면, 최종 승리와 1수 낙서 적용을 확인. 긴 곡의 진행 확인에는 오디오 위치 이동을 사용했다.
- 확인한 저사양 설정에서 2D 합성은 1회 그리기/삼각형 2개. 단체 춤의 실제 3D 장면은 약 840회 그리기/삼각형 12.6만 개이며 최종 잉크 합성은 별도 1회다. 화면 전체에 매 프레임 새 텍스처를 만들지 않는다.
- 실제 휴대전화 성능과 모든 무기의 자연 플레이 연속 클리어는 확인하지 않았다. 사진·모델 로딩과 GPU 셰이더는 시작 로딩 중 준비한다.
