# 최규원 실제 전장 회상·해일 카메라 수정

2026-11-07. 기존 황금 상징물 배경은 실제 맵 전환이 아니었으므로 교체했다.

- 이권재: `buildEnvironment`로 성소·석재 바닥·폐허·기사상 원본 생성.
- 오슬우: `buildCircus`로 실제 서커스 무대·천막·커튼·관객·조명 생성.
- 박성원: `buildDiceBoard`로 실제 카지노·룰렛 탁자·칩·거인 관객 생성. 공통 전투 구역에 맞춰 균일 배율 0.3 적용.
- 배서준: `createWhiteCathedral`로 실제 성당·스테인드글라스·제단·혈해 생성.
- 각 맵은 전투 시작 시 한 번 생성한 뒤 캐시한다. 3페이즈 `stageMemory` 변경에 따라 하나만 표시한다. 사망/재시작/종료 시 숨김 및 자원을 정리한다.
- 실제 모델과 텍스처를 유지하고 옅은 황금 기억색과 기존 입자를 함께 사용한다. 원본 맵의 하늘/달은 숨겨 최규원의 흰 배경을 유지한다. 구조물은 원본 형태이며 카메라와 캐릭터 사이를 가리는 구간은 기존 카메라 시야 절개 셰이더로 처리한다.
- 맵 생성기는 독립 장면에 실행해 원래의 배경색·안개·조명 초기화가 공용 전투 장면에 영향을 주지 않는다. 맵은 시각적 재현이며 기존 중앙 이동/공격 판정은 유지한다.
- 최규원의 배서준 기억 해일은 시작 후 수평선을 비추는 짧은 카메라 이동을 사용한다. 1.85초에 연출 가중치가 0이 되고, 해일이 실제 전투 구역에 도착하기 전 기본 카메라로 복귀한다. 시뮬레이션 시간에 따라 움직이고 스킵 조작과 설명 문구를 추가하지 않는다. 일반 배서준 보스전과 다른 최규원 패턴의 공격/피해 수치는 변경하지 않았다.
- 공개 메뉴의 `최규원 연습` 버튼과 해당 진입 처리를 제거했다. 보통 여정에서 다섯 번째 보스로 진행한다. 브라우저 QA는 내부 런처로 직접 진입하며 사용자 UI를 만들지 않는다.

검증: 관련 검사 36개 통과. 원본 루트 이름/독점 전환/4회 생성 고정/흰 배경/종료 정리, 해일 카메라의 방향·복귀·다른 공격 비개입, 연습 버튼 제거를 검사한다. Edge에서 네 원본 맵 렌더링, 수평선 카메라, 모바일 가로 배치, 승리와 재도전을 확인한다. 실기기 성능은 미측정이며 최적화 완료로 표현하지 않는다.

범위 밖 기존 과제: 최규원 HUD의 패턴 이름/대사 노출과 단순 학생 모델은 현행 AGENTS 제작 기준에 미달하며 후속 수정 대상으로 남는다. 이번에는 사용자가 유지하도록 한 다른 패턴과 모델을 변경하지 않았다.
