# 최규원 5~10수 참고 미니게임

사용자가 제공한 여섯 장의 참고 화면과 후속 선택을 반영했다. 5수는 기존 오든링 캐릭터를 쓰는 실제 3D 파티 전투, 6~10수는 Canvas2D 전용 화면이다. 캐릭터와 배경은 기존 모델 또는 새로 그리는 도형 아트이며 원작 게임의 스프라이트·모델·음원을 추출하지 않았다. 원작의 완성된 작화나 연출을 그대로 복제한 버전은 아니다.

| 수 | 참고 | 반영한 구조 |
| --- | --- | --- |
| 5 | 붕괴: 스타레일 | 네 명의 파티, 다섯 적, 속도와 행동 순서, 대상 선택, 공유 스킬 포인트, 일반 공격·전투 스킬·개별 필살기, 약점과 강인도, 실제 접근 후 타격 |
| 6 | 쿠키런 | 횡스크롤 꽃밭, 이단 점프, 누르는 동안 슬라이드, 발판 틈, 바닥·공중 장애물, 접촉 젤리·회복 아이템, 체력과 보너스 |
| 7 | 냥코 대전쟁 | 아군·적 기지, 자동 전진하는 여섯 유닛, 비용·생산 대기, 생산력 강화, 재충전식 대포, 사거리와 준비 모션을 가진 공격 |
| 8 | 댄서 / Backup Spotlight | 가수와 네 백업 댄서, 제자리 포즈·반복 턴·빠른 턴, 소리와 동작 신호, 박자 판정, 방향 전환, 실패 반응 |
| 9 | 스컬걸즈 | 2D 대전, 좌우 이동·점프·앉기·가드, 주먹·킥·스킬·초필살, 개별 체력·게이지, 사거리·높이·공격 준비와 접촉 판정, 연속 타격과 라운드 |

8수의 세 가지 신호와 상대적인 박자 간격은 [Backup Spotlight 동작 문서](https://rhmodding.github.io/GrooveDocs/commands/scenedancer.html)를 참고했다. 제자리 포즈는 신호 후 2.5박, 턴과 빠른 턴은 신호 후 2박을 기준으로 하며 기존 8수 곡의 BPM에 맞춰 안무를 배치했다. 원작 곡의 채보를 복제한 것은 아니다. J·L·Space와 화면 버튼을 사용한다.

## 음악과 진행

편집된 기존 음악, 실제 재생 시각, 자막, 일시정지·음소거·재생 실패 시의 시간 처리를 유지한다. 미니게임의 점수·기지·라운드·적 체력은 각 장르의 판정이고, 최규원의 전체 체력은 기존 곡 종료 규칙을 따른다. 11수 뮤지컬과 800 HP 엔딩, 석판과 복도 후일담도 유지한다.

## 확인한 범위

- `tests/gyuwon-reference-games.test.mjs`: 접촉 시점, 점수, 자원, 실제 틈과 장애물, 생산 대기, 박자, 공격 거리, 폭탄, 드래그 등 17개 검사.
- 장르·음악 시계·초반 진행·여정 검사를 합쳐 48개 통과.
- `scripts/gyuwon-reference-qa.mjs`: 브라우저의 실제 버튼과 키, 생산 카드 여섯 개, 대포, 춤 입력, 격투 접촉과 필살기, 슈팅 드래그와 폭탄, 각 장르의 정지·재개, 11수 3D 복귀, 844×390 터치 점프 검사. 고비용 카드와 필살기는 자원을 공급한 검사 장면도 사용한다.
- `scripts/gyuwon-musical-qa.mjs`: 실제 음악 종료 일곱 번, 정확한 전체 체력, 정지·음소거, 엔딩과 복도, 작은 화면 자막 검사.
- 전체 검사 2,149개 중 2,121개 통과, 기존 실패 28개를 이전 실행과 비교했다. 해당 실패는 다른 보스·무기와 과거 계약 검사에 있으며 이번 변경으로 추가된 실패는 없다.

## 성능과 남은 검증

Windows Edge의 자동 브라우저 검사에서 2D 다섯 장르는 WebGL 렌더를 호출하지 않는다. 검사 장면의 Canvas 그리기 비용은 약 0.2~1.1ms, WebGL draw call·삼각형은 0이었다. 5수는 실제 3D로 검사 장면에서 716 draw call, 약 10만 삼각형이었다. 소프트웨어 렌더러와 자동 품질 조절을 사용하는 검사 결과이며 실제 기기의 FPS를 뜻하지 않는다. 기본 음악 경로에서는 사용하지 않는 옛 5~11수 세계의 선행 생성을 생략하고, 옛 연차 경로는 기존 전체 준비 과정을 유지한다.

데스크톱 화면은 여섯 장르 모두 확인했다. 터치는 브라우저 에뮬레이션이며 실제 휴대전화의 성능·오디오 지연과 곡 전체의 수동 무피격 플레이는 아직 확인하지 않았다. 원작 수준의 신규 3D 모델·리깅·전용 필살기 영상은 포함하지 않는다. 5수는 사용자가 선택한 기존 캐릭터 기반 전투 구조를 구현했다.
