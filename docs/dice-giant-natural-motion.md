# 박성원 모션 자연화 및 투척 애니메이션

## 연결된 동작
- 거인 손의 목표 위치를 지수 보간 대신 임계 감쇠 스프링(속도 유지)으로 이동. 손과 피격 판정은 동일한 giantHandPose 사용.
- 표 위에 놓인 실제 칩/코인/주사위/체스 물체를 집고, 손바닥에 부착하여 어깨 뒤로 당긴 뒤 던짐.
- 발사점은 물체가 손을 떠나는 순간의 손 월드 좌표. 이후 목표까지 포물선 궤적으로 비행해 원래 위험 판정 시작 시점에 도착.
- 같은 손은 앞 물체를 던진 뒤 새 물체를 집으므로 다수의 물체가 손 안에서 겹치지 않음.
- 발사 회전을 상속하여 회전이 튀지 않고, 부드러운 손목 반동과 몸통 비틀림으로 던지기 연계.
- 3페이즈 머리 박치기는 여러 타격의 자세 가중치를 합성해 연속 5회 타격 시 자세가 한 번에 바뀌지 않음. 초기 머리 떨림도 공격 준비와 블렌드.

## 판정과 성능
- 공격 데미지, warn/active 시작 시각, 피해 구역의 크기를 바꾸지 않음. 물체는 기존 판정의 충돌 시점에 사라지고 기존 이벤트의 이펙트를 발생.
- 공격 범위 표시(바닥 원/사각형)를 되살리지 않음.
- 투사체 메시를 재사용하고 메모리는 WeakMap으로 발사점 캐시. 추가 애니메이션 프레임 루프 없음.
- Node 회귀 테스트: tests/dice-giant-throw.test.mjs 및 tests/dice-giant-continuity.test.mjs.

## 검증 필요
- 실제 모바일/브라우저에서 손·투사체 동기화 및 3페이즈 연속 공격의 체감 동작 테스트.
