# 통합 기획안 v1.0 대비 구현 현황

기준일: 2026-11-04. 비교 대상은 사용자가 제공한 「오든링 — 두상의 서약」 통합 기획안 v1.0과 main `0598bec2`를 바탕으로 배서준을 추가한 코드다. 기획서 끝의 ‘박성원 신규 2페이즈·전장 개편 미구현’ 표기는 현재 코드를 반영하지 않는다. 과거 구현 문서에도 이전 규칙이 남아 있으므로 아래 코드와 현행 여정 규칙을 우선한다.

## 얼마나 구현되었나

배서준 추가 전에는 3/5보스, 이번 변경 후에는 **4/5보스(80%)가 전투 가능**하다. 이는 보스 수를 센 값이다. 최규원과 두 엔딩, 최종장 스토리 및 5보스 통합 검증이 남아 있어 전체 제작 완성률을 80%라고 평가하지 않는다. 기존 세 보스도 일부 연출과 수치가 기획안 이후 개편되었다.

## 기획과 다른 핵심 규칙

1. **중간 이어하기 폐지:** 패배·메인 복귀·새로고침 뒤 처음부터 도전한다. 기존 토벌과 기억의 불빛은 유지한다.
2. **서약 → 무기 진화:** 무기에 맞는 두 선택지를 첫 두 토벌 뒤 고른다. 박성원 뒤에는 강화 없이 배서준으로 진행한다.
3. **박성원 손 기믹 변경:** 손 경직 누적과 게이지 재생 대신 영구 손 파괴, 광기 붕괴 및 머리 박기 반격 구조를 사용한다.
4. **공통 페이즈 규칙은 완전히 통일되지 않음:** 배서준은 현재 공격을 마친 뒤 전환한다. 기존 박성원은 진행 공격을 취소하고 변신하므로 기획서 공통 순서와 다르다.
5. **그래픽의 수준:** 현재는 절차적 Three.js 메시 중심이다. 기획서의 액체·대성당 붕괴·초현실적 도서관 연출을 모두 완성한 상태가 아니다.

## 이번 변경의 검사 결과

- 배서준·공유 진행·저장·음악·인트로·렌더·모바일 관련 65개 검사 통과.
- 전체 로컬 검사: 889개 중 881개 통과. 4개는 로컬에 복원하지 않은 기존 음원 파일의 존재 검사다. 나머지 4개는 변경 전 main에서도 실패하는 광대 마운트 배율 2건, 박성원 머리 박기 높이 1건, 거인 의상 메시 개수 1건이다.
- 변경 전 실패는 [main의 Node regression tests 로그](https://github.com/gwonjae06-droid/oibung-elden-ring/actions/runs/41782887310/job/126418275982)에서도 동일한 4건으로 확인했다. 이 변경에서 기존 전투 수치나 메시를 임의로 수정하지 않았다.
- Edge WebGL에서 진입·변신·일시정지·승리·재도전·종료를 검사한다. 장기 자연 플레이, 실제 휴대폰 터치 감도·GPU 성능과 녹음 음질 검증은 별도다.
