# 오든링 — 배서준 혈액 유체 움직임 개선

## 실제 적용
- **공중 혈액:** 중력과 점성 항을 지수 해석 형태로 통합해 30/60/120fps에서 낙하 궤적이 일치하도록 개선. 크기에 따른 약한 저항력 차이와, 바닥 관통 대신 접촉 시간의 선형 보간 적용
- **바닥 핏자국:** 충격 운동량을 보유하고 면적 가중 병합. 표면장력 계열의 감쇠 확산과 점성 마찰로 퍼짐/멈춤/흡혈 회수 시 미끄러짐을 표현
- **스킬 피 형상:** 무작위 고주파 노이즈보다 한 방향으로 흘러가는 광택과 에너지에 따라 커지는 저주파 흐름으로 교체
- **성당 외부 혈해:** 플레이 가능한 마른 섬 근처 파도가 잦아드는 경계 감쇠, 느린 유향 파동과 유속에 연결된 하이라이트
- **2페이즈 흡혈:** 혈해→흉부의 곡선 흡입 경로, 속도 방향과 나란히 긴 피방울, 채널 종료까지 실제 흉부에 도착

## 성능과 밸런스
- **시각 효과 전용**: 피격 판정, 위치/높이 충돌, 피해량, 패턴 빈도, HP 회복 시간, 체력, 보스 AI 변경 없음
- Three.js 기존 InstancedMesh/유체 Geometry/재질 재사용; 입자/핏자국/물결 수량 상한 및 저사양 옵션 동일
- CPU 입자 계산은 유한 상수 시간 작업; 낙하에 필요한 해석적 점성 계산만 추가. GPU 혈해 지형에는 신규 세그먼트/메쉬 추가 없음
- 배서준의 액체 흐름은 근사 시뮬레이션 + PBR 변형이며, 일반적인 3D 입자 기반 유체역학(SPH/FLIP)을 도입한 것은 아님
- 기기별 FPS와 실사감은 브라우저/모바일 실물 점검 대상
