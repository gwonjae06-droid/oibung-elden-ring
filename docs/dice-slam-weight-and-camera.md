# 박성원 머리 박기: 타격 정지 및 카메라 무게감

- 머리가 착지하는 기존 headSlam 위험 판정 시작 순간에 한 번만 dice-giant-head-impact 이벤트를 보냅니다.
- 머리의 실제 판정과 피해량은 변경하지 않으며, 상체 무게중심 이동만 시각적으로 보강했습니다.
- 일반 충돌 시 약 65ms, 빠른 연속 박치기는 더 짧은 타격 정지를 적용합니다.
- 기존 전투 프레임의 시뮬레이션만 잠깐 정지하며 화면 연출은 지속됩니다.
- 카메라 충격은 급격히 감쇠하며, 모션 감소 설정에서는 정지와 흔들림 모두 생략합니다.
- 일시정지 또는 비활성 화면에서는 충격 진행 시간을 소모하지 않습니다.
- tests/dice-slam-feedback.test.mjs에서 충돌 시점, 자세, 카메라, 접근성, 일시정지를 검사합니다.
