# 배서준 전투 시네마틱 고도화

2026-11-04. 기존 전투 판정 파일 `blood-combat.mjs`, `blood-data.mjs`는 수정하지 않았다. 14개 기술의 피해량, 예고 시간, 회피 무적, 근접 반격 배율과 착지 시간은 기존 값을 사용한다.

운영 페이지의 import map에서 변경된 16개 렌더링·음원 모듈에 같은 배포 버전을 부여했다. Pages를 이미 열어 둔 브라우저가 예전 음악 모듈과 새 컷신 모듈을 섞어 읽지 않도록 하고, 같은 모듈을 서로 다른 URL로 중복 실행하지 않게 유지한다. 기존 보스의 다른 import map 항목은 유지한다.

## 구현

### 백색 대성당 미술 변경

사용자 요청으로 배서준 전장을 따뜻한 백색 대리석·흰 벽과 기둥·금장·옅은 청색 스테인드글라스로 변경했다. 벽면 구획과 상부 금장, 대리석 줄눈과 원형 상감을 추가하고 배경·안개·주광을 밝은 중성색으로 맞췄다. 보스의 어두운 머리·의복과 붉은 피는 유지한다. 2페이즈에는 흰 건축 위로 붉은 창빛과 혈흔이 대비되며, 일식과 컷신의 감광은 유지한다. 흰 바닥의 위험 예고에는 짙은 와인색 외곽선을 사용한다.

최신 원격 전투 효과를 보존해 통합한 뒤 전체 958개 검사를 재실행했다. 결과는 950개 통과·8개 실패다. 수정 전 원격 커밋 180783f의 별도 사본에서도 같은 8개가 실패함을 확인했다. 이전 7개에 원격에서 추가된 패턴 단계 순서 검사 실패가 포함되며, 흰 성당 변경으로 생긴 실패는 없다. 브라우저에서 1·2페이즈의 색감과 공격 예고 가독성을 확인했다. 혈왕 연출 모듈의 import map 버전을 갱신해 이전 어두운 전장이 캐시에서 남지 않게 했다.

## 실제 음원 분석과 선택

파일 바이트는 변경하지 않았다. `scripts/analyze-blood-audio.mjs`로 디코딩한 길이, 시작 에너지, 1초 단위 RMS와 피크를 확인했다. 스크립트는 분석용 `ffmpeg-static` 또는 `FFMPEG_PATH`가 필요하다. 재생에는 이 도구가 필요 없다.

| 원본 | 길이 | 원본 스테레오 RMS/평균 | 피크 | 적용 |
|---|---:|---:|---:|---|
| bloodbgm1.mp3 | 192.79초 | -17.5 dB | -1.8 dB | 변신 시작부터 0.48초 동안 전체 믹스를 감쇠 |
| womanvoice.mp3 | 18.00초 | -13.02 dB | -0.04 dB | 0.6초에 재생, 시작 무음 0.077초 보정, 게인 0.29, 4.4초까지 페이드 종료 |
| bell.mp3 | 4.81초 | -26.67 dB | -5.31 dB | 1.8초에 재생, 시작 무음 0.157초 보정, 게인 0.62, 4.6초까지 페이드 종료 |
| bloodbgm2.mp3 | 263.23초 | -17.1 dB | -1.9 dB | 컷신 3.8초에 파일의 1.8초부터 페이드인 |

2페이즈 음원은 시작 1초 구간보다 2초 구간의 에너지가 약 10dB 높아지는 도입부를 선택했다. 특정 합창이나 악기 구성을 추정하지 않았다. 18초 독창 전체를 재생하는 대신 4.6초 전투 전환 안에 앞부분을 배치하고 감쇠한다. 약한 필터 잔향을 추가하며 원본의 피치·속도는 바꾸지 않는다. 마스터·효과음·음악 음량과 음소거를 준수한다.

## 검증과 한계

- 신규 자동 검사: 패턴 종료 후 1회 변신, 독창·종의 1회 시작, 일시정지·재개·건너뛰기, 음소거, 차단된 재생 반복 방지, BGM 단독 전환, 모든 기술의 실제 피해, 파티클 상한·소멸, 반복 전투의 고정 자원 수.
- 기존 예고 메시 방향·모양, 모든 무기의 실제 피해·공중 저항·착지 반격·회피 검사를 유지했다. 기존 테스트의 기대값은 수정하지 않았다.
- 실제 IAB WebGL에서 14개 기술 순회, 변신, 두 음원 재생 횟수와 BGM 볼륨·재생 위치, 실제 건너뛰기 버튼, 일시정지, 재도전, 종료와 작은 가로 화면을 검사했다.
- 전체 테스트 및 성능 수치는 아래 최종 검증 기록에 정리한다. 초기 의존성이 없는 실행은 928개 중 10개 실패였고, CI와 같은 Three.js를 준비한 기준 결과는 **932개 중 925개 통과·7개 실패**였다.
- 실패 기준: `balance.test.mjs`의 제거된 도전 모드, `clown-mount-volume.test.mjs`와 `clown-pressure.test.mjs`의 배율, `dice-model.test.mjs`의 모델 세부, `moves.test.mjs`의 체력 기대값, `skill-combat.test.mjs`의 망치·활 피해 기대값. 이 작업은 해당 기능이나 기대값을 변경하지 않았다.
- 화면 공간 유체·굴절이나 실제 유체 시뮬레이션은 구현하지 않았다. 절차적 곡면과 셰이더·입자 운동을 조합한 경량 근사다. 반사는 동적 광원의 젖은 표면 하이라이트이며 실시간 평면 반사는 아니다.
- 모바일 크기의 브라우저 검사와 실제 모바일 기기 성능은 다르다. 실기기 터치, 중급·저사양 기기의 30FPS 보장, 네 무기의 자연 플레이 완수는 미검증이다.

## 재현

`npm install --no-save --no-package-lock three@0.180.0` 후 `npm test`를 실행한다. 브라우저 검사는 `node scripts/serve-preview.cjs`를 실행하고 `/scripts/blood-qa.html`에서 진행한다. QA 페이지는 실제 전투를 iframe에 띄우며 운영 진입점에는 QA 코드를 연결하지 않는다. 진단은 `launchBloodBattle({diagnostics:true})`에서만 켜지고 최근 240프레임과 렌더러 자원 수를 제공한다.

일반·모바일·저품질의 방울 상한은 각각 240·128·64개, 웅덩이는 28·18·10개다. 저품질은 날개 혈류 개수와 지오메트리 분할 및 셰이더 연산도 줄인다. 위험 예고와 공격 판정은 품질 단계에 관계없이 같다.

## 최종 로컬 검증 기록

- 전체 자동 테스트: **942개 중 935개 통과, 기존 7개 실패 유지, 신규 실패 0개**. 새 검사 10개를 추가했다. 혈왕·BGM·보스 녹음 효과음 관련 집중 검사 55개는 모두 통과했다.
- 실제 브라우저: 일반 품질 14개 기술 순회, 최종 저품질 14개 순회, 각 품질에서 14개 기술을 4회 반복하는 렌더링 검사. 브라우저 QA 오류 수집 결과는 비어 있었다.
- 최종 일반 품질 반복 검사: GPU 지오메트리 **193 → 193 → 193 → 193**, 텍스처 **1 → 1 → 1 → 1**. 최종 저품질 반복 검사: 지오메트리 **196 → 196 → 196 → 196**, 텍스처 1개 유지. 가림 처리와 카메라 경로에 따라 처음 GPU에 올라오는 자원 수는 달라지지만 반복 중 증가하지 않았다.
- 프레임 간격: 일반 품질 1440×900, 저품질 844×390의 최근 240프레임에서 중앙값·95백분위가 각각 약 **5.6ms**. 현재 PC의 IAB 브라우저에서 측정한 짧은 표본이다. 휴대폰 성능이나 긴 플레이 세션의 최저 FPS를 뜻하지 않는다.
- 실제 음원 진단: 정상 컷신의 독창·종 모두 재생 시도 1회·실패 없음. 컷신 0.6~3.8초 구간의 BGM1 볼륨 0, 3.8초 이후 BGM2만 존재하며 1.8초 오프셋에서 시작했다.
- 독창 중 일시정지한 전투 시계 **5.3535초**, 변신 시계 **1.0496초**, 독창 재생 위치 **0.520577초**가 관측 사이에 동일했다. BGM과 두 효과음은 일시정지 상태였다.
- 작은 화면의 실제 한국어 건너뛰기 버튼으로 2페이즈에 진입하고 전투가 활성화된 것을 확인했다. 저품질 보스 HUD는 844×390 화면에서 세로 247~342px 안에 표시됐다.
- 스크린샷·원시 진단 JSON은 로컬 `qa-output/`에 보관하며 저장소에서는 제외한다. GitHub 업로드·Pages 배포와 실제 배포 화면 확인 결과는 작업 완료 보고에 별도로 명시한다.
