# 배서준 — 혈익 골격·14개 공격 전신 안무 개선 (2026-11-05)

## 구현 범위

- `src/blood-wings.mjs`: 어깨 관절, 위팔뼈, 팔꿈치, 손목, 6개 방사형 날개뼈. 기존 중첩 막대날개 대신 인접한 뼈 사이에 굴곡 있는 양면 두께의 막을 만들고, 가장자리에 피막 봉합선과 발톱을 추가한다.
- 날개 움직임은 좌우 개별 회전, 팔꿈치/손목 힌지, 접기·펼치기·내리찍기·날개 휘두르기, 선회 관성을 사용한다. 날개 뼈와 막은 기존 2페이즈 변신 타임라인에 따라 순차 노출된다.
- `src/blood-attack-motion.mjs`: 14개 패턴 각각의 상체 기울기·회전, 양손, 팔꿈치, 시선, 날개 전개·접기·흔들기·망토의 고유 모션을 정의한다. 경고 진행도는 게임의 `blood.hazards[].warn`, `age`, `blood.t`에서 파생한다.
- `src/blood-regalia.mjs`: 팔꿈치 아래의 실제 회전 피벗을 추가하고 가슴갑옷, 로브, 망토, 손목·손이 동작을 따라가게 한다.
- `src/blood-head.mjs`: 얼굴 회전도 같은 동작 타임라인에 연동한다.
- `src/blood-view.mjs`: 기존 파티클·혈마법 효과 및 실제 판정을 보존한 채 위 모션을 합성한다. 피격 반응은 별도 오프셋으로 처리해 패턴 애니메이션과 상쇄되지 않게 한다.
- `spider-combat.html`: 새 모델·동작 모듈의 버전 통일 및 브라우저 캐시 갱신.

## 공격별 동작

| 공격 | 핵심 몸짓 |
|---|---|
| 피의 파도 | 상체 앞으로, 양손 앞으로 밀어내기 |
| 피의 분수 | 상체 뒤로 젖히고 양팔을 위로 들어올림 |
| 피폭발 | 흉부 수축 후 양팔로 폭발 펼치기 |
| 피의 구체 | 양손 교차·순차 투척 |
| 피의 사슬 | 왼팔 당겨 포획·몸통 비틀기 |
| 혈류 회전 | 상체 큰 회전과 손의 반원 궤적 |
| 피의 소용돌이 | 상체 접기·손을 모으는 회오리 |
| 혈익 강하 | 날개를 접고 전신 숙여 창처럼 강하 |
| 피의 일식 | 몸을 뒤로 젖히고 날개 완전 전개 |
| 혈우 | 공중에서 손을 들어 연속 낙혈 |
| 붉은 날개 베기 | 몸통 비틀기·한쪽 날개 횡베기 |
| 심장 파동 | 양손 가슴으로 모으고 날개 펴 파동 |
| 혈익 추격 | 날개를 뒤로 접어 빠른 추격자 자세 |
| 종말의 혈조 | 날개 크게 열고 양손으로 종말의 물결 유도 |

## 테스트·보존

- 캐릭터와 날개는 전투 중 프레임마다 기존 메시를 재사용한다. 모바일 저세부 메시, 사용자 모션 감소 옵션을 보존한다.
- 공격의 *위험 범위, 공격 발생 시간, 체력/피해량, 경고 타이밍*은 모두 `blood-combat.mjs`, `blood-data.mjs`를 그대로 사용한다.
- 자동 검사: `node --test tests/blood-attack-animation.test.mjs tests/blood-regalia.test.mjs tests/blood-head.test.mjs tests/blood-render.test.mjs`.
- 실제 WebGL에서 날개 크기·가림·애니메이션의 시각적 자연스러움 및 모바일 FPS는 별도 수동 확인이 필요하다.
