# 봉인 밖의 문

메인화면에서 제목 ‘오든링’을 5번 빠르게 클릭/터치하거나, 키보드로 ODEN을 순서대로 입력하면 열립니다. 키보드는 물리 키(event.code)를 사용하므로 한글 입력 상태에서도 같은 위치의 키로 동작합니다. 입력 필드·설정·전투 중 입력과 키 반복은 무시합니다. 새로고침 후에는 다시 숨겨집니다.

검·망치·활·카드를 고른 뒤 현재 구현된 이권재·오슬우·박성원 중 하나로 바로 이동합니다. 전투 시작 유예와 해당 보스의 기본 체력을 적용하며 진화는 없이 시작합니다. 승패 결과에서 같은 보스 재도전, 다른 보스 선택, 메인 복귀가 가능합니다.

이 경로에서는 토벌 불빛·서약 기억·클리어 시간·도전 해금을 갱신하지 않습니다. 승리 연출 도중 창을 닫아도 기록에 섞이지 않습니다. 일반 ‘시련 시작’은 항상 첫 보스부터 시작합니다. 기존 3보스 전투·일시정지·자원 정리 경로를 재사용하며 구형 보스 이동 런타임은 다시 활성화하지 않습니다.

박성원 개편 후에는 ‘박성원 · 육체 강탈부터’로 체력 49%의 강탈 컷씬에서 바로 시작할 수도 있습니다. 같은 보스 재도전도 이 시작 지점을 유지합니다.
