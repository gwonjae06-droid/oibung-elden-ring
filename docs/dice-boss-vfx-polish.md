# 박성원 전용 VFX 강화 (1~3페이즈)

- 1페이즈: 주사위 착지·점프 충돌·눈금 폭발에 금속 파편, 금빛 반짝임, 여러 겹의 후충격파
- 2페이즈: 실제 손 충돌과 칩/코인/체스 물체의 착지에 상아색·금빛 입체 파편을 동기화. 손 타격·파괴·재생은 각기 다른 강도
- 3페이즈: 머리 박기 충돌에는 붉은 입자, 긴 잔상, 세 겹의 후충격파, 빠르게 감쇠하는 광원. 광기 전환은 머리 주위의 공중 파동
- 공격 준비 중의 3D 에너지 입자는 손·머리·주사위 자체에만 붙여서 기존에 제거한 위험 범위 오버레이를 복원하지 않음
- 순수 렌더러 전용. 게임 수치, 판정 반경, 발동 시간은 변경하지 않음
- PC 최대 270/모바일 140/모션 감소 55 입자를 미리 할당. 동적 BufferGeometry만 갱신. 일시정지/재시작/메뉴/종료 시 해제
- 테스트: tests/dice-boss-fx.test.mjs, tests/dice-boss-impact-beats.test.mjs
