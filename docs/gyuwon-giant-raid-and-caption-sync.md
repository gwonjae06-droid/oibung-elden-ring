# 최규원 — 거대 5수 레이드와 원곡 자막

사용자가 지정한 거대 5수 레이드 전체를 구현하는 작업이다. 기반은 최신 main `a840b53`이며, 여덟 원곡의 1배속 전체 재생과 5수 이후 공유 체력 1HP 보호는 그 변경을 유지한다. 마지막 800HP 엔딩의 영상 구조를 개편하지 않고 해당 원곡의 자막도 함께 교정한다.

## 5수 전투

- 네 파티원은 이권재·오슬우·박성원·배서준이다. 오슬우는 현재 보스전이 사용하는 `clown-ringmaster-actor.mjs`의 1페이즈 리깅, 배서준은 `blood-regalia.mjs`의 실제 의복·몸통·팔·손가락·다리·관절과 `blood-head.mjs`의 1페이즈 얼굴을 사용한다. 옛 광대 모델과 별도로 만든 원기둥 혈왕 몸체를 교체했다.
- 거대 최규원은 기존 얼굴·머리·의복 메시를 바탕으로 무대 뒤편에 상반신을 드러낸다. 분리된 어깨·팔꿈치·팔목과 손가락 3관절, 턱·입·눈꺼풀·눈썹, 호흡과 연미복 패널을 움직인다. 입의 활동 구간은 실제 원곡 자막 구간을 따른다. 정밀한 음소별 비짐을 캡처한 영상이나 신규 인물 스캔은 아니다.
- 왼손·오른손·조명핵·가면·중심핵은 독립 HP와 강인도를 가진다. 음악 구간에 따라 노출되며, 파괴한 부위는 재생하지 않는다. 브레이크·속박으로 해당 부위의 공격 순서를 늦춘다.
- 일반 공격은 공유 포인트를 회복하고 스킬은 소비한다. 개별 에너지가 찬 파티원은 자기 턴 밖에서도 필살기를 사용한다. 지원 행동과 자동 지원으로 KO한 동료를 복귀시키므로 전원 KO가 곡의 진행을 막지 않는다.
- 이권재는 높은 부위로 실제 도약해 접촉한 뒤 강인도를 깎는다. 필살기는 높게 도약한 뒤 내려찍는다. 오슬우는 충격파와 광대 인형·단체 공격으로 다중 부위를 속박한다. 박성원은 실제 이동하는 주사위와 1~6의 결과에 따른 증폭·추가타·에너지 지원을 사용한다. 배서준은 지속 피해·파티 회복·혈익과 보호 고리를 사용한다.
- 적의 손은 실제 손 좌표로 준비→이동→접촉→회복한다. 조명·가면·핵의 공격체도 발사 위치에서 피해 위치까지 이동한다. 준비 중에는 피해가 없으며, 접촉 후 같은 공격이 반복 판정되지 않는다.
- 무대 판자는 손의 충격 위치에서 내려앉고, 파괴 부위에는 풀링한 3D 파편을 사용한다. 카메라는 기본 구도와 필살기 강조 구도 사이를 보간하며 상단 진행 표시와 부위 선택창을 분리한다.

원곡의 시작 인사와 첫 절, 약 40초의 막 올리기, 90초의 새 역할, 109초의 후렴과 165초 이후 후주를 공연의 기준점으로 사용한다. 기획서의 초 단위 구획을 강제하기 위해 음악을 자르지 않는다. 마지막 합동 장면의 강도는 실제 부위 파괴와 사용한 능력을 반영한다. 부위를 일찍 모두 파괴해도 후주까지 들려주고, 원곡 종료 후에만 전체 HP 6,000→5,300 및 6수 전환을 처리한다.

## 음악과 영어·한국어 자막

8개 원곡을 로컬 Whisper small.en/base.en으로 단어 단위 분석하고, 흔들린 구간은 짧은 원곡 구간으로 다시 분석했다. 반복 인식·악기 구간의 허위 문장·음원 길이 밖의 타임스탬프를 제외하고 원문 구절과 번역을 대조했다. 8수 첫 문답의 두 구절은 출처가 있는 기존 원곡 구간 매핑을 사용한다.

| 원곡 | 자막 구절 수 |
| --- | ---: |
| Welcome to My World! | 32 |
| Run Into Tomorrow! | 27 |
| My Little Army! | 29 |
| Dance Until the Morning! | 24 |
| Give Me One More Round! | 31 |
| A Million Shooting Stars! | 25 |
| The Greatest Show of My Life | 30 |
| When the Music Ends | 26 |
| 합계 | 224 |

`gyuwon-aligned-captions.mjs`는 실제 원본 MP3의 SHA-256, 파일명, `audio.currentTime` 기준과 구절별 정렬 신뢰도를 기록한다. 아직 확인되지 않은 극본 문장을 일정 간격으로 반복 생성하던 경로는 제거했다. 간주·후주에는 억지로 가사를 채우지 않는다. 원곡 교정을 추가할 수 있는 수동 우선 데이터 구조는 유지한다.

**한계:** 단어 단위 시각은 로컬 음성 분석과 구절 대조 결과다. 사람이 여덟 곡을 모두 들으며 모든 자음·긴 음의 끝을 승인한 결과라고 주장하지 않는다. 자동 인식은 합창·애드리브·길게 끄는 음에서 미세한 경계 오차나 누락을 남길 수 있다. 모델과 분석 결과는 제작용이며 게임에 음성 분석 라이브러리를 배포하거나 플레이 중 모델을 다운로드하지 않는다.

자막 제작을 다시 실행하려면 선택적 제작 의존성 `@huggingface/transformers`, `ffmpeg-static`을 준비한 뒤 `node scripts/transcribe-gyuwon-originals.mjs`, `node scripts/align-gyuwon-captions.mjs` 순서로 실행한다. 원곡 오디오는 로컬에서 처리하며 외부 전사 서비스로 업로드하지 않는다. 분석 자료가 없을 때 정렬 도구는 기존 자막을 빈 데이터로 덮어쓰지 않고 중단한다.

## 검증

- 관련 검사 75개 통과: 실제 도약과 접촉, 다중 속박, 회복·보호·출혈, 전원 KO 복귀, 부위 영구 파괴, 곡 종료 소유권, 자막의 시간·번역·정렬 출처와 원본 파일 해시 등을 검사한다.
- 전체 2,176개 중 2,146개 통과, 30개 실패. 변경 전 최신 main `a840b53`을 별도 작업 폴더에서 검사한 결과는 2,164개 중 2,134개 통과, 동일한 30개 실패였다. 새 실패는 없다.
- `gyuwon-giant-raid-qa.mjs`: 5수 원곡을 탐색하지 않고 실제 재생 시계로 끝까지 진행하며 화면의 실제 버튼으로 전투했다. 다섯 부위 파괴, 네 동료의 능력 사용, 1HP 보호, 곡 종료 후 정확한 5,300HP와 6수 진입을 확인했다. 검사 중 플레이어/부위 HP나 에너지를 임의로 공급하지 않는다.
- 최종 주요 구간 화면을 별도로 확인했다. 844×390의 터치 대상 선택도 통과했다. 자동 검사에 사용한 입력은 실제 휴대전화의 물리 터치 검증과 구분한다.
- 기존 브라우저 검사로 일곱 곡의 정상 종료, 음악 정지·재개·음소거, 정확한 HP, 800HP 엔딩, 복도, 여섯 장르의 조작과 3D 복귀를 확인했다.
- 관측 성능: Edge 소프트웨어 렌더러의 터치 품질 1280×800 주요 구간에서 약 499~545 draw call / 8.4만~9.3만 삼각형. 데스크톱 품질 검사 장면은 529 draw call / 약 21.5만 삼각형이었다. 실제 GPU별 FPS, 기기의 장시간 발열과 오디오 출력 지연은 미측정이다.

기존 6~10수의 2D 렌더링과 11수 합동 배역 재사용을 유지한다. 11수에서 5수로 다시 시작할 때에도 실제 파티 모델이 레이드의 부모 장면으로 돌아오도록 처리했다. 파편·탄환·보호·속박 효과는 풀링하고, 종료 시 모델과 오디오 자원을 정리한다.
