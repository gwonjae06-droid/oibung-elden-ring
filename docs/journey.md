# 여정: 기본 시련과 불꽃 지름길

## 진행 규칙

무기를 선택해 이권재 → 오슬우 → 박성원 → 배서준 순서로 도전합니다. 패배·메인 복귀·새로고침·브라우저 종료 시 진행 중인 도전은 종료됩니다. 패배 화면의 재도전은 첫 보스부터 시작합니다. 대장간에서 영구 각인한 무기 진화와 보유 불꽃은 유지됩니다. 전투 중 불꽃 부활은 제공하지 않습니다.

## 불꽃 지름길

메인에서 **불꽃 사용 → 시련 시작 → 무기 선택 → 출정** 순서로 해금된 마지막 보스부터 시작할 수 있습니다. 비용은 정화의 불꽃 1개이며, 메인과 무기 선택 화면에 도착할 보스와 건너뛸 보스 수를 표시합니다. 선택만 하거나 사용 취소·메인 복귀·새로고침한 경우에는 차감하지 않습니다. 실제 전투 세션이 열린 뒤 1개를 차감하므로 전장 로딩 실패 후 재시도에도 중복 지불하지 않습니다.

첫 보스는 처음부터 해금됩니다. 앞 보스들을 순서대로 정상 토벌하면 다음 보스가 해금됩니다. 예를 들어 이권재만 토벌했다면 오슬우, 박성원까지 토벌했다면 배서준으로 이동합니다. 앞 순서의 토벌 기록이 빠져 있으면 그 문을 넘어갈 수 없습니다. 숨겨진 이동 전투의 승리는 지름길을 해금하지 않으며, 미구현 최규원에게는 이동할 수 없습니다. 건너뛸 보스가 없거나 불꽃이 부족하면 사용 버튼이 비활성화됩니다.

건너뛴 보스의 불꽃·기억·토벌 기록은 새로 지급하지 않습니다. 도착한 보스부터 실제로 토벌한 보상만 얻고, 대장간 각인은 선택한 무기에 그대로 적용됩니다. 지름길 완수는 출발 보스와 실제 전투 시간으로 별도 표시하며 전체 연속 클리어 횟수·전체 최고 기록과 섞지 않습니다. 매번 지름길로 새 출정할 때마다 1개가 필요합니다.

각 전투는 1.6초 준비 유예 후 시작합니다. 유예 동안 공격 입력과 전투 시뮬레이션을 멈추며, 일시정지·비활성 창에서는 유예도 소비하지 않습니다. 보스 체력은 2,100 / 3,400 / 5,200 / 6,400입니다. 후반의 기존 패턴과 페이즈 차이를 유지합니다.

## 토벌과 전환

토벌 장면 → 스토리 → 정화의 불꽃 1개 획득 확인 → 다음 도전 → 보상 화면이 사슬에 끌려 내려감 → 다음 보스 전환 연출 → 실제 전투.

이권재의 기억 확인 시 광대 연출을 먼저 재생하던 동작은 제거했습니다. 광대는 불꽃 보상 확인 이후에 등장합니다. 마지막 보스 뒤에는 다음 전투가 없으므로 최종 결과와 기록을 표시합니다.

무기 진화는 토벌 직후 선택하는 대신 메인의 대장간에서 불꽃으로 영구 각인합니다. 옛 3보스 기록은 4보스 기록과 구분하며, 옛 기록으로 배서준의 토벌 불빛을 켜지 않습니다. 이전 세 보스의 정상 토벌 기록은 배서준 지름길 입장 조건을 충족합니다.

## 무기 진화

| 무기 | 경로 A | 경로 B |
|---|---|---|
| 검 | 일반 베기와 함께 전방 검기 | 누른 뒤 떼는 차징 공격 |
| 망치 | 일반 강타와 함께 전방 파동 | 유효한 일반 공격 흡혈 12% |
| 활 | 일반 사격에 화살 1발 추가 | 일반 화살 속도·피해·관통 강화 |
| 카드 | 일반 공격 카드 2장 추가 | 유효한 일반 카드 피해 흡혈 8% |

대장간의 무기별 두 경로에 각각 최대 2단계를 각인할 수 있으며 단계당 불꽃 1개를 사용합니다. 검기·파동 피해, 차징 최대 배율, 화살·카드 수, 흡혈 비율, 관통 화살 피해가 각각 강화됩니다. 각인은 같은 브라우저의 이후 도전에도 유지되며, 무기별 투자 불꽃을 반환하여 다른 무기에 다시 투자할 수 있습니다.

차징은 좌클릭·J·터치 공격을 누르고 떼어 사용합니다. 짧게 누르면 일반 피해, 약 0.9초 유지하면 최대 3배 피해이며 추가 기력을 사용합니다. 두 번째 선택은 최대 배율 3.5배입니다. 회피·일시정지·포커스 상실 시 차징을 취소합니다. 적중하지 않거나 장갑에 막히면 흡혈하지 않습니다.

## 영구 기록과 저장 호환

토벌한 보스 ID, 기억, 완수 횟수와 기록을 브라우저 localStorage에 저장합니다. 토벌한 보스의 메인 문양에는 불이 켜집니다. 불빛은 패배나 새 도전 후에도 유지됩니다. 서버·계정 동기화나 온라인 랭킹은 아닙니다.

저장 스키마는 v4입니다. 이전 v1/v2/v3의 완수 기록과 기억을 보존하고, 이전 진행에서 이미 토벌했음이 확인되는 보스의 불빛을 복원합니다. 정화의 불꽃·누적 획득량·대장간 각인도 저장합니다. 지름길 기록에는 `startStage`를 저장하고, 이 필드가 없는 이전 기록은 첫 보스부터 시작한 기록으로 처리합니다. 지름길 기록 자체만으로 건너뛴 보스의 토벌을 복원하지 않습니다. 저장할 때 run은 항상 null로 기록하고, 현재 도전과 불꽃 사용 선택은 이어서 복원하지 않습니다.

## 모바일 가로 전용 화면

모바일 터치 기기에서는 세로 화면을 게임 UI로 사용하지 않습니다. 메인 메뉴와 네 보스전 모두 세로 방향에서는 회전 안내를 보여주고, 화면을 가로로 돌리면 게임이 표시됩니다. 전투 중 세로로 돌아가면 현재 전투를 자동 일시정지하고, 다시 가로로 돌아오면 자동 일시정지했던 동일 전투만 재개합니다.

가로 고정 버튼은 사용자가 누를 때 전체화면과 Screen Orientation API의 `landscape` 잠금을 시도합니다. 브라우저/기기에서 지원하지 않거나 허용하지 않는 경우 강제로 회전할 수 없으므로 수동 회전을 안내합니다. PC는 가로 전용 제한을 받지 않습니다. 모바일 가로 화면에서는 공통 HUD를 축소하고 조이스틱·공격/회피/스킬 버튼의 터치 영역을 유지합니다. 실제 휴대폰 기종별로 브라우저 지원과 UI 겹침을 확인해야 합니다.

## 검증

자동 검사: 네 전투 엔진의 체력·유예 설정, 무기별 두 경로, 반복 각인, 실제 검기 충돌 피해, 차징 기력·배율·취소, 흡혈과 관통 수치, 외부로 이동한 포인터 해제, 저장 호환, 스토리·불꽃·사슬·등장의 순서를 확인합니다. 지름길의 연속 해금 조건, 잔액 부족, 취소, 실패한 로딩 후 재시도, 1회 차감, 실제 토벌만 보상, 출발점별 완수 기록 구분도 검사합니다.

`scripts/flame-skip-smoke.cjs`는 실제 여정 화면에서 선택 취소, 모바일 가로 화면, 영구 활 각인을 적용한 배서준전 진입, 불꽃 1개 차감 및 미해금 비활성 상태를 확인합니다. 브라우저 검증은 준비된 토벌 기록으로 진행하며 실제 조작으로 앞 보스를 모두 토벌하거나 장기 밸런스를 확인한 검증을 대체하지 않습니다. 검증용 페이지는 정적 배포에 포함하지 않습니다.

`scripts/startup-cache-smoke.cjs`는 배포용 HTML과 실제 초기화 코드를 그대로 열고, 오래된 여정 URL에 이전 부활 함수의 import가 남은 상황을 재현합니다. 시작 코드는 import map을 따르는 여정 주소를 사용하며 이전 URL도 같은 최신 주소로 연결합니다. 삭제된 부활 함수 이름은 동작하지 않는 호환 export로 유지하여 캐시가 섞여도 초기화를 막지 않습니다. 이 검사는 메인 표시와 실제 첫 보스전 진입까지 확인합니다.

메인 음악은 기존 업로드된 assets/music/maintheme.mp3를 사용하며, 최초 입력·메뉴 전환 페이드·음소거·창 비활성화 처리를 유지합니다. MP3가 로드되지 않는 경우에만 기존 피아노 합성곡으로 대체합니다. 보스별 기존 MP3도 유지합니다.
