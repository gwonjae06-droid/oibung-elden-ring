# 여정: 처음부터 도전하고 무기를 진화시키기

## 진행 규칙

무기를 선택해 이권재 → 오슬우 → 박성원 → 배서준 순서로 도전합니다. 패배·메인 복귀·새로고침·브라우저 종료 시 진행 중인 도전은 종료됩니다. 이어하기와 중간 보스 재도전은 제공하지 않습니다. 패배 화면의 재도전도 첫 보스부터 시작하며 모든 무기 진화가 초기화됩니다.

각 전투는 1.6초 준비 유예 후 시작합니다. 유예 동안 공격 입력과 전투 시뮬레이션을 멈추며, 일시정지·비활성 창에서는 유예도 소비하지 않습니다. 보스 체력은 2,100 / 3,400 / 5,200 / 6,400입니다. 후반의 기존 패턴과 페이즈 차이를 유지합니다.

## 토벌과 전환

토벌 장면 → 스토리 → 무기 진화 2개 중 선택 → 선택한 진화 확인 → 다음 도전 → 보상 화면이 사슬에 끌려 내려감 → 다음 보스 전환 연출 → 실제 전투.

이권재의 기억 확인 시 광대 연출을 먼저 재생하던 동작은 제거했습니다. 광대는 보상 선택 이후에 등장합니다. 마지막 보스 뒤에는 다음 전투가 없으므로 최종 결과와 기록을 표시합니다.

박성원 뒤에는 기억을 읽고 추가 진화 없이 배서준으로 진행합니다. 무기 진화 선택은 첫 두 보스 뒤 두 번으로 제한합니다. 옛 3보스 기록은 4보스 기록과 구분하며, 옛 기록으로 배서준 토벌을 해금하지 않습니다.

## 무기 진화

| 무기 | 경로 A | 경로 B |
|---|---|---|
| 검 | 일반 베기와 함께 전방 검기 | 누른 뒤 떼는 차징 공격 |
| 망치 | 일반 강타와 함께 전방 파동 | 유효한 일반 공격 흡혈 12% |
| 활 | 일반 사격에 화살 1발 추가 | 일반 화살 속도·피해·관통 강화 |
| 카드 | 일반 공격 카드 2장 추가 | 유효한 일반 카드 피해 흡혈 8% |

같은 경로를 다시 선택할 수 있습니다. 검기·파동 피해, 차징 최대 배율, 화살·카드 수, 흡혈 비율, 관통 화살 피해가 각각 강화됩니다. 진화는 현재 도전에만 적용됩니다.

차징은 좌클릭·J·터치 공격을 누르고 떼어 사용합니다. 짧게 누르면 일반 피해, 약 0.9초 유지하면 최대 3배 피해이며 추가 기력을 사용합니다. 두 번째 선택은 최대 배율 3.5배입니다. 회피·일시정지·포커스 상실 시 차징을 취소합니다. 적중하지 않거나 장갑에 막히면 흡혈하지 않습니다.

## 영구 기록과 저장 호환

토벌한 보스 ID, 기억, 완수 횟수와 기록을 브라우저 localStorage에 저장합니다. 토벌한 보스의 메인 문양에는 불이 켜집니다. 불빛은 패배나 새 도전 후에도 유지됩니다. 서버·계정 동기화나 온라인 랭킹은 아닙니다.

저장 스키마는 v3입니다. 이전 v1/v2의 완수 기록과 기억을 보존하고, 이전 진행에서 이미 토벌했음이 확인되는 보스의 불빛을 복원합니다. 이전의 진행 중 체크포인트를 이어서 시작하지 않습니다. 저장할 때 run은 항상 null로 기록하고, 현재 창의 도전만 메모리에 유지합니다.

## 모바일 가로 전용 화면

모바일 터치 기기에서는 세로 화면을 게임 UI로 사용하지 않습니다. 메인 메뉴와 네 보스전 모두 세로 방향에서는 회전 안내를 보여주고, 화면을 가로로 돌리면 게임이 표시됩니다. 전투 중 세로로 돌아가면 현재 전투를 자동 일시정지하고, 다시 가로로 돌아오면 자동 일시정지했던 동일 전투만 재개합니다.

가로 고정 버튼은 사용자가 누를 때 전체화면과 Screen Orientation API의 `landscape` 잠금을 시도합니다. 브라우저/기기에서 지원하지 않거나 허용하지 않는 경우 강제로 회전할 수 없으므로 수동 회전을 안내합니다. PC는 가로 전용 제한을 받지 않습니다. 모바일 가로 화면에서는 공통 HUD를 축소하고 조이스틱·공격/회피/스킬 버튼의 터치 영역을 유지합니다. 실제 휴대폰 기종별로 브라우저 지원과 UI 겹침을 확인해야 합니다.

## 검증

자동 검사: 네 전투 엔진의 체력·유예 설정, 무기별 두 경로, 반복 진화, 실제 검기 충돌 피해, 차징 기력·배율·취소, 흡혈과 관통 수치, 외부로 이동한 포인터 해제, 저장 호환과 기록만 유지, 스토리·보상·사슬·등장의 순서를 확인합니다.

브라우저에서는 검증용 토벌 이벤트를 이용해 스토리 → 진화 → 사슬 → 실제 광대전 진입을 확인했습니다. 실제 광대전에서 J를 누르고 떼어 완충 기력 소모 28과 입력 해제를 확인했고, 패배 후 처음부터 재도전 UI와 콘솔 오류 없음도 확인했습니다. 실제 조작으로 첫 보스를 토벌한 검증이나 모든 진화 조합의 연속 클리어·장기 밸런스 검증을 대체하지 않습니다. 검증용 페이지와 토벌 버튼은 배포에 포함하지 않습니다.

메인 음악은 기존 업로드된 assets/music/maintheme.mp3를 사용하며, 최초 입력·메뉴 전환 페이드·음소거·창 비활성화 처리를 유지합니다. MP3가 로드되지 않는 경우에만 기존 피아노 합성곡으로 대체합니다. 보스별 기존 MP3도 유지합니다.
