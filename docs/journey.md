# 오슬우의 시련: 메인과 여정

메인에서 무기를 선택하고 이권재 → 오슬우 → 박성원 순서로 도전합니다. 보스 연습 메뉴는 추가하지 않았습니다. 전투 중 좌상단 오이붕 문장 또는 일시정지 후 무기 선택 버튼으로 메인에 돌아갈 수 있습니다.

## 진행과 보상

- 보스 토벌 직후 보상 선택 대기 상태를 저장합니다. 이때 창을 닫아도 이어하기에서 보상을 고릅니다.
- 보상은 기본 공격을 빠르게 하되 피해를 줄이는 바람, 피해와 기력 소모를 늘리는 파괴, 생명과 회피 효율을 높이는 생명 서약입니다. 두 번 선택하며 같은 서약을 중복 선택할 수 있습니다. 선택 후 다음 도전 버튼을 눌러 출발합니다.
- 다음 보스는 생명과 회복약을 보충하고 시작합니다. 서약은 이번 여정에만 누적 적용됩니다.
- 일반·시간·무회복 모드는 패배해도 현재 보스와 서약을 유지합니다. 연속 격파는 패배하거나 전투를 중단하면 첫 보스로 돌아가며 서약도 초기화됩니다.
- 새로고침 후에는 전투 도중 위치가 아닌 현재 보스 시작 지점부터 이어집니다.

## 기록과 도전

전체 클리어하면 무기, 모드, 누적 전투 시간, 패배 횟수, 날짜를 저장합니다. 최근 40개 기록과 무기·모드별 최고 시간을 표시합니다. 패배·메인 복귀 때 소비한 전투 시간도 누적되며, 메뉴·보상 선택 시간은 제외됩니다. 첫 전체 클리어 후 연속 격파, 시간 기록, 무회복 모드를 개방합니다. 무회복은 회복약을 금지하며 기존 망치 흡혈은 유지합니다.

저장 위치는 이 브라우저의 `localStorage`입니다. 계정·서버 동기화와 온라인 랭킹은 아닙니다. 저장을 사용할 수 없을 때는 안내하고 현재 창의 메모리로 진행합니다. 다른 기기나 다른 브라우저와 진행을 공유하지 않습니다.

## 메인 연출과 소리

중앙 텍스트를 거미·광대·주사위·핏방울·거울의 다섯 문양이 둘러싸는 고대 신전 벽화로 구성했습니다. 문양의 눈·미소·눈금·피·거울 반사 일부가 은은하게 빛납니다. 메인 음악은 58 BPM의 느린 피아노 선율과 잔향으로 변경했고, 전자적인 톱니파 화음과 저음 펄스·드럼 계열을 제거했습니다. 첫 입력 후 재생되며 전투 진입, 음소거, 비활성 창에서는 정지합니다. 기존 보스 MP3 여섯 개와 재생 코드는 유지했습니다.

설정에는 전체 음소거, 메인 음악 음량, 저사양 렌더 해상도 제한, 모션 감소가 있습니다. 그래픽·모션은 저장 후 새로고침하여 적용합니다. 운영체제의 모션 감소도 존중합니다.

## 검증

저장 복원·손상 복구·보상 대기 중 중복 승리 처리 방지·모든 모드의 패배 규칙·세 엔진의 실제 서약 적용·무회복·최종 기록과 도전 해제를 자동 검사합니다. UI 제어기를 통해 세 단계 전환과 보상·최종 클리어도 검사합니다. 음악은 제스처 전 생성 방지와 정지·해제를 검사합니다.

브라우저에서는 메인, 무기 선택, 실제 첫 보스 진입, 패배, 재도전, 새로고침 후 이어하기, 설정 적용과 390px 모바일 배치를 확인했습니다. 실제 조작으로 세 보스를 연속 클리어하거나 물리적 기기에서 음악을 청음한 것은 아닙니다. 서약 조합별 장기 밸런스와 실제 모바일 성능은 추가 플레이 검증이 필요합니다.

## 여정 전환 연출

첫 출정은 검기가 화면을 가르고 두 벽화 조각이 벌어지며 이권재 전장을 드러냅니다. 이권재 토벌 후에는 광대의 기존 3D 등장·인사를, 광대 토벌 후에는 주사위의 화면 압착 연출을 재생합니다. 각 연출이 끝나야 보상 선택이 열리며, 서약 선택 후 별도의 다음 도전 버튼으로 다음 보스를 시작합니다. 마지막 토벌에는 세 시련의 종결을 표시합니다. 전환 중 게임 시간은 흐르지 않으며 건너뛰기와 종료 시 정리를 지원합니다. 모션 감소에서는 첫 분할은 정적인 표시로 축소합니다.
