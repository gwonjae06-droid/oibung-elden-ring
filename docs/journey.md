# 여정: 기본 시련과 보스 자유 이동

## 진행 규칙

기본 여정은 이권재 → 오슬우 → 박성원 → 배서준 → 최규원 순서로 이어집니다. 메인의 **시련 시작** 화면에서 출발할 보스와 무기를 선택할 수 있습니다. 해금한 보스를 빠르게 다시 찾으려면 메인의 **해금 보스 선택 · 이동**을 누르면 됩니다. 보스 출발 지점을 바꾸거나 같은 보스를 재도전해도 **정화의 불꽃을 사용하지 않습니다**. 불꽃은 대장간 영구 각인 전용입니다.

처음에는 이권재만 열려 있습니다. 앞의 보스를 정상 토벌하면 다음 보스가 영구 해금됩니다. 예를 들어 이권재만 토벌했다면 이권재·오슬우 중 원하는 출발점을 선택할 수 있습니다. 순서가 맞지 않는 토벌 증거, 비밀 전투나 미해금 보스를 가리키는 임의 클릭으로 잠긴 보스에 진입할 수 없습니다.

선택한 보스부터 이후 보스들까지 순서대로 도전하며, 실제로 토벌한 적의 보상·기억만 획득합니다. 이미 해금한 보스를 다시 토벌해도 보스당 획득하는 불꽃은 기존 규칙을 따릅니다. 첫 보스부터 시작해 모든 보스를 토벌한 경우에만 전체 여정 클리어 횟수가 증가합니다. 선택 출발 기록은 별도로 남습니다. 패배·메인 복귀·새로고침·브라우저 종료 시 진행 중인 도전은 종료됩니다. 패배 화면에서 다시 도전하면 원래 선택했던 출발 보스부터 새로 도전합니다.

## 무기 능력치 그래프

출정 무기 선택 화면과 대장간의 무기 탭에서 검·망치·활·카드별 그래프를 볼 수 있습니다. 기본 1회 공격 피해와 경직 누적은 `src/weapon-data.mjs`를, 최대 체력·받는 피해·이동 속도·회피 거리·기력 회복은 `src/weapon-stats.mjs`의 실제 수치를 사용합니다. 막대 길이는 네 무기 간 상대 비교이며, 실제 수치는 막대 위에 표시합니다. 피해를 적게 받는 무기는 방어 효율 막대가 더 깁니다. 스킬·각인에 의한 별도 효과를 기본 수치에 합산하지 않아 잘못된 공격력 정보로 오해하지 않게 합니다.

## 토벌과 전환

토벌 장면 → 스토리 → 정화의 불꽃 1개 획득 확인 → 다음 도전 → 보상 화면이 사슬에 끌려 내려감 → 다음 보스 전환 연출 → 실제 전투.

이권재의 기억 확인 시 광대 연출을 먼저 재생하던 동작은 제거했습니다. 광대는 불꽃 보상 확인 이후에 등장합니다. 마지막 보스 뒤에는 다음 전투가 없으므로 최종 결과와 기록을 표시합니다.

무기 진화는 토벌 직후 선택하는 대신 메인의 대장간에서 불꽃으로 영구 각인합니다. 옛 3보스 기록은 4보스 기록과 구분하며, 옛 기록으로 배서준의 토벌 불빛을 켜지 않습니다. 이전 세 보스의 정상 토벌 기록은 배서준 자유 이동 해금 조건을 충족합니다.

## 무기 진화

| 무기 | 경로 A | 경로 B |
|---|---|---|
| 검 | 일반 베기와 함께 전방 검기 | 누른 뒤 떼는 차징 공격 |
| 망치 | 일반 강타와 함께 전방 파동 | 유효한 일반 공격 흡혈 12% |
| 활 | 일반 사격에 화살 1발 추가 | 일반 화살 속도·피해·관통 강화 |
| 카드 | 일반 공격 카드 2장 추가 | 유효한 일반 카드 피해 흡혈 8% |

대장간의 무기별 두 경로에 각각 최대 2단계를 각인할 수 있으며 단계당 불꽃 1개를 사용합니다. 검기·파동 피해, 차징 최대 배율, 화살·카드 수, 흡혈 비율, 관통 화살 피해가 각각 강화됩니다. 각인은 같은 브라우저의 이후 도전에도 유지되며, 무기별 투자 불꽃을 반환하여 다른 무기에 다시 투자할 수 있습니다.

차징은 좌클릭·J·터치 공격을 누르고 떼어 사용합니다. 짧게 누르면 일반 피해, 약 0.9초 유지하면 최대 3배 피해이며 추가 기력을 사용합니다. 두 번째 선택은 최대 배율 3.5배입니다. 회피·일시정지·포커스 상실 시 차징을 취소합니다. 적중하지 않거나 장갑에 막히면 흡혈하지 않습니다.

## 영구 기록과 저장 호환

토벌한 보스 ID, 기억, 완수 횟수와 기록을 브라우저 localStorage에 저장합니다. 토벌한 보스의 메인 문양에는 불이 켜집니다. 불빛은 패배나 새 도전 후에도 유지됩니다. 서버·계정 동기화나 온라인 랭킹은 아닙니다.

저장 스키마는 v4입니다. 이전 v1/v2/v3의 완수 기록과 기억을 보존하고, 이전 진행에서 이미 토벌했음이 확인되는 보스의 불빛을 복원합니다. 정화의 불꽃·누적 획득량·대장간 각인도 저장합니다. 선택 출발 기록에는 `startStage`를 저장하고, 이 필드가 없는 이전 기록은 첫 보스부터 시작한 기록으로 처리합니다. 선택 출발 기록 자체만으로 건너뛴 보스의 토벌을 복원하지 않습니다. 저장할 때 run은 항상 null로 기록하고, 현재 도전과 불꽃 사용 선택은 이어서 복원하지 않습니다.

## 모바일 가로 전용 화면

모바일 터치 기기에서는 세로 화면을 게임 UI로 사용하지 않습니다. 메인 메뉴와 네 보스전 모두 세로 방향에서는 회전 안내를 보여주고, 화면을 가로로 돌리면 게임이 표시됩니다. 전투 중 세로로 돌아가면 현재 전투를 자동 일시정지하고, 다시 가로로 돌아오면 자동 일시정지했던 동일 전투만 재개합니다.

가로 고정 버튼은 사용자가 누를 때 전체화면과 Screen Orientation API의 `landscape` 잠금을 시도합니다. 브라우저/기기에서 지원하지 않거나 허용하지 않는 경우 강제로 회전할 수 없으므로 수동 회전을 안내합니다. PC는 가로 전용 제한을 받지 않습니다. 모바일 가로 화면에서는 공통 HUD를 축소하고 조이스틱·공격/회피/스킬 버튼의 터치 영역을 유지합니다. 실제 휴대폰 기종별로 브라우저 지원과 UI 겹침을 확인해야 합니다.

## 검증

`tests/journey.test.mjs`와 `tests/journey-controller.test.mjs`에서 보스의 연속 해금, 선택 가능 범위, 미해금 보스 클릭 차단, 불꽃 미소모, 출발점별 기록, 패배 재도전, 기존 저장 호환성을 검사합니다. `tests/weapon-stat-chart.test.mjs`에서 막대와 실제 전투 스탯의 일치도 검사합니다.

`scripts/boss-travel-smoke.cjs`에서는 실제 메뉴의 이동 버튼, 모바일 선택 화면, 해금 및 잠금 상태, 무기 그래프와 보스전 진입을 확인합니다. 브라우저 자동 검사는 실제 플레이에 의한 장기 밸런스 검증을 대체하지 않습니다.

메인 음악은 기존 업로드된 assets/music/maintheme.mp3를 사용하며, 최초 입력·메뉴 전환 페이드·음소거·창 비활성화 처리를 유지합니다. MP3가 로드되지 않는 경우에만 기존 피아노 합성곡으로 대체합니다. 보스별 기존 MP3도 유지합니다.
