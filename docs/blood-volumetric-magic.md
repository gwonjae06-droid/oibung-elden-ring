# 오든링 — 입체 유체형 피의 파도 / 대성당 혈마법 확장

## 바뀐 렌더링 아키텍처
**주 공격 본체에 쓰이던 평면 `sheet` 메시를 실제 두께가 있는 3D 폐곡면으로 교체**했습니다.

- `src/blood-volumetric-wave.mjs`: 가로 단면마다 높이, 파면 말림, 앞부분 돌출, 뒤쪽 점성 후류를 조합해 3D 파도와 언더토우(under-tow)를 생성. 앞/뒤 단면을 캡으로 닫고 노멀 계산
- `src/blood-sculpture.mjs`: `fluid.surge`, `fluid.undertow`을 공유 유체 모델 목록에 등록. 패턴마다 새 정점 버퍼를 만들지 않음
- `src/blood-spell-fx.mjs`: `wave`, `tide`, `cross`, `bloodScissors`의 두꺼운 본체 + 전면 말림 + 바닥 질량 + 전면 비말. 기존 파티클 시스템의 충돌/흘러내림/합체와 함께 작동
- **전조 → 형성 → 두꺼운 파면 돌출 → 본체 전진 → 잔류 핏자국**. 가시적 움직임은 각 `h.age`, `h.warn`, `h.life`, `hazardPosition`에 동기화됨. 발동 전 비말은 숨김

## 대성당 규모 혈마법
`src/blood-grand-rites.mjs`에 기존 피 마법 패턴에 연동되는 **시각 전용** 3D 계층을 추가:
- **종말의 혈조 / 성혈의 십자:** 전장 바깥에서 솟아오르는 혈기둥, 높은 혈장막, 천장 가까이 떠 있는 혈륜
- **붉은 세례 / 피의 일식 / 천상의 혈검:** 성당 상부에서 압축되고 팽창하는 거대한 혈구, 겹치는 혈륜, 십자가형 혈류
- **심장 파동 / 피의 폭발:** 혈구의 수축과 큰 맥동 형태
- **혈우 / 혈분수 / 순교자의 혈창:** 높은 혈류 상승과 낙하를 강조하는 혈기둥
- 공격 종료 뒤 최대 1.2초에 걸쳐 사라지는 후속 잔상. 성당 기둥 및 천장 높이를 활용하되 새로운 위험 구역은 만들지 않음

## 전투·성능 안전장치
- 보스 HP, 피해량, 피격 판정, 행동/전조 시간, 이동 경로, 회피 가능 경로, 공중 무적, 흡혈량: **코드 변경 없음**
- 기존 `hazardPosition`을 그대로 읽고 액체 메시/스프레이/성당 장식은 판정에서 제외
- **배경 혈마법 고정 메시:** 일반 최대 22개, 저사양 최대 12개. 파도당 추가 비말 20개(저사양 8개)는 InstancedMesh로 1 draw call
- 신규 지오메트리는 공유 형태 2종만 추가. 스펠이 재생될 때마다 새로 생성하지 않음. 새 포스트프로세싱/실시간 광원/입자 물리 엔진 없음
- 기존 PBR 혈액 재질, 피입자/물체 충돌, 표면 핏자국, 2페이즈 흡혈과 호환
- 실제 입자 기반 유체역학(SPH/FLIP)이 아니라 **3D 액체 질량 모델 + 지수 감쇠 유체 입자 + 효과 방향의 시각 통합**이며 모바일 FPS는 실제 기기에서 점검 필요
