# 두상의 서약: 이권재 1장 적용

통합 기획안 v1.0의 첫 구현 단위입니다. 게임명은 오든링 — 두상의 서약, 플레이어는 응시자로 표기합니다. 메인에는 세계의 정답 대신 소망과 이름에 관한 질문을 남깁니다.

## 전장과 마지막 순간

기존 충돌과 전투 범위를 보존하고 외곽에 검을 든 기사상 10개, 기둥과 부서진 천장 리브를 배치했습니다. 배경은 차가운 달빛으로 조정했습니다. 장식은 피해 판정을 만들지 않습니다.

2페이즈에 들어서면 기사상의 머리가 순차적으로 떨어지고, 바닥의 금빛 균열과 조명 변화가 나타납니다. 기존 머리·검 변형 컷씬에는 기획안의 대사를 연결했습니다.

토벌 후 약 4.8초 동안 카메라가 쓰러진 보스와 떨어진 검을 향합니다. 보스의 팔은 검 쪽으로 뻗으며 주변 검들이 기울어집니다. 횃불의 맥동과 장식의 움직임은 잦아듭니다. 영화적 고해상도 인체 애니메이션이 아닌 기존 Three.js 모델과 관절을 활용한 연출입니다.

진행 순서: 토벌 장면 → 이권재의 서약 기억 → 기억을 새기고 다음 문으로 → 광대 등장 → 보상 선택 → 다음 도전.

## 저장과 기록

기억은 첫 획득 시 브라우저에 저장되고 기록실에서 다시 읽을 수 있습니다. 새 여정에서도 획득한 기억은 유지됩니다. 토벌 뒤 읽기 전 창을 닫았다면 이어하기에서 기억으로 돌아옵니다.

기존 v1 저장에 memories 배열과 선택적인 memoryRead 필드를 추가했습니다. 기존 세 보스 진행과 무기·서약·기록을 보존합니다. 이전 버전의 토벌 시각을 추측해 첫 토벌 날짜를 만들지 않으며, 기억은 업데이트 후 이권재를 토벌하면 획득합니다. 향후 다섯 보스 확장에는 별도 저장 마이그레이션이 필요합니다.

## 검증과 남은 범위

기존 저장 복원, 첫 토벌 기억 지급·중복 방지·저장 복구, 단계별 환경 수치, 기억 확인 후 광대 전환과 보상 연결을 자동 검사했습니다. 실제 브라우저에서 메인 표기, 기존 저장으로 첫 보스 진입, 응시자 HUD와 성소 렌더링을 확인했습니다. 직접 조작으로 2페이즈·토벌까지 클리어한 검증과 네 무기 장기 밸런스 검증은 남아 있습니다.

이번 구현은 이권재 1장과 공통 표기에 한정합니다. 오슬우·박성원의 서사적 처치 장면, 박성원 육체 강탈, 배서준·최규원과 다섯 장·엔딩은 후속 구현입니다. 기존 세 보스 클리어 및 도전 해제 규칙은 유지합니다.
