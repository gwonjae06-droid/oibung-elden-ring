# 최규원 뮤지컬: 원곡 스코어 + 5~11수 무대/모델링 완성도 패스
2026-11-09 · PR #110

## 범위
- 현역~4수의 기존 전투, 5수 이후 플레이어 최소 1HP, 무대의 컷씬 스킵 금지, 8곡 원곡 1배속 무편집은 유지.
- 사용자가 별도 제작하기로 한 마지막 800HP의 영화형 엔딩은 개편하지 않는다.
- 5~11수 실시간 완주를 정규 목표로 하며, 테스트에서 원곡 끝부분을 탐색하는 것은 실제 3분 자연 완주에 대한 증명이 아니다.

## 원곡의 사건·박자 위치
- `src/gyuwon-master-director.mjs`: 이전 편집본에 사용된 원곡 섹션의 출처 시각을 중심으로 공연 세계의 장면을 배치한다. 전체 보컬 구간을 채보한 것은 아님.
- `gyuwonVerifiedMasterAccents()`: 과거 편집본의 분석된 악센트를 원곡 MP3 위치로 되돌려 사용할 수 있는 부분만 매핑한다.
- `gyuwonMasterRhythmNotes()`: 그 밖의 구간에서 잠정적인 낮은 밀도 반주 비트를 표시한다. `source:'guide-grid'`는 정확한 원곡 비트라고 주장하지 않음.
- `scripts/gyuwon-source-score-audit.mjs`: 각 곡의 원곡 구간에 근거한 영·한 자막 커버리지, 매핑된 악센트, 임시 자막 개수를 점검한다.
- `src/gyuwon-caption-overrides.mjs`: 녹음을 대조한 정확한 영어 가사/한국어 번역/구간 시각을 곡별로 추가할 최우선 교정 데이터 구조.
- `src/gyuwon-subtitles.mjs`: 수동 원곡 교정 > 과거 편집본을 거꾸로 대응시킨 출처 구간 > 미검증 극본 기반 임시 표시 순으로 선택한다.
- **미완:** 실제 제공 음원 8곡 전체의 보컬 가사 전사, 구절·박자·후렴/브리지·페이드 아웃의 1:1 수동 검증. 현재 임시 극본 문장은 실제 들리는 가사와 다를 수 있다. 특히 원곡의 인스트루멘탈에서 불필요한 문장이 나오는지 확인 필요.

## 5수: 실제 3D 보스 모델을 무대 파티로
- `src/gyuwon-party-portraits.mjs`는 기존 게임의 Kwon 턱검 보스, Oslu 광대, Sungwon 주사위, Baeseojun의 실제 머리/사진 지오메트리를 재사용하며 각기 다른 모델 실루엣과 공격 몸짓을 가진다.
- `src/gyuwon-turn-stage.mjs`에서 복제한 플레이어 아바타 네 개를 교체한다. 이동/타격 타이밍은 원래 턴제 시뮬레이션 `m.party`, `m.actorMotion`을 따른다.
- 이 파티를 11수 피날레의 네 명 합동 공연에 다시 사용해 이중 메시 로드를 피한다.
- 배서준은 실재 보스 얼굴 메시를 사용하지만 5수 무대용으로 몸·날개를 새롭게 장식한다. 기존 보스 전투 연출/AI는 여전히 독립적이다.

## 6~10수: 각기 다른 2D 세계
- 6수: 꽃밭/폭우 다리/밤/일출의 다른 원경·전경·발판 색과 파라랙스, 위험과 휴식 섹션을 원곡 섹션 위치에 연결.
- 7수: 이권재·오슬우·박성원·배서준·최규원·거대 행진자 콘셉트로 여섯 유닛 실루엣을 다시 그려 기존 비용/사거리/공격 준비와 연결. 과거 보스의 실제 3D 모델을 2D로 촬영한 사진은 아니며 독립적으로 그린 2D 변형이다. 무대의 휴식과 최종 진지는 원곡 섹션에 연결.
- 8수: 댄서의 준비 신호/스포트라이트/완벽 판정 반응과 중반 조용한 브리지, 후반 합동 군무 장식. 박자 교정 가능한 원곡 악센트는 우선 반영, 나머지는 잠정 비트.
- 9수: 세 라운드를 원곡 내 구간에 연결, KO 후 합창/침묵 구간을 거쳐 다음 라운드. 상대의 실제 준비 모션과 공격 접촉 판정 유지.
- 10수: 도심 타일에서 별하늘로 실제 화면 바뀜. 적의 조준 예고는 사격할 때 확정한 방향을 가리키며 탄환 시뮬레이션도 동일 방향을 사용. 최종 거대 캐리어에 전용 외형·후광 및 격파 후 별빛 비행을 추가.

## 11수: 서로 이어지는 3D 뮤지컬
- 0~176초 단일 극장에서 이전 역할/배역의 기억이 서로 이어지도록 변경. 이전 보스 캐릭터들이 기획된 구간에 실제 모델로 입장한다.
- 별·행진/배역 소품이 입장하는 동안 물리 판정 위치에 그림자를 표시하고, 실제 피격 위치까지 이동한다.
- 원곡 장면별로 위험 종류·간격이 달라지며 마지막 큰 후렴에서 합동 장면 연출.
- 단순 리듬 버튼 외에 실제 3D 가까운 거리에서만 점수를 얻는 공격·스킬, 회피 입력을 지원. 이 로컬 점수는 전체 보스 HP의 노래 종료 소유권을 훼손하지 않는다.

## QA와 후속 검수 기준
- CI Fast checks, D-day, Gyuwon nightmare, Gyuwon musical, Four-boss regressions 모두 확인.
- 반드시 직접 확인해야 할 것: 5수의 네 실제 보스 메시 정면/측면 및 라이브 사진 로딩, 장시간 WebGL 성능/프레임, 8수 춤 포즈 및 9수 2D 라운드, 10수 탄/전조 방향, 11수 숨은 공격 판정, 5~11수 20분55초 이상 전체 자연 재생.
- 별도 남은 장기 과제: 원곡 실제 영문 가사 채보·전체 싱크, 3순위 곡별 이어하기와 모바일 최적화, 사용자가 제작할 최종 엔딩.
