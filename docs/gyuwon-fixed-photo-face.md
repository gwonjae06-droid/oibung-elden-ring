# 최규원 얼굴 고정 — 2026-11-09

사용자가 올린 assets/kyu.png를 모든 최규원 얼굴의 원본으로 고정한다. 이전의 얼굴 조형보다 ‘구에 사진을 입힌 얼굴’이라는 이번 사용자 지시를 우선한다.

- 공통 3D 인물은 변형하지 않은 SphereGeometry와 사진 재질만 사용한다. 기존 눈·코·입·턱·귀·별도 머리카락 및 연차별 표정 덧씌우기를 제거한다.
- 모든 n수가 공유하는 본체, 사수→5수 일상 컷씬, 거대 5수 진행자, 11수/종결의 본체, 작은 학생과 기존 신격화·손등 분신도 같은 사진을 사용한다. 체형·복장·행동과 전투 판정은 유지한다.
- 2D 달리기·군대의 규원 유닛·리듬 진행자·격투 상대는 같은 사진을 둥근 얼굴 영역에 넣는다. 2D 장르를 3D로 전환하지 않는다. 방향 전환에도 사진이 거울처럼 뒤집히지 않게 한다. 사람 얼굴이 없는 기체에는 얼굴을 새로 붙이지 않는다.
- 5수의 세계 손그림 효과는 유지하면서 얼굴 사진 영역은 원본 색을 보존한다. 사진 구를 그릴 때 기존 렌더 대상의 알파를 표식으로 사용하므로 추가 전면 화면 렌더링이나 픽셀당 추가 텍스처 조회가 필요하지 않다. 일반 렌더링에서는 불투명 상태로 되돌린다.
- kyu.png는 원본 그대로 사용한다. 기존 choi.png는 다른 기록과 호환성을 위해 저장소에 남겨두되 최규원의 얼굴에는 사용하지 않는다.

기존 인물 검사에서 구의 형태, 동일한 가로·세로·깊이 비율, kyu 원본 연결 및 얼굴 조형 부재를 검사한다. 관련 검사 27개가 통과했고 전체 2,186개 중 2,156개 통과, 기존과 동일한 30개 실패로 새 실패가 없다. 실제 브라우저에서 58초 컷씬의 얼굴 근접 구도, 손그림 5수와 2D 미니게임을 확인했다. 일시정지·재개와 여섯 장르의 기존 조작 검사도 통과했다. 실제 휴대전화 성능은 별도로 측정하지 않았다.
