## 연결과 판정

기존 3초 채점 장면 안에서 이전 전장이 내려앉고 다음 전장이 솟아오른다. 별도의 대기·무적 장면이나 건너뛰기 기능을 추가하지 않는다. 처음 시작하거나 재도전하면 파괴 기록을 초기화한다.

공유 원형 전장과 이동 제한은 유지한다. 배경 학교·책장·매장·파편은 전장 바깥에 두며 새로운 보이지 않는 장애물을 만들지 않는다. 사수의 엄폐와 오수의 독·해일, 팔수의 공격 촉수는 기존 실제 판정이 담당한다.

OMR 바닥의 경첩 위치·폭·길이·각도는 시뮬레이션과 렌더러가 같은 값을 읽는다. 발 위치의 지면 높이를 구해 플레이어와 보스를 받치고, 높은 바닥 가장자리로 갑자기 올라가는 이동은 막는다. 내려오는 바닥에서 떨어질 때는 중력을 적용한다. 플레이어의 근접·발사 높이, 보스의 피격 부위와 카메라도 그 높이를 반영한다. 충돌 피해는 바닥이 원위치에 닿는 시각에 두 실제 판정으로 발생하며, 중앙 통로가 남는다. 12수 이후 주변 세계가 회전해도 이 바닥의 방향은 판정과 일치하도록 고정한다.

9수는 선택된 원본 맵 전체와 파편이 등장한다. 10수는 네 원본 구조물을 동시에 보여주기 위해 단일 원본 맵 전체 표시를 끄고 네 실제 모델의 파편을 함께 사용한다. 11수는 원본 기억 맵을 숨기고 마지막 시험장만 남긴다. 공격 기억과 황금 입자는 유지한다.

## 자원과 카메라

건축 키트·재질·지형을 재사용하고 책·책상·창문은 인스턴싱한다. 작은 먼 소품에 보이지 않는 곡면을 과도하게 그리지 않도록 크기별 메시를 사용한다. 원본 전장 파편은 원본 지오메트리·재질을 공유한다. 전환 중 새 맵 생성이나 대량 자원 폐기를 하지 않는다.

전투 시작 전 11개 전장을 점진적으로 준비한다. 실제 화면의 색 공간·톤 매핑 조건에서 먼저 컴파일하고, 작은 오프스크린 화면에서는 버퍼를 업로드한다. 원본 기억 맵과 카메라 투명 처리의 조명 조합도 함께 준비한다. 작은 묶음으로 셰이더·버퍼를 준비하고, 현재 카메라 밖의 물체도 업로드해 처음 보일 때의 작업을 줄인다. 기억 맵의 조명 조건에서도 건축 재질을 준비한다. 가까운 캐릭터 등신대가 플레이어를 가리면 해당 일러스트만 옅게 표시한다. 전장 안쪽의 카메라에는 불필요한 투명 처리 셰이더를 사용하지 않고, 외곽에서 구조물이 시선을 가릴 수 있을 때 가시성 통로를 적용한다.

## 확인 범위

- 연차별 건축 차이와 캐시 재사용, 채점 전환, 제단 파괴·재도전 복구, 12수 융합의 안정성, OMR 바닥 높이·가장자리·충돌·발사 높이, 원본 파편의 자원 공유를 회귀 검사한다.
- 실제 전투 브라우저에서 1~13수 화면, 전장 변형, 제단 붕괴, 하수도 해일, 접히는 바닥, 일시정지·종료를 검사한다. 터치 가로 화면도 별도로 검사한다.
- 비교 기준은 변경 전 `72d512a`, Windows Edge, 1280×800, SwiftShader 소프트웨어 렌더러다. 18프레임 표본은 짧은 참고 측정이며 실제 GPU/휴대전화의 FPS 증거로 해석하지 않는다.
- 로컬 관련 검사 147개가 통과했다. 전장 화면 검사는 PC와 터치 브라우저에서 1~13수를 확인한다.
- 상세 수치는 `qa-output/gyuwon-worlds/before/report.json`, `after/report.json`, `touch/report.json`에 생성된다. 맵별 드로콜·삼각형·프레임 시간·준비 시간을 함께 기록한다. 소프트웨어 렌더러의 전환 지연은 남아 있으므로 '렉 완전 해결'이나 실기기 60/30FPS 달성으로 표시하지 않는다.

다음 표는 최종 색 변환 준비 보완 전의 전체 전장 검사 표본이다. 초기 새 서가의 846,682개 삼각형은 작은 소품의 LOD를 적용해 145,082개로 줄었다. PC 참고 측정은 다음과 같다. 자동 렌더 해상도 조절이 활성화되어 있으므로 아래 프레임 시간은 고정 해상도 GPU 벤치마크로 비교하지 않는다.

새 연차 전장 준비는 별도 약 1.06초, 최장 준비 단위 약 41ms로 측정됐다. 기존 기억 맵 준비는 약 4.19초였다. 구수 첫 전환에는 약 689ms의 프레임이 관측되어 변경 전 약 494ms보다 길었다. 이 부분은 해결됐다고 하지 않는다. 실제 화면과 다른 오프스크린 톤 매핑 조건에서만 컴파일하던 문제를 보완했다. 이후 현역·구수 재검사에서 오류는 없었지만 구수 첫 전환은 약 900ms로 남았으며, 18프레임 평균은 약 174ms였다. 해당 재검사의 준비 시간은 기존 기억 맵 약 8.35초, 새 연차 전장 약 1.79초였다. 환경 변동과 짧은 표본을 고려하면 성능 개선을 확인했다고 볼 수 없다. GPU 추적은 실시하지 않았다.

- 전체 검사 2,055개 중 2,026개 통과, 29개 실패다. 남은 29개 실패는 변경 전과 이름을 대조해 새 실패가 없음을 확인했다. 이번 기능의 회귀 검사와 기존 다른 보스·오디오의 실패를 구분한다.

참고 이미지를 게임 이미지로 가져오지 않고 저장소의 모델과 코드로 전장을 구성했다. 추가 외부 이미지·음원 다운로드는 없다.
