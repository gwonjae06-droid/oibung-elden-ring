# 최규원 — 끝나지 않는 수능 개편 기록

## 전투에 반영한 변경

- 현역부터 11수까지 기존 일반기와 연차별 필살기를 유지한다. 매년 필살기를 마치기 전 시험으로 넘어가지 않으며, 11수의 마지막 답안 공격이 끝나야 최종 처치가 가능하다.
- 연차마다 최대 체력의 6.5%를 기본 피해 구간으로 배정한다. 초과 피해 중 최대 체력의 3.25%까지 다음 연차에 한 번 이월하고, 계속 공격한 압력은 달력을 최대 2.2배까지 빠르게 진행한다. 생존만 해도 달력은 진행한다.
- 기본 달력은 48초, 시험은 5과목 각 1.8초, 결과 장면은 3초다. 피해를 받지 않는 고정 대기 컷씬을 새로 추가하지 않았다. 결과 체력 후보는 +5%, +2%, -4%로 적용하되 조기 처치를 막는 연차별 잔여 체력을 지킨다.
- 3~4수의 빠른 표시, 5~6수의 불안정한 표시, 7~8수의 겹친 숫자, 9~10수의 과거 연도, 11수의 D-365 정지 후 감소를 표시한다. 표시 왜곡과 실제 판정 시계는 분리한다.
- 기억 전장 시간은 공격 중에도 누적한다. 교체가 예약되면 실제 공격 종료 후 원본 네 보스 맵 중 다음 전장으로 교체한다. 셔플된 순서를 사용한다.
- 국어·수학·영어·한국사의 기존 근거리 공격에 보스에서 출발해 원거리 플레이어까지 비행하는 투사체를 더했다. 과목이 바뀌어도 비행 중인 투사체는 유지한다. 탐구의 세 강화는 유지한다.
- 차량은 기존 공용 이동 경로와 판정을 유지한다. 문제집이 착지하면 펼쳐지며 별도의 전조 뒤 종이 파동을 만든다. 글자는 문장을 이루며 모인 뒤 발사된다. 네 거대 교과서 도미노는 유지한다.
- 사수 필살기에 총탄을 실제로 막고 무너지는 엄폐물 세 개를 배치한다. 일반 교차 사격은 소총 연사 후 활로 전환하며, 활의 분산 방향은 셔플한다.
- 오물 착탄 뒤 보이는 독 웅덩이가 남아 초당 피해를 준다. 웅덩이는 최대 12개, 수명 7초다. 일반 해일의 접근 방향을 바꾸고, 필살기의 여덟 파도는 속도·높이·도착 시점이 다르다.
- 육수 수집품은 외모·의상·역할이 다른 성인 캐릭터 일러스트 여섯 장으로 교체했다. 이미지 로드를 전투 시작 전에 기다린다. 여섯 제단은 속사·확산파·느린 대형탄·반대 방향 발사·글자·먹물로 나뉘며, 파괴된 제단의 공격이 사라진다. 전부 파괴하면 3초 그로기다.
- 칠수 가챠는 대형 낙하 후 폭발, 순차 소형 낙하, 본체 돌진, 왕복 투사체, 연속 충격파, 연쇄 낙하/폭발로 분화했다. 룰렛이 멈춘 이후 피해가 시작되며 결과별 공격 수명까지 시전을 유지한다.
- 팔수의 여덟 연속 표면 촉수와 공용 각도 판정을 유지한다. 곡선과 샘플 벡터를 재사용해 프레임마다 생기던 임시 객체를 줄였다.
- 기억 합성에서 주사위의 충격이 관객 진행 방향을 바꾸고, 무대가 주사위의 낙하 경로를 비튼다. 검격 이후 해일의 실제 통로 위치가 검이 자른 위치로 이동한다. 거대 검의 표시 길이와 판정 길이를 맞췄다.
- 기억 공격과 전장 재현에 황금색 입자를 사용한다. 별도의 피해 판정은 만들지 않는다.
- 십일수 몸에 차량·책·총·수집품·촉수의 흔적을 더했다. 열 분신은 각 연차의 소품을 지닌 채 기존 순차 공격을 수행한다. 기존 연타·화염 뒤에 양면 OMR 기록이 있는 거대 입체 답안지가 접히며 무너진다. 전체 필살기는 23.5초이며 이후 5.5초 반격 구간을 둔다.
- 12수 이후에는 공간 배치와 기억 조합을 바꾸며 공격력의 무한 배율을 추가하지 않는다. 붕괴 잔해는 기존처럼 전장 바깥의 비충돌 장식이다.

## 로딩과 자원

원본 전장 네 개를 미리 만들고, 메시를 16개씩 나눠 준비한다. 준비 중에는 전투 시간을 멈추고 로딩 화면을 표시한다. 전장 교체는 이미 준비한 루트의 가시성을 바꾼다. 비행 소품 풀은 최대 48개이며, 해일의 두 입체 메시도 재사용한다. 종료 중 로딩이 완료되더라도 폐기된 장면을 다시 건드리지 않는다.

Windows Edge / 1280×800 / SwiftShader에서 초기 동기 전장 준비는 한 덩어리 약 1,217ms였다. 변경 후 측정은 91개 준비 단위로 분리되어 최장 단위 약 372~537ms, 전체 준비 약 3.6~3.7초였다. 연속 화면 표시를 유지하는 대신 총 준비 시간이 길어지는 절충이다. OMR 문양을 입체 도넛 대신 종이에 인쇄된 인스턴스 문양으로 바꿔 동일 시점의 삼각형 수는 347,318개에서 85,526개로 줄었다. 실제 GPU의 60FPS나 실기기 모바일의 30FPS 달성 증거는 아니다. 소프트웨어 렌더러에서 카지노가 444 드로콜로 가장 무거웠으며, 전장 교체 시 수백 ms 프레임이 여전히 관측된다.

## 검증과 해석 범위

- 네 무기의 실제 공격·탄창·기력 처리로 현역부터 11수 필살기까지 진행을 검사한다. 생존/이동은 테스트에서 보조하므로 사람이 네 무기로 완주한 결과와는 구분한다.
- 네 무기 모두 실제 공격으로 여섯 제단을 파괴하고 그로기를 얻는 회귀 검사를 포함한다.
- 무제한 피해를 주어도 11수 최종 공격 전에 처치할 수 없는지, 이월 피해 중복, 전장 전환 시점, 원거리 시험탄, 엄폐 파괴, 독 웅덩이, 여섯 가챠, OMR 낙하와 자원 해제를 검사한다.
- 고정 DPS 150/60/30, 무적 테스트 플레이어와 보통 결과를 사용한 모의 전투는 약 444/492/584초였다. 낮은 DPS에서는 12수로 넘어간다. 실전 평균 클리어 시간으로 확정한 수치가 아니다.
- 37개 공격을 브라우저에서 세 차례 반복하고, 반복 후 그래픽 자원 수가 안정적인지 검사한다. 실제 전투에서 네 원본 맵 표시, 일시정지, 가로 화면, 재도전, 종료를 확인한다. 터치가 활성화된 브라우저에서도 재도전 후 공격·회피 입력과 기력 소비를 확인했다.
- 관련 회귀 검사 127개는 모두 통과했다. 전체 검사는 2,035개 중 2,006개 통과, 29개 실패다. 저장소 전체 검사에서 남은 29개 실패 이름은 변경 전 `db208f0`에서도 재현됨을 확인했다. 기존 다른 보스의 패턴 수/오디오 기대값/판정 관련 실패까지 모두 통과했다고 주장하지 않는다.

## 남은 외부 제작과 품질 확인

전용 오케스트라 음원은 아직 없다. 연결된 Runway 음악 생성이 `paid_plan_required`로 중단됐다. 연차별 여섯 구간을 읽는 음악 연결부와 시험 감쇠 상태를 준비했으며, 없는 파일을 요청하거나 전자음 대체 음악을 재생하지 않는다. 실제 여섯 음원·결과 변주·최종곡 편집과 청음 검증은 음원 확보 후 남은 작업이다.

실제 GPU PC와 모바일 기기의 장시간 성능, 사람이 회피하며 플레이한 네 무기 완주, 촉수 사이 고정·견인 같은 추가 연계 모션과 최종 아트 디테일은 별도의 품질 확인/후속 제작 범위다. 이번 구현을 완전한 포토리얼리즘이나 실기기 성능 목표 달성으로 표시하지 않는다.
