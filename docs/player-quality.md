# 서약의 수호자 플레이어

2026-11-05. 기존 파란 의상과 붉은 망토를 유지하며 플레이어 전체를 직접 설계한 기사형 모델로 교체한다. 전투 판정, 피해량, 이동 속도, 기력, 공격 시간과 회피 무적 시간은 바꾸지 않는다.

## 모델과 무기

- 몸에 맞는 흉갑·허리 겹판, 투구의 눈구멍과 통풍구, 어깨·팔·무릎·정강이 갑옷, 금속 장식, 허리 가방·물약병·칼집을 제작했다.
- 손목은 팔꿈치에 연결되고, 구부린 손가락과 좌우 엄지가 실제 무기 손잡이를 감싼다.
- 검은 마름모 단면의 테이퍼 날·홈·구부러진 가드·감은 손잡이, 망치는 모서리를 깎은 타격면·금속 띠·보석, 활은 리커브 팔다리·변형 시위·시위에 걸린 화살, 카드는 테두리와 문양을 가진 부채 형태로 만든다.
- 금속·천·가죽·목재는 재질별 64×64 표면 맵을 공유한다. 망토는 연속된 20×18 천 격자이며 가장자리와 서약 문양을 색으로 짜 넣었다.
- 모든 새 형상은 직접 작성한 단면과 다각형으로 만든 BufferGeometry다. 외부 모델·모션·텍스처를 사용하지 않는다.

## 동작

- 네 전장 모두 공통 플레이어 표현 계층을 사용한다. 무기별 대기, 앞/뒤/옆 이동, 준비·공격·복귀, 차징, 회피, 물약, 피격과 쓰러짐을 처리한다.
- 검은 세 가지 시각적 베기·찌르기를 순환한다. 판정과 공격 종류는 기존 공격 그대로다.
- 망치는 양손으로 들고 준비·내려치기·복귀에 체중을 싣는다. 두 관절 IK로 보조 손을 자루에 고정한다.
- 활은 왼손으로 들며 오른손이 시위를 당기고 놓는다. 무기와 두 손의 위치를 같은 관절 좌표로 맞춘다.
- 회피는 몸의 무게중심을 기준으로 웅크려 회전한다. 이동·공격 자세에서는 발바닥 기준점으로 몸 높이를 맞춰 바닥에 발을 붙인다.
- 천은 이동과 몸통 회전에 따라 변형되고, 같은 시간이 반복되는 일시정지 화면에서는 정점과 노멀을 다시 갱신하지 않는다.

## 이펙트와 성능 예산

- 검·망치 궤적은 무기 끝의 얇고 짧은 리본이다. 타격 조각은 실제 적중 이벤트에서만 나오고, 배경 입자나 동적 조명은 추가하지 않는다.
- 회피 먼지·발걸음, 활 발사, 카드 버프와 회복은 짧은 전용 반응을 사용한다.
- 날아가는 화살·카드·진화 파동도 공통 제작 모델을 사용하며 재도전 시 재사용한다.
- 플레이어와 네 무기를 전부 합쳐 약 6,332 삼각형, 상한 10,000. 사용하지 않는 무기는 그리지 않는다.
- 타격 조각은 PC 80개/터치 40개/동작 줄이기 20개, 검 궤적 14개 표본 이내, 발사체 표시 128개 이내다. 발사체 한 개는 재질 색을 합쳐 한 번만 그린다.
- 효과가 없는 대기 상태에서는 접촉 조각과 리본을 그리지 않는다. 기존 카메라 투명 처리·고정 화면·가려진 전장 그리기 중단을 유지한다.

## 검증

관절 연결과 기하 예산, 공격 끝의 대기 자세 복귀, 유효 공격 구간의 궤적, 망치 양손 및 활 시위 접촉, 게임 상태 불변, 반복 공격·재도전의 자원 수와 해제를 검사한다. player-quality-smoke.mjs는 네 무기의 대기·준비·공격, 망토 뒤, 회피·회복·발사체와 실제 네 보스전과 모바일 가로 화면을 WebGL에서 확인한다.
