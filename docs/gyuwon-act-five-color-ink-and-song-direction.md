# 5수 색연필 낙서 무대와 원곡 대사 연출 — 2026-11-09

## 화면 가독성

기존 합성은 모든 모델의 색에 밝은 종이색을 32% 섞은 뒤 다시 13%의 종이색을 더해 어두운 의상과 배경까지 회백색으로 만들었다. 이번에는 종이색 가산을 0.8%로 낮추고 원래 색의 채도와 명암을 보존한다. 8단계 물감 면을 원본 색과 약하게 섞으며 기존 A/B 윤곽선은 초당 8회 유지한다. 정적인 종이 결도 훨씬 약하게 남긴다. 전면 흰 안개나 깜빡이는 잡음은 사용하지 않는다.

남색 연미복, 붉은 커튼, 황갈색 나무 바닥과 동료들의 기존 재질을 구분한다. 실제 장면 안개 밀도도 0.0025에서 0.0006으로 낮췄다. 무대 전면광과 테두리광을 추가하고 5수 안에서만 동료 모델을 1.25배로 보여 준다. 5수를 나가면 크기를 되돌린다. kyu.png의 구 얼굴은 계속 원본 색으로 유지한다.

## 낙서 UI

대상 선택, 행동 순서, 부위 HP·강인도, 네 동료의 HP·에너지·필살기, 공유 포인트, 일반 공격·전투 스킬·지원, 곡/전체 공연 진행도, 자막과 일시정지를 기존 HTML 제어 그대로 사용한다. 테두리를 두 번 그린 듯한 불규칙 선, 종이색 바탕, 색연필 막대, 잉크 강조로 외형만 바꾼다. 장식 선은 포인터를 가로채지 않는다. 준비되지 않은 능력의 비활성 상태와 키보드 포커스 표시도 남긴다.

자막은 동료 위를 가리지 않도록 높이고 손의 대상 표시는 자막과 간격을 둔다. 작은 화면에서 진행도와 제목의 가로 영역을 분리한다. 5수 범위를 나타내는 속성이 꺼지면 모든 스타일도 꺼지므로 6수 이후의 UI는 기존 형태를 유지한다. 전투 패턴 해설 텍스트나 스킵은 추가하지 않는다.

## 대사와 행동·공격

32개 구절의 시작·끝을 기존 원곡 정렬 자막에서 직접 가져온다. 별도의 축약 음원 시간표를 만들거나 음악을 편집하지 않는다. 실제 audio.currentTime을 읽는 m.time으로 행동·소품과 현재 구간의 공격 종류를 결정한다. 입장 중의 첫 인사도 연기하되 전투 조작을 여는 시점은 유지한다.

공격은 기존 턴 흐름을 유지하면서 그 차례가 시작되는 대사 구간에 맞춰 고른다. 손 뻗기·옆으로 휩쓸기·높이 들고 내려치기·박자 동작·추격 궤적, 황금 고리·별과 3방향 투사체를 사용한다. 대사가 바뀌어도 이미 시작한 공격의 준비→이동→접촉→회복을 끝낸다. 범위 공격은 각각의 실제 공격체가 목표 위치에 도착해야 한 번씩 피해를 준다. 장식용 문·왕관·길·별은 피해 구역이 아니다.

공격 전조는 최소 1.35초이며 대사 순간에 즉시 피해를 주지 않는다. 손의 부위 좌표는 연출과 동일한 시뮬레이션 좌표이고 상체를 기울여도 어깨와 팔을 연결한다. 공격 중 부위 이동, 부위 영구 파괴, 약점·속박·회복·1HP 보호, 원곡 종료 후 6,000→5,300HP와 6수 전환을 유지한다.

## 검증과 범위

- 관련 검사 97개 통과. 새 검사 6개: 32개 원곡 구절의 시간, 입장 인사, 모든 패턴의 준비와 정확한 접촉점, 3방향 공격의 한 번 판정, 웃음 구간의 반격 기회, 오디오가 멈췄을 때 포즈와 공격체 정지.
- 최신 main의 11수 커튼콜 변경을 보존해 합친 전체 2,197개 중 2,167개 통과, 기존과 동일한 30개 실패. 새 실패가 없다. 기존 반복 피격 검사는 고정 2.15초 대신 실제 선택된 공격의 접촉 시각까지 진행하도록 바꿨다.
- 원곡 5수 전체를 배속·탐색 없이 재생하며 실제 UI로 전투했다. 다섯 부위 파괴, 네 동료 능력, 1HP 보호, 원곡 후주와 정확한 6수 전환을 확인했다.
- 별도 장면 검사에서 15개 대사 구간의 실제 화면, 색감·사진 얼굴·소품·낙서 UI와 일시정지·대상 선택·스킬을 확인했다. 844×390 화면의 터치 대상 선택과 버튼 범위도 확인했다. 이 장면 검사는 음악 탐색을 사용하며 위의 전곡 자연 재생 검사와 구분한다.
- 관측 성능: 자동 브라우저 1280×800, 터치 품질의 15개 대사 표본에서 세계 렌더링 467~501 draw call / 77,228~81,760개 삼각형이었다. 같은 표본의 최근 프레임 간격 중앙값은 8.3ms, p95는 9.1~11.0ms였다. 이는 자동 검사 환경의 관측값으로 기기별 GPU 실행 시간이나 실기기 FPS 보장은 아니다. 합성 후 마지막 사각형만 세던 진단에 세계 렌더링 수치를 따로 추가해 앞으로 비교할 수 있게 했다.
- 화면 전체 효과는 기존과 같은 2회 렌더링 / 출력 픽셀당 3회 텍스처 조회를 유지한다. 별은 24/48개 인스턴스, 동시 보스 공격체는 최대 3개로 제한하고 소품은 재사용한다. 실제 휴대전화의 발열·FPS와 GPU 시간은 미측정이다.
