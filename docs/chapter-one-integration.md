# 통합 기획안 1단계 적용

범위: 기존 3보스의 전장과 서약의 기억. 사용자 제공 원문은 game-design-v1.md에 보관했습니다. 항상 첫 보스부터 시작하며, 현재 무기의 2중 택1 진화 보상과 사슬 전환을 유지합니다.

| 장 | 이번 적용 | 함께 유지한 기존 연출 |
|---|---|---|
| 이권재 | 오래된 대리석, 성소 뒤편의 공명 대검과 부러진 검, 순차적으로 쓰러지는 검, 달빛 강도 복구, 멈추는 먼지와 안개 | 2페이즈 금빛 균열·석상 머리 붕괴·검의 현현·처치 카메라 |
| 오슬우 | 얼굴 없는 인형의 박수, 일부 정지한 관객, 2페이즈 직후 잠깐 멈추는 박수, 붉은 추적광과 벌어지는 커튼, 처치 후 순차적으로 내려가는 손과 소등 | 중앙 무대·천막·머리의 공 변신·처치 동작·기존 효과음과 MP3 |
| 박성원 | 주사위를 향하는 손님의 시선, 2페이즈의 손 반응과 불길한 조명, 샹들리에의 결정 장식, 처치 후 움직임 정지·조명 감쇠 | 룰렛 탁자·격자·사진 약점·거대한 관객·기존 MP3 |

## 이야기와 기록

- 세 보스 모두 그림·짧은 이야기·서약 주제를 가진 기억을 얻습니다.
- 첫 두 보스는 처치 연출 → 기억 → 무기 진화 선택 → 다음 도전 → 사슬 → 다음 보스 등장 순서입니다.
- 박성원은 처치 연출 → 기억 → 세 지배자 완수 기록 순서입니다. 추가 진화는 주지 않습니다.
- 기억과 첫 토벌 날짜는 승리를 확인하는 시점에 저장합니다. 기억 화면에서 메인으로 나가거나 재접속해도 남습니다.
- 첫 토벌 날짜는 반복 토벌로 덮어쓰지 않습니다. 예전 기록의 날짜가 불명확하면 ‘이전 기록’으로 표시합니다.
- 기존 버전 1·2 저장의 클리어·시간·토벌 기록을 보존하며, 진행 중 여정은 복구하지 않습니다.

## 검증과 한계

전체 자동 테스트 814개 통과. 실제 컨트롤러를 사용하는 별도 브라우저 검증에서 세 승리를 강제로 발생시켜 기억 → 보상 → 다음 도전 → 최종 기억 → 기록실 흐름을 확인했습니다. 별도 전장 검증에서 정상·붕괴·침묵을 전환해 확인했습니다. 이는 세 보스를 자연 플레이로 연속 격파한 검증을 뜻하지 않습니다. 실기기 모바일 성능·새 음원 제작은 이번 검증에 포함하지 않았습니다.

장식은 기존 전투 구역 밖에 배치하며 충돌 판정과 패턴은 유지합니다. 정상·2페이즈의 경과는 게임 시간, 처치 후 감쇠는 일시정지를 반영하는 시각 시간으로 처리합니다. 입자·관객은 수량을 제한하고 인스턴싱을 사용합니다.

## 후속 단계

박성원 머리 강탈·거인 손 전투는 기획안 2단계입니다. 배서준·최규원, 5보스 전체 여정과 엔딩은 이후 단계이며 이번에 구현한 것으로 표시하지 않습니다. 기존 3보스 완수 화면도 최종 엔딩과 구분해 유지합니다.
