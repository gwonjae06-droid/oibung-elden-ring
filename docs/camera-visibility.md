# 전장 전체의 카메라 가림 처리

2026-11-05. 뒤로 이동하거나 시점을 돌릴 때 카메라가 외곽 벽·천막·기둥·성당·카지노 관객 안으로 들어가 플레이어를 가리는 문제를 수정한다.

## 적용 범위

- 이권재: 검의 성소와 외곽 폐허, 기사상·기둥.
- 오슬우: 커튼·아치·천막·관객. 카메라가 서커스 안에 있을 때도 검사한다.
- 박성원: 룰렛 탁자의 장식과 카지노 손님. 기존 거인 팔 가림 처리는 유지한다.
- 배서준: 실제 흰 대성당의 벽·기둥·스테인드글라스. 비어 있던 기존 가림 목록 대신 성당 구조물 전체를 대상으로 한다.

## 동작

`camera-visibility.mjs`가 렌더 직전에 카메라에서 전투 대상까지 여러 시선을 검사한다. 몸 중심 한 점뿐 아니라 주변과 카메라 근접면을 함께 보호하며, 양면 교차 검사로 카메라가 이미 벽 안에 있는 경우도 처리한다.

가리는 일반 메시만 이번 화면에서 숨기고 렌더 직후 원래 상태로 돌린다. 여러 구조물을 한 번에 그리는 `InstancedMesh`는 가리는 기둥·커튼 조각의 행렬만 임시로 축소한다. 배치 전체를 지우지 않으며, 화면을 그린 뒤 정확한 원래 행렬로 복구한다. 따라서 다음 프레임의 관객 동작·성당 애니메이션과 충돌하지 않는다.

공유 재질의 투명도는 변경하지 않는다. 스테인드글라스처럼 진한 투명 재질도 처리하고, 낮은 농도의 안개·빛줄기·입자는 제외한다. 보스·플레이어·공격 이펙트는 맵 루트 밖에 두어 유지한다. 전투 충돌, 피해 판정, 이동 범위와 카메라 조작은 바꾸지 않는다.

이전 렌더 콜백을 보존하고, 재도전·종료·초기화 실패 시 남은 임시 상태와 콜백을 정리한다. 렌더가 도중에 실패한 경우에도 다음 검사 또는 `dispose()`에서 원상 복구한다.

## 검증

- 벽 안쪽에서 시작하는 카메라, 가까운 기둥, 진한 유리, 공유 재질 보존, 보스 제외, 인스턴스 개별 처리·애니메이션 행렬 복구, 중단·종료와 기존 콜백 연결을 Node에서 검사한다.
- 실제 흰 대성당의 양쪽 벽을 통과하는 카메라도 검사한다.
- `scripts/camera-visibility-smoke.cjs`는 네 실제 맵을 Edge WebGL에서 만들고 **8방향씩 총 32개 위치**에서 검사한다. 수정 전 실제 구조물이 대상 픽셀을 가리는 사례를 확인하고, 가림 처리 후 대상이 드러나는지 픽셀로 확인한다. 렌더 뒤 모든 인스턴스 행렬이 원래 값과 일치하는지도 검사한다.
- 실제 휴대폰의 프레임과 모든 줌·시점 조합에서의 장기 플레이는 별도 확인 범위다.
