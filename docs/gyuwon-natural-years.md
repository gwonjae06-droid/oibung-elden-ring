# 최규원 — 연차별 전투와 자연스러운 접촉 연결

기준: `main`의 `6dedfee58cad767ee6c3caa386bacbe77aec64d2`. 첨부된 연차별 수정안을 현재 게임의 전조·컷씬·전투 규칙에 맞춰 반영한다. 과거 철학 패턴은 호환용 엔진에만 남겨 둔다.

## 전투 규칙

- D-365 카운트다운은 30초, 시험은 5과목 × 1.8초, 결과 연출은 3초다. 이미 시작한 공격과 회복은 끝낸 뒤 시험에 들어가므로 실제 시험 시작은 30초보다 늦을 수 있다.
- 시험 중 받는 피해 50% 감소를 유지한다. 결과는 대성공 30%(최대 체력 10% 회복), 평타 40%(5% 회복), 폭망 30%(5% 감소)다.
- 탐구는 공격력 25% 증가 5초, 최대 체력 1% 회복, 이동 강화 3초 중 하나다. 시간제 강화는 다음 전투 시간에 소모된다. 기존의 탐구 피해 파동을 없앤다.
- 11수 다음에도 실제 연차를 올리며 `n수`로 표시한다. 매년 서명이 초기화되어 D-365 악몽을 다시 사용한다. 세계 붕괴는 치른 시험 수와 실패 누적에 따라 강해진다.
- 일반 패턴 26종과 연차별 필살기 11종을 유지한다. 시험 5과목 중 탐구는 강화 기믹이며 숨은 피해를 주지 않는다.

## 변경한 공격과 리깅

| 킥보드 | 제동·방향 전환을 끼운 좌우 5연속 질주와 마지막 파동. 경로 전환 때 방향을 보간한다. |
| 3수 필살기 | 거대 교과서 4권이 서서 천천히 기울어진 뒤 바닥을 강타한다. 기존 도구 호환 때문에 ID `ultimateSmoke`만 유지한다. |
| 4수 | 총·활을 동시에 표시하지 않는다. 연결된 어깨–팔꿈치–손목의 두 관절 IK로 총과 활을 쥔다. 총구와 판정 광선은 같은 소켓을 쓰며 활시위는 실제 당기는 손을 따라간다. 화살마다 재장전한다. 집중 포격은 맵 끝까지 향하는 부채꼴 소총 연사다. |
| 5수 | 사과 껍질·심, 생선 뼈, 묶은 쓰레기봉투를 오물에 넣고 투척 궤적을 적용한다. 필살기는 폭격 5회 → 서로 간격이 있는 8방향 해일 → 최종 폭발이다. |
| 6수 | 2D 피규어 일러스트를 유지한다. 체력 42의 제단 6개를 반경 5m에 배치하고 18.8초간 유지한다. 각 제단이 포토카드를 발사하며 파괴된 제단의 공격은 취소된다. 전부 파괴하면 남은 공격을 취소하고 3초간 그로기다. |
| 7수 | 체중 이동과 교대 발동작을 연결한다. 실제 피해 파동은 하나의 연속된 입체 물결이다. 후원 결과는 전투의 시드 난수를 쓰며 여섯 결과를 섞어 선택한다. |
| 8수 | 촉수의 마지막 부분을 바닥까지 내린다. 휩쓸기는 시각과 판정이 같은 각도로 돌아가며, 판정 폭은 가늘어지는 촉수 굵기를 따른다. |
| 기억 공격 | 거대 검, 외곽에서 오는 구체 3개와 달려오는 관객, 주사위 낙하, 실제 빈 통로가 있는 해일을 사용한다. 공격 진행 중에는 기억 전장을 바꾸지 않는다. |
| D-365 | 교과서가 세 번째 공격으로 등장한다. 탈것은 뒤의 공격 전 원점으로 돌아온다. 11개 공격은 순차적으로 진행되고 마지막 화염은 반경 25m 이상으로 퍼진다. |

## 시각적 정리와 자원

연차 모드에서는 기존의 판정 주변 돌조각, 필살기 궤도 고리·구체, 가챠 장식 입자, 피규어 주위 별, 제단 후광을 렌더링하지 않는다. 연기, 실제 화염, 파동, 투사체, 피규어, 무기와 전장 자체가 전조를 전달한다. 설명 팝업이나 컷씬 건너뛰기 경로를 추가하지 않는다.

공격 전용 메시와 연기 재질은 공격이 끝나면 해제한다. 반복 렌더링의 geometry 수를 확인하여 연차가 계속될 때 공격 메시가 쌓이지 않도록 검사한다. 기존 PBR 인물과 가변 디테일 체계를 사용하며, 전체 인물을 새 실사 모델로 교체한 작업은 아니다.

## 검증과 한계

- 새 회귀 검사 11건 통과: 시간·확률 경계, n수 반복, 이동 경로 일치, 교과서 접촉, 실제 총구 방향·위치, 무기 배타성·재장전, 제단 그로기, 탐구 효과, 촉수 각도, 악몽 순서, 9수 이후 머리 판정.
- 최규원 검사 94건 중 93건 통과. 남은 1건은 기존 `gyuwon-spectacle-resource.test.mjs`의 spotlight 해제 검사로 변경 전부터 실패한다. 기존 pooling 계약과 테스트 기대가 다른 문제다.
- 전체 검사: 수정 전 2,009건 중 1,979 통과·30 실패, 수정 후 2,020건 중 1,990 통과·동일한 30 실패. 새 실패가 없다.
- `scripts/gyuwon-natural-smoke.cjs`: 37종의 준비·접촉·회복 렌더링, 3회 반복 자원 검사와 전투 세션 시작·일시정지·종료 로직을 확인했다. 해당 실행의 브라우저 오류는 0건, 반복 후 geometry 수는 249 → 249 → 249였다. 1280×800 및 844×390 실제 UI 캡처에서는 메인 메뉴가 전투를 가리는 검증 흐름 문제를 발견했다. 스크립트에 메뉴 종료와 최상단 모달 검사를 추가했으나, 재실행 도구가 응답하지 않아 실제 전투 PC·모바일 캡처는 미검증으로 남긴다.
- 캡처 13장면의 공격 전용 검증 씬은 111~184 draw call, 약 6.8만~8.9만 삼각형이었다. 실제 전투 시작 장면은 162 draw call, 152,834 삼각형이다. 이 수치는 카메라와 장면에 따라 달라진다.
- Windows Edge의 SwiftShader 소프트웨어 렌더링에서 확인했다. 실제 전투 시작 시 기존 4개 기억 맵의 동기 shader compile/pre-render가 포함된 긴 프레임(약 23초)을 관찰했다. 이는 정상 GPU에서의 FPS 측정이 아니며, GPU 프로파일·물리 휴대기기 성능·전 패턴 수동 무피격 공략은 미검증이다. 시작 부분의 프레임 수치로 안정적인 플레이 FPS를 주장하지 않는다.

스크린샷과 전체 수치는 로컬 `qa-output/gyuwon-natural/`에 저장한다. 검증 스크립트는 `PLAYWRIGHT_PATH`(선택), `EDGE_PATH`(선택)를 지원한다.
