# 오든링 네 보스 환경 전조 리워크

모든 실제 피해 판정은 기존 시뮬레이션 데이터에서 계산한다. 바닥에 위험 범위의 정확한 원, 직사각형, 부채꼴을 그리지 않는다.

- 이권재: 보통 검격의 오버레이를 삭제한다. 강타·도약·지축 강타는 작은 돌먼지 파문을 보스의 바닥 동작과 연결한다.
- 오슬우: 일반 공격 및 곡예 돌진은 배우와 실물 폭탄 움직임으로 읽는다. 광역 공연은 무대 스포트라이트를 띄우되 정확한 원형 피해 범위는 그리지 않는다.
- 박성원 1페이즈: 도착 칸의 색 타일과 돌진 직사각형 표시를 없애고 작은 그림자만 표시한다. 광역 눈금 폭발은 주사위 눈금의 반짝임으로 예고한다.
- 박성원 2/3페이즈: 손과 머리 움직임에 연결된 작은 낙하 그림자, 대형 카지노 기믹에는 금빛 주변 빛을 준다. 피해 영역의 반경·폭·시간은 기존 그대로다.
- 배서준: 빨간 원과 부채꼴의 정확한 면적 오버레이를 삭제한다. 주요 혈마법은 혈액이 공중에서 응집하는 모습을 보여주며 마법 객체와 실제 피해 데이터를 공유한다.

세부 구현: src/environmental-telegraphs.mjs, tests/environmental-telegraphs.test.mjs.
주의: 정확한 거리나 각도가 표시되지 않으므로 실제 회피 공정성은 브라우저 플레이 검증으로 추가 확인해야 한다.
