# 보스 피격 특성

실제 피해를 받은 경우에만 해당 보스의 특성을 적용한다. 회피·무적에 막힌 공격은 적용하지 않는다. 같은 특성을 다시 받으면 남은 시간을 갱신하며 강도는 중첩하지 않는다.

| 보스 | 효과 | 표시 |
| --- | --- | --- |
| 이권재 | 칼날·턱날에 베이면 2초 출혈. 초당 체력 2 감소, 기력 재생 20% 증가 | 붉은 핏방울, 초록 기력 고리, 물방울 아이콘 |
| 오슬우 | 피해를 받으면 0.7초 기절 | 머리 위 금색 별 입자·별 아이콘 |
| 박성원 | 피해를 받으면 1초 짓눌림. 이동·공격·회피·회복 불가 | 몸통 세로 크기 32%, 바닥 먼지·압착 아이콘 |
| 배서준 | 플레이어가 실제 잃은 체력의 25%를 회복, 최대 체력 상한 적용 | 플레이어에서 보스로 흐르는 붉은 입자·하트 화살표 아이콘 |

상태 이름·설명·남은 시간·알림 텍스트는 추가하지 않았다. 플레이어 위 고정 22px SVG 아이콘과 전투 공간의 이펙트만 사용한다. 배서준의 흡혈 표시는 0.75초간 유지한다. 상태 시간은 전투 시뮬레이션 시간을 사용하므로 일시정지 중 진행하지 않는다. 종료·재시작·화면 해제 시 표시와 짓눌린 몸통 크기를 복구한다. 복제된 보스 화면에 이전 아이콘이 남지 않도록 복사본도 제거한다.

박성원 1페이즈의 구르기·돌진·착지 몸체 압사는 즉사 대신 피해 44와 짓눌림을 준다. 체력이 남으면 생존한다. 몸체를 회피 무적으로 통과할 수 없는 기존 충돌 규칙은 유지하며, 동일 접촉의 반복 피해는 1.1초 제한한다. 체력 44 이하에서는 정상적으로 사망할 수 있다. 2페이즈의 기존 몸체 충돌 판정은 이번 변경 대상이 아니다.

## 검증

- 새 회귀 검사 13개: 실제 피격 경로, 재적용·정확한 종료 시간, 네 무기의 행동 제한과 복구, 무적·회피 제외, 출혈 사망, 실제 피해량 기반 흡혈과 상한, 1페이즈 압사 생존·반복 제한, 아이콘 무문자·몸통 복구·복제 화면 정리.
- 기존 압사 검사는 바뀐 1페이즈 생존 규칙으로 갱신했다. 배서준 전환 검사는 패턴 중 흡혈과 전환 자체의 체력 변경을 구분한다.
- 최신 변경 통합 후 전체 974개 중 966개 통과. 변경 전에도 있던 8개 실패는 도전 모드 제거, 혈왕 패턴 단계 순서, 광대 모델 크기·난도, 주사위 모델 세부 묘사, 공통 전환 체력 검사, 망치·활 스킬 기대값이다.
- 실제 브라우저의 네 보스 화면에서 실제 피격을 일으켜 출혈·기절·짓눌림·흡혈 아이콘과 이펙트를 확인했다. 아이콘의 텍스트 내용은 비어 있으며 런타임 오류가 없었다. 짓눌린 몸통 모습과 배서준 피해 38 → 회복 9.5도 확인했다.
- 실기기 모바일 조작·성능과 장시간 밸런스는 별도 검증 대상이다. `scripts/boss-traits-qa.html`은 실제 전투 화면과 피해 경로를 호출하는 재현 도구다.
