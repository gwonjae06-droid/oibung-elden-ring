# Main arena lifecycle integration

The foundation controller is now used by arena.mjs, which exports arenaRuntime. Import-time automatic startup is preserved. The frame function no longer schedules itself; the controller schedules it. All arena event listeners and three timer sites use owned registration. Pointer capture and both directly constructed audio backends use controller ownership. Lazy module installers and the boss skin callback cannot add resources after disposal. Detached shared projectile geometry/materials and generated face textures are explicitly registered.

stop() clears held input, releases captures, pauses an active fight and stops ambience. start() restarts rendering, resets the frame timestamp and adjusts an ending deadline; a paused fight still needs the normal resume action. stop() does not cancel timers or terminate already playing one-shot sound. dispose() is terminal, unregisters listeners, cancels timers, clears transient UI, disables main controls, closes owned contexts and disposes discoverable scene/renderer resources. It does not await context close completion. No same-document remount is implemented.

bootstrapGame exposes arena and a dispose() alias for disposeFeatures(). Both cleanup paths now include the main arena after feature/entry cleanup. Its capture-phase permanent pagehide cleanup precedes the arena controller's normal pagehide listener once bootstrap finishes. Persisted pagehide keeps the cached instance. Startup cancellation while optional modules are still loading is not solved here.

Validation: three isolated Node VM tests passed against the lifecycle binding block with mocks: input reset/idempotent stop/restart time adjustment; cleanup failure isolation; input suppression while stopped. This was not execution of the full arena module, full repository npm test, a Three.js integration test, real browser/audio test or GPU leak measurement.

Remaining: audit hidden resources and asynchronous work inside nested environment/effect/audio modules; dispose secondary battle sessions and unmanaged feature installers; explicit construction/remounting. This is a main arena shutdown handle, not verified complete game shutdown.
