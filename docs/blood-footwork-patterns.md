# 배서준의 발걸음과 패턴 선택

2026-11-05. 회복 중 매 순간 플레이어를 초당 최대 9만큼 따라가던 이동을 제거했다. 기존 외형에는 다리 관절도 없어서 발을 딛지 않은 채 긴 로브가 바닥을 미끄러졌다. 강하는 예고 시간에 목표로 순간 이동했고, 다른 공중 공격도 끝날 때 높이 8에서 0으로 내려왔다.

지금은 회복 초반에 고정한 방향으로 최대 두 걸음(총 1.7)만 접근한다. 걸음의 시작과 끝에 속도를 줄이고 마지막 **1.55초 이상은 정지**해서 반격을 받는다. 이미 거리 4 이내면 걸음을 시작하지 않는다. 발·무릎 관절과 부츠, 앞쪽을 조금 올린 옷자락을 추가했다. 지지하는 발은 바닥의 같은 위치를 유지하고 다른 발을 들어 옮긴다. 몸과 발이 같은 시뮬레이션의 걸음 계획을 읽으며 표현이 전투 상태를 변경하지 않는다. 지상 대기의 지속적인 상하 부유도 제거했다.

강하는 처음 고정한 목표까지 날아가 실제 충돌 시각에 착지한다. 추격은 경로의 양 끝에서 속도를 줄이고, 모든 공중 패턴은 끝나기 0.6초 전부터 내려온다. 실제 높이가 공중 피격 제한과 일치한다. 바닥을 지나는 플레이어 발사체와 공중 피해 차단, 착지 반격 배율 및 혈해 흡수 회복은 유지한다.

기존 18개 패턴은 전부 구현되어 있었지만 각 페이즈의 9개를 항상 같은 순서로 사용했다. 혈창·십자·혈검·세례는 뒤쪽에 있어 빠르게 페이즈가 바뀌거나 처치되면 만나기 어려웠다. 이제 시도마다 한 번 정한 시드로 순서를 섞고, 각 페이즈에서 9종을 한 번씩 사용한 뒤 다음 순환으로 간다. 두 순환 사이 같은 공격이 연속되지 않는다. 혈창·십자와 혈검·세례는 각 페이즈 첫 네 공격에 포함하고, 2페이즈 두 번째와 여섯 번째에는 지상 패턴을 섞는다. 순서는 바뀌지만 피해량·예고 시간·판정 범위·체력은 변경하지 않는다. 빠르게 끝난 페이즈에 모든 9종을 강제로 시전시키거나 처치를 지연시키지 않는다.

검증: 64개 시드와 반복 순환의 누락·중복, 실제 자동 전투에서 18종의 선택 및 모든 후속 판정 실행, 지지 발의 고정과 실제 관절 좌표, 도망가는 플레이어에 대한 정지 반격 시간, 강하 경로와 착지의 연속성을 검사한다. 기존 혈마법·모션·공중 피격·회복 검사와 함께 52개가 통과했다. `scripts/blood-footwork-smoke.mjs`는 18종을 실제 WebGL로 그리고 모바일 보스전 진입도 확인한다. 추가 관절·부츠는 생성 시에만 만들고 걸음마다 기하나 입자 방출기를 만들지 않는다.
