# 최규원 뮤지컬: 커튼, 7막 진행도, 3분 무대 개편 (2026-11-09)

대상: 원곡 8개 1배속 전곡 유지, 5~11수 및 마지막 800HP. 7,000HP와 연차별 곡 종료 700/1,000 피해 규칙은 이전 구현 유지.

## 자막 결함 원인과 수정
- PR107에서 44~70초 편집본의 자막을 원곡 타임으로 변환할 때, 기존 편집 구간 안에 온전히 포함된 짧은 문구만 남겨 원본 대부분(약 3분)이 무자막으로 표시되었다.
- 이번에는 보장 가능한 변환 가사를 우선 적용하고, 그 밖의 구간에 기존 영/한 극본을 **임시 시간 배치**하여 자막 줄 자체가 사라지지 않도록 했다.
- 기존 장르별 박스 없는 자막을 유지하고 줄바꿈, 모바일 크기를 조정했다.
- **미완:** 원곡 실제 보컬을 전곡 받아쓰기하여 박자/발음에 맞추는 작업. 현재 임시 자막은 원곡 내용이나 시각과 다를 수 있고 정확한 가사 싱크라고 볼 수 없다. 실제 가사 검수 후 대체해야 한다.

## 4수→5수 극장 오프닝
- 5수 처음 5.8초를 전주 개막으로 사용한다. 실제 THREE 메시 커튼/상인방/기둥은 무대 관객 쪽에 놓인다.
- 커튼이 2.15~5.7초 사이 양옆으로 열리고 Gyuwon이 무대 왼쪽에서 걸어나와 긴장된 인사를 한다.
- 해당 연출은 공격이 잠긴 무대 준비 구간에서만 시각적으로 적용한다. 스킵 버튼은 두지 않는다.
- 음악 시간 증가량을 기준으로 커튼 전환을 진행한다. CPU/GPU가 느려도 연출이 음원보다 뒤처지지 않도록 물리 시뮬레이션의 프레임 상한과 구분했다.

## 상단 진행도
- 5~11수 총 7막 진행 비율 = (완료한 막 수 + 현재 원곡 재생률) / 7.
- 현재 막 번호·장르, 원곡 실재 재생 시간 및 길이를 보인다. 종료 처리 중복과 실패 방지를 위해 미디어 시계를 기준으로 한다.
- 엔딩곡은 별도의 극이므로 이 7막 진행도에서는 제외한다.

## 개별 3분 미니게임 리듬
- 5수: 3개 무대 구간에 맞춘 적군 진영 교체(38%, 76%). 쓰러진 적이 같은 자리에서 3초 뒤 다시 생기지 않는다.
- 6수: 꽃밭/비/조용한 길/일출, 위험을 줄인 브리지 및 14초 주기 회복 젤리.
- 7수: 두 번째와 마지막 적 기지, 병사가 멈추는 조용한 구간, 자동 무한 기지 재생 제거.
- 8수: 중간 안무 쉬는 구간. 기존 3분 동작은 보존한다.
- 9수: 첫 대결/변주/마지막 대결을 음악 비율에 연결, 빨리 KO면 다음 절까지 승리 자세로 대기. 3분 동안 무한 KO 라운드 생성 금지.
- 10수: 지상→별하늘, 중간 휴식, 마지막 대형 적 1회 출현, 격파 시 점수 수집 비행.
- 11수: 3D 극장 유지, 이전 막의 기억 소품 변화, 기존 68초까지만 존재했던 입력표 뒤에 드문 연주 응답과 쉼을 확장.

## 기획서와 비교한 추가 과제
1. 원곡 전체 음원 가사/전주/후렴/브리지/후주·리듬 채보로 임시 비율과 자막 대체.
2. 5수 파티 캐릭터를 과거 4보스의 실제 3D 리그로 치환(현재는 기존 4무기 모티프 캐릭터의 복제품); 7수 실제 보스 2D 유닛 이미지 치환.
3. 11수의 이전 장르 공격을 실제 투사체·충돌과 연결하고, 800HP 엔딩의 전곡 시네마틱 구성 추가.
4. 3분 연속 실제 플레이와 모바일 자막/터치/오디오·FPS 검수, 전곡/연차 단위 체크포인트 및 복원.
5. 실제 음원이 아닌 추정 구간 변화와 잠정 비트·가사 시간은 확정하지 않는다. 테스트에서 원곡 종료 직전 seek은 3분 자연 완주 검사를 대체하지 않는다.
