# 오든링 — 플레이어 무기 효과음 배치 및 음량 정책

2026-11-04 기준 GitHub 저장소에 적용된 사양.

## 공통 규칙

- 모든 보스전(이권재·오슬우·박성원)에서 동일한 `src/player-weapon-sfx.mjs` 재생기를 사용한다.
- **일반 공격, 스킬, 활 적중**은 분리된 이벤트 및 파일을 사용한다.
- 플레이어의 무기 공격 계열 효과음은 **동시에 최대 1개**만 재생한다. 다음 공격이 시작되면 이전 공격음을 멈추고 새 음원을 재생한다.
- 일반/스킬 이벤트가 함께 발생하는 활·망치는 스킬 발동 후 이어지는 `swing`/`shot` 이벤트에 일반 공격음을 중복 재생하지 않는다.
- 플레이어의 공격음을 다른 합성 타격음과 동시에 내는 중복 경로를 정리했다.
- 기본 SFX 볼륨 범위는 **0.10~0.21**이며, 사용자 전체 음량·효과음 설정이 곱해진다. 이는 원본의 음압(LUFS)을 측정해 맞춘 수치가 아니라 보수적인 초기 설정이다.
- 재생 길이는 약 **0.35~1.06초**로 제한하며 종료 직전 페이드아웃한다. 반복 쿨다운은 0.08초 이상이다.
- 회복·사망 소리(`heal.mp3`, `dead.mp3`)와 보스 전용 17개 효과음, 기존 BGM 7곡은 유지한다.
- 일시정지·메뉴 복귀·재도전·전투 종료 시 플레이어 무기음을 정리한다.

**노랑 카드**는 실제로 다음 적중 시 기절을 부여하는 스킬이다. `healing-magic` 파일은 밝은 마법 음색을 빌려 사용하는 것으로, 게임 스킬의 실제 효과를 회복으로 변경하지 않는다.

망치 스킬에 지정된 `(1).mp3`는 기존 보스에 사용 중인 이름이 같은 원본 파일과 별개의 업로드 경로이다. 보스용 매핑은 바꾸지 않았다.

## 수정된 주요 코드

- `src/player-weapon-sfx.mjs`: 전용 샘플 매핑·단일 보이스 재생·볼륨·길이·페이드.
- `src/arena.mjs`, `src/clown-battle.mjs`, `src/dice-battle.mjs`: 공통 이벤트 연결, 중복 일반/스킬 음향 경로 억제, 일시정지·종료 정리.
- `src/feel.mjs`: 플레이어의 보스 적중 시 별도 합성 타격음 제거(혈흔·카메라 효과 보존).
- `tests/player-weapon-sfx.test.mjs`: 4무기 구분·16개 파일 존재·단일 재생·볼륨·페이드·중복 억제 테스트.

## 확인이 필요한 사항

자동화 테스트는 **파일 경로, 오디오 재생 로직, 제한값과 이벤트 연결**을 검증한다. 실제 휴대폰/헤드폰에서 원본 음원의 상대 음압, 음색, 시작점·끝점이 자연스럽게 들리는지는 추가 청취 확인이 필요하다. 공개 배포 전에 모든 음원의 원본 라이선스를 점검한다.
