# 최규원 — 페이즈별 시각 언어와 가독성

2026-11-08. `gyuwon-pattern-effect-styles.md`가 패턴마다 움직임을 달리했다면, 이번에는 페이즈마다 위험 이펙트의 몸(모양)과 색 규칙을 달리했다. 시각 전용이며 피해 판정, 타이밍, 히트박스, 드로콜 수, `stats()` 키는 바꾸지 않았다. `src/gyuwon-hazard-vfx.mjs`만 수정했다.

## 페이즈별 컨셉

| 페이즈 | 컨셉 | 위험 이펙트의 몸 | 색 |
|---|---|---|---|
| 1 · 끝없는 자습실 | 시험지 | 바닥에 세워진 종이 한 장(사각 면 2장, 위가 살짝 기울어짐) | 기존 회청색 계열(어두운 배경) |
| 2 · 백색과 암흑 | 증명과 반증 | 가늘고 높은 결정 칼날 2개를 십자로 엇갈림 | 백색: 흑연(연필선) / 암흑: 밝은 보라 먹물 |
| 3 · 황금 기억 | 기억의 불씨 | 삼면 첨탑(뾰족한 불씨 기둥) | 금빛으로 끌어당긴 색, 흰 배경에서는 깊게 |

- 같은 풋프린트(직선·원·링·부채꼴)에 몸만 바꿨다. 파편은 판정 영역 가장자리 위에서 솟는다.
- 링의 확장(`ring`)도 같은 몸으로 갱신되며 정점 수가 일정해야 하므로 몸 종류는 패턴 id로 고정된다.

## 가독성 수정

배경을 코드에서 확인해 보니 3페이즈 전체와 2페이즈의 백색 공간은 배경이 흰색이다(`gyuwon-view.mjs`의 `white` 계산). 기존 위험 이펙트 색은 대부분 옅은 톤이라 흰 배경에서 거의 보이지 않았을 가능성이 높다. 그래서:

- 밝은 배경(3페이즈, 2페이즈 백색)에서는 파편 색을 밝히지 않고 깊게 한다(0.6배). 3페이즈는 금색으로 끌어당긴다. 발광과 불투명도를 올리고, 타격 순간의 흰색 번쩍임은 끈다.
- 2페이즈 백색의 기록 연출은 옅은 분필색에서 흑연색으로 바꿨다. 흰 종이 위의 연필선이라는 컨셉에도 맞는다.
- 2페이즈 암흑의 먹물은 검은 배경에서 잘 보이도록 더 밝은 보라(`0x6a4fb0`, 발광 `0xb28cff`)로 올렸다.
- 해일 통로 단서는 청록을 깊게(`0x1f8f88`) 하고 불투명도를 올렸다.

## 하지 않은 것

- 요청에 "어렵고"가 있었으나 난이도는 건드리지 않았다. 난이도는 전투 로직(패턴 타이밍, 판정, 속도)의 문제이고 이번 작업은 시각 전용이다. 더 어렵게 하려면 어떤 패턴을 어떻게 바꿀지 정해야 한다.
- 별도 입자(떠오르는 불씨, 종이 날림)와 배경 조명 변화는 추가하지 않았다. 몸 모양과 색·밝기만 바꿨다.

## 한계와 확인할 것

- 자동 테스트와 브라우저 렌더링은 실행하지 못했다. 정점 수가 달라졌으므로(종이 6, 결정 6, 불씨 9 정점/조각) 정점 수나 `position` 배열 길이를 엄격히 검사하는 테스트가 있으면 실패할 수 있다.
- 색 수치(0.6배, 금색 혼합 0.55, 흑연색 등)는 감으로 정한 값이다. 실제 화면에서 가독성을 보고 조정해야 한다.
- 흰 배경에서 가독성이 정말 문제였는지는 코드로 추정한 것이며 화면으로 확인하지 못했다.
