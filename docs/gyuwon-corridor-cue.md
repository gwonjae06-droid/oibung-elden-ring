# 최규원 결합 공격 — 해일 통로 이동 방향 전조

2026-11-08. `gyuwon-combined-memory.md`의 한계 항목("통로가 움직이는 방향을 미리 알려 주는 별도 표시 없음")을 시각 전용으로 보강했다.

## 변경

파일: `src/gyuwon-hazard-vfx.mjs`. 해일 위험(`gapTarget`이 있는 `wave`)이 시전되는 순간부터, 이동이 끝난 뒤의 새 통로 양쪽 가장자리를 따라 청록색 균열 조각이 바닥에서 솟기 시작한다.

- 위치: 새 통로의 중심(`gapTarget`)에서 좌우 2.65(실제 안전 반폭 `opening-.55`)에 아레나 전체 길이(±30)로 뻗는다. 판정과 화면이 맞도록 실제 충돌 기준 폭을 썼다.
- 타이밍: 해일의 age 0에서 통로가 움직이기 시작하는 2.55초까지 점점 높고 밝아진다(전조는 이동이 시작되기 전에 이미 읽을 수 있다). 해일이 아레나를 지나간 뒤(age 약 5.9~6.5초)에는 서서히 사라진다.
- 재질: 기존 위험 파편과 같은 재질 계열(균열 파편 메시)이며 청록색이다. 설명 텍스트나 평면 도형은 쓰지 않았다. 이 청록색은 문서 `gyuwon-three-phases.md`에 적힌 "파도 통로까지의 진입 경로는 청록색으로 안내"와 같은 색 언어다.
- 시각 전용: 피해 판정, 타이밍, 통로 이동 로직은 바꾸지 않았다. 통로 단서는 위험당 메시 1개이며 `stats()`의 키와 값은 기존과 같다.

## 한계와 확인할 것

- 새 통로 위치를 미리 보여 주므로 난이도가 낮아진다. 결합 공격이 "읽고 따라가는" 압박이라면 이대로가 맞지만, 더 어렵게 하고 싶다면 단서의 시작 시점을 늦추면 된다(`lead` 계산의 분모 `shiftAt`).
- 카메라 구도와 해일 메시에 가려지는지, 모바일 화면에서 보이는지는 확인하지 못했다. 자동 테스트와 브라우저 렌더링도 실행하지 못했다.
- 기존 `gyuwon` 위험 시각 효과 테스트가 `drawCalls`나 파편 수를 엄격히 비교한다면 영향받을 수 있다. 통로 단서는 `states`에 포함하지 않고 별도 맵으로 관리한다.
