# 오든링: 표면 흐름 · 벽 충돌 · 혈액 덩어리 병합

## 이 릴리스의 유체 기능
1. **보스 신체 표면:** 배서준의 가슴/갑옷을 따라 아래로 흐르는 피줄기를 상체 뼈의 로컬 좌표에 고정했습니다. 보스가 숙이고 몸을 틀 때 따라갑니다. 보스 피격 시 추가로 생성되며 1~2초 안에 사라집니다.
2. **기둥·벽:** 성당 측면 벽(x≈±41.5), 성당 뒤쪽 석재 벽(z≈-47.15), 기둥(x≈±35.4, z=-35,-21,-7,7,21,35)에 닿은 **실제 시각용 피입자**를 경계 교차 분석으로 감지합니다. 벽과 기둥의 근사 충돌면에서 속도가 반사/감쇠하고, 표면에 묻은 핏방울이 아래로 흘러내립니다.
3. **피 덩어리:** 같은 분출에서 가까이 이동한 피입자를 일정 수량만 합칩니다. 덩어리 반지름은 부피(반지름 세제곱)와 운동량으로 결정되며, 합쳐진 직후에 조금 부풀었다가 원래 형태로 가라앉습니다.
4. **무대 효과:** 2페이즈의 큰 혈액 패턴일 때 성당 기둥 쪽으로 작은 부수 분출이 일어납니다. 해당 입자가 실제 기둥에 충돌해야 비로소 표면 핏자국이 만들어집니다.

## 성능 정책
- 기존 혈액 파티클/핏자국/물결 풀의 최대 수량 **유지**, 추가된 표면 흐름은 최대 보스 22/벽 18개의 인스턴스로 제한합니다. 저사양에서는 10/8개입니다.
- 기존 혈액 Geometry와 PBR 재질을 재사용합니다. 새로운 개별 Mesh나 물리 엔진/광원은 매 프레임 만들지 않습니다.
- 피입자 병합은 최대 7회/프레임(저사양 3회)이고, 각 파티클은 최대 3개의 이웃 입자와만 비교하여 비용을 제한합니다.
- 성당 충돌은 간단한 원/평면으로 근사하며 복잡한 고폴리곤 건축물 전체를 raycast하지 않습니다. 실제 장면의 모든 장식 표면을 정확하게 적시는 시뮬레이션은 아닙니다.
- 공격 데미지, 피격 판정, 투사체 높이 판정, 실제 스킬 발동, AI, 치유량에는 개입하지 않는 **시각 전용 시스템**입니다.

## 검증
- `tests/blood-wall-surface-merging.test.mjs`: 실제 벽/기둥 접촉, 반사, 피 덩어리 운동량, 몸체 리깅, 표면 피줄기, 재시작 시 정리
- `.github/workflows/blood-wet-surfaces.yml`: 기존 혈액·혈해·흡혈·비행 전투·렌더링 테스트를 함께 실행합니다.
