# 최규원 2페이즈 백색 공간 — 공격 흡수 피드백

2026-11-08. `gyuwon-concept-analysis.md` 5·6장의 "백색에서 공격이 흡수되어 글자로 분해되는 시각 피드백" 제안을 구현했다.

## 변경

- `src/gyuwon-combat.mjs`: 백색 공간에서 `damageGyuwon`이 피해를 0으로 막을 때, 지속 피해가 아닌 타격이면 `gyuwon.absorbAt`(게임 시간)과 `gyuwon.absorbCount`를 기록한다. 반환값(0), 체력, 판정, 타이밍은 바꾸지 않았다.
- `src/gyuwon-absorb-fx.mjs`(신규): 흡수 시점마다 보스 위치에서 분필색 기호(∑ ∫ ∀ ?)가 퍼지며 위로 올라가 약 1.3초 안에 사라진다. 기호 종류별 Points 4개만 쓰며, 흡수가 없을 때는 숨겨 두어 드로콜을 쓰지 않는다. 모션 감소 설정에서는 움직임을 40%로 줄인다.
- `src/gyuwon-view.mjs`: 위 이펙트를 생성·갱신·정리하도록 연결했다.

인게임 설명 텍스트는 쓰지 않는다. 기호는 칠판 수식과 같은 시각 요소이며 조작 설명이 아니다.

## 정정

`gyuwon-concept-analysis.md` 구현 상태 표에는 "백색 풀(negate·verdict·mirror·axiom) 미사용"을 문제로 적었다. `tests/gyuwon.test.mjs`의 "white rehearsals…" 검사를 보면 2페이즈 백색은 어두운 풀의 패턴(예: 반례의 그림자)을 미리 보여 주는 설계로 보인다. 즉 의도된 동작일 가능성이 높다. 문서의 "백색 = 선·부정·분신·표식" 설명과 코드 중 어느 쪽을 정본으로 할지는 결정이 필요하다.

## 검증 범위

자동 테스트, Edge/모바일 렌더링은 실행하지 못했다. 확인할 것: 백색에서 무기별(검·망치·활·카드) 타격 시 기호가 나타나는지, 연타 시 이펙트가 재시작되는지, 검은색 전환 시 사라지는지, 일시정지 중 멈추는지.
