# 오든링 개발 규칙 준수 점검 — 2026-11-07

최상위 개발 기준은 AGENTS.md이다. 정적 코드와 실제 플레이의 검증은 구분한다.

## 구현된 변경
- 1: 다섯 전투 HUD와 이권재 초기 HTML에서 패턴·회피·반격 설명 제거. 스토리 대사 및 필수 체력 HUD는 유지.
- 2: 배서준 거대 패턴 시네마틱의 스킵 버튼, C 단축키, skip 렌더 API 제거. 자원 정리용 내부 동작은 유지.
- 3~4: 최규원 2페이즈에서 누락됐던 다섯 공격 전용 모션 추가. 이권재 전환 보간 완화. 모든 보스 간 전환은 실전 영상 검증 필요.
- 5~6: 최규원·오슬우·박성원·이권재 모델 지오메트리, 의상·금속·피 표면 개선 및 모바일 폴리곤 LOD 설정. 모든 인물의 포토리얼리즘 완료는 아님.
- 7: 모든 다섯 보스에서 FPS 프레임 시간, 렌더 드로콜, 삼각형, 리소스 수를 샘플링해 느린 프레임 시 실측과 가설을 구분해 콘솔에 보고. CPU/GPU 원인 확정은 별도 프로파일링 필요.
- 8: 혈해 카메라는 자연 완료만 가능하며 타격 전 전장으로 복귀. 최규원 기억 해일의 표면 질감 개선. 피격 판정과 시각 효과의 완전 일치는 실기기 검증 필요.

## 기존의 구체적 성능 병목
- 최규원 최종 서커스 기억에서 독립적 360개 메시와 포인트 오버레이 360개를 생성하던 부분을 두 개 InstancedMesh로 통합해 반복 구조의 드로콜을 절감.
- 오슬우 모바일 렌더의 안티앨리어싱과 그림자 비용을 조건부 비활성화.
- 배서준 폭풍 광원 강도가 프레임마다 누적되던 밝기 버그를 기준값 재계산으로 수정.

## 검증 상태
새 GitHub Actions 생산 규칙 검사, 코드 검증용 테스트가 등록됨.
기존 전체 Node 회귀 테스트에서는 역사적 실패 다수가 존재해 완전 통과를 주장하지 않음.
PC/모바일 실기기의 모든 패턴 전환, 시각 가독성, 리깅 자연스러움, FPS와 GPU/CPU 병목은 아직 직접 측정·검수되지 않음.
