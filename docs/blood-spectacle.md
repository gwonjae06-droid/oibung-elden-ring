# 배서준: 대성당 규모의 혈마법

2026-11-05. 기존 흰 대성당, 인물·왕의 장식, 혈익, 사용자 제공 MP3와 피격 특성을 유지하면서 배서준의 공격과 연출을 확대했다. 체력·기본 피해량과 최근 공통 기력 소모 조정은 유지한다.

## 크기와 전투

기존 14종을 확대하고 4종을 추가해 **1페이즈 9종 + 2페이즈 9종, 총 18종**으로 구성한다. 전투장은 반경 28로 유지한다.

| 기존 공격 | 변경 |
|---|---|
| 피의 파도 | 피해 폭 5.2 → 12, 겹쳐 흐르는 높은 혈벽과 말리는 물결 |
| 피의 분수 | 3 → 5개 지점, 반경 2.7 → 4, 최대 높이 12 → 24 |
| 피폭발 | 반경 9 → 14, 예비동작 1.35 → 1.6초 |
| 피의 구체 | 3 → 5발, 반경 1.15 → 1.8 |
| 피의 소용돌이 | 반경 5 → 7.5 |
| 혈익 강하 | 착지 반경 5 → 7.5, 예고 1.6 → 1.8초 |
| 피의 일식 | 공중 핵 구체 3.6 → 8, 지상 코로나와 예비동작 2.8초 |
| 혈우 | 6 → 10개 낙하지점, 반경 2.8 → 3.7 |
| 붉은 날개 베기 | 사거리 12 → 19, 예비동작 1.1 → 1.4초 |
| 혈익 추격·종말의 혈조 | 더 넓고 긴 흐름, 각 파동의 후속 타격 간격 유지 |

## 새 공격

- **순교자의 혈창:** 다섯 낙하지점에 거대한 혈창이 순서대로 꽂힌다. 낙하 전 떠 있는 창과 피의 응집으로 위치를 전달한다.
- **성혈의 십자:** 전장 양 끝에서 두 쌍의 혈벽이 시간차로 교차한다. 직사각형 바닥 위험 표시는 추가하지 않는다.
- **천상의 혈검:** 공중의 거대한 검이 왼쪽·오른쪽·중앙을 연속으로 벤다. 실제 판정 시간에 맞춰 팔·날개·혈검이 함께 움직인다.
- **대성당의 붉은 세례:** 네 방향의 의식이 두 차례 교차하고 마지막 심장 파동이 퍼진다. 중앙 반경 5.5와 방향 사이 통로는 부채꼴 공격 동안 안전하며, 마지막 파동은 회피하거나 지나갈 수 있다. 다음 순서의 부채꼴을 미리 꽉 채우지 않아 현재 안전 통로를 읽을 수 있게 한다.

범위를 확장한 만큼 준비시간과 착지·복귀 시간을 함께 조정한다. 피의 사슬 뒤에는 1.7초 후속 예고를 두고 회피 속도는 유지한다. 공중 공격 뒤에는 다시 착지해 검과 망치의 반격 기회를 제공한다. 보스 외형은 1.25배이며 대형 패턴에서는 카메라가 부드럽게 뒤로 물러나 시야각을 62 → 70도로 넓힌다.

## 그래픽과 예산

혈마법의 기본 표면을 직접 작성한 `BufferGeometry`로 교체했다. 물방울의 불규칙한 윤곽, 굽은 주름과 말린 물결, 홈이 있는 혈창, 속이 빈 의식 부채꼴을 공유한다. 새로운 기본 도형 생성자를 추가하지 않았다. 새 액체 표면의 공유 기하 예산은 **고유 삼각형 9,000개 이하**이며, 효과는 기존 패턴별 풀과 입자 상한을 사용한다. 반복 시전 때 기하를 매 프레임 만들지 않는다.

기존 변신·대성당·장신구·음원은 교체하지 않는다. 기존 녹음된 피의 타격과 분출 소리를 새 공격의 실제 시전 타이밍에 연결한다. 독립적인 유체 물리나 추가 음원 다운로드가 필요한 효과는 아니다.

## 검증

- 혈마법 전투, 모든 18종의 5단계 모션, 네 무기의 착지 반격, 변신, 정리·풀 재사용, 성당·캐릭터 회귀 검사 49개 통과.
- 새 4종 각각에 대해 8방향에서 시작하는 연속 보행 경로를 0.05초 판정 간격으로 검사한다. 스크린샷만 보고 안전 구역을 추정하지 않는다.
- Edge WebGL에서 모든 18종을 실제 프레임으로 렌더링하고 일시정지·종료를 확인한다. `scripts/blood-spectacle-smoke.cjs`가 `artifacts/blood-spectacle`에 이미지를 저장한다.
- 소프트웨어 GPU에서 오류 없이 렌더링했으며, 실제 휴대폰 프레임과 모든 무기·진화 조합의 장기 자연 플레이를 검증했다는 뜻은 아니다.
