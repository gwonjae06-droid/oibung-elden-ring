# 오든링: 4보스 공격별 전신 모션과 동적 시네마틱 조명

2026-11-06 / 최규원 제외

## 변경 내용
- 이권재: 기존 스킬의 준비·활성·회복 시간을 그대로 참조해 허리 브레이싱, 가슴 반대 회전과 복부 충격 흡수를 추가. 기존 다리 IK와 목 리깅을 유지합니다.
- 오슬우: 현재 박수·착지·도약·회전 제스처에서 전신 압축, 몸통 기울기, 어깨 반대 회전을 유도합니다. 무대 위험 지역과 손장갑 판정은 그대로입니다.
- 박성원: 각 손 공격과 거인 머리 내려찍기의 실제 경고·충돌 시점을 사용해 상체 회전·전방 숙임·압축 반동을 부여합니다. 실제 손바닥의 위치와 머리 공격 판정은 바꾸지 않습니다.
- 배서준: 혈마법 사전 준비, 방출, 타격, 잔여 동작에서 체중 이동·코어 브레이싱·혈의 망토 후속 움직임을 더합니다. 혈마법 위험 영역과 유체 타격 판정은 유지합니다.
- PBR 조명: 각 페이즈와 실제 공격 상태에 따라 기존 그림자 없는 실루엣 광원의 강도와 색을 소폭 변화시킵니다. 추가 광원·그림자맵은 만들지 않으며 모바일의 해당 광원 강도는 계속 0입니다.

## 애니메이션 원칙
모든 신호는 전투 상태를 읽기만 하는 시각 계층입니다. 별도 공격 타이머·피해 이벤트·위험 예고 시간을 만들지 않습니다. 무작위 요소를 추가하지 않고 재도전/일시정지에 같은 상태를 재현합니다.

## 검증
`tests/boss-performance.test.mjs`는 물리적 모션 범위, 기존 스킬 프레임 연계, 공격 유닛 상태 불변, 모바일 렌더러의 추가 광원 없음 및 상태 복구를 검사합니다. 별도 CI 워크플로에서 기존 모션·그래픽 회귀 테스트도 함께 실행합니다.

## 한계와 후속
이는 절차적 리깅 및 PBR 조명 단계입니다. 새로운 고해상도 캐릭터 메시, 모션캡처, GPU 유체 시뮬레이션 또는 카지노 탁자의 실제 파괴 물리 시뮬레이션을 추가한 것이 아닙니다. 실제 PC 및 모바일 화면의 자연스러운 움직임과 FPS 측정은 별도 실기기 확인이 필요합니다.
