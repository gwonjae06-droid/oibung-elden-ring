# 오슬우 공포전용 SFX 업로드 안내

아래 MP3 파일들은 **아직 저장소에 없고**, 코드에 경로만 연결되어 있습니다. 추후 각 파일을 `assets/sfx/` 디렉터리에 올리면 전투 중 해당 이벤트에서 사용됩니다. 파일이 누락되어도 게임은 침묵하며, 8비트 전자음으로 대체하지 않습니다.

| 업로드할 이름 | 재생 대상 |
| --- | --- |
| `childfunny.mp3` | 텅 빈 객석과 가짜 광대의 기이한 아이 웃음 |
| `reversedclap.mp3` | 지연·역재생 박수 |
| `maskcrack.mp3` | 가면/도자기 얼굴 낙하 |
| `bodycreak.mp3` | 몸 접기 및 풍선 내부 괴물 움직임 |
| `clothbreath.mp3` | 숨 쉬는 천막·커튼과 그림자 |
| `audiencewhisper.mp3` | 비어 있는 관객석의 속삭임 |
| `voidsmile.mp3` | 거대한 입 벌림·이빨 시계 |
| `facesplit.mp3` | 떼어 던지는 가면·얼굴 |
| `circuswarp.mp3` | 현실 뒤집힘·무대 균열 |
| `nightmaretransition.mp3` | 보스 체력 25% 이하의 3막 전환 |

업로드 위치 예시: `assets/sfx/childfunny.mp3` (철자와 소문자 일치). 일반적으로 44.1 또는 48kHz MP3, 0.5~2초 길이가 알맞으며, 주변 소리와 섞이게 무리하게 큰 음량으로 제작하지 않는 것을 권장합니다.

현재 연결은 `src/clown-nightmare-sfx.mjs`에서 관리하며, 파일명을 바꾸고 싶다면 이 파일의 매핑만 고치면 됩니다. 기존 보스 SFX와 일반 전투 타격음은 그대로 유지됩니다.
