# 실사 신전 벽화 아트

기본 내장 image_gen 도구로 생성한 프로젝트용 아트입니다. CLI/API 방식은 사용하지 않았습니다. 전체 프롬프트는 [generation-prompts.json](generation-prompts.json)에 보관했습니다.

- temple-wall-v1.jpg: 마모된 석회암·현무암, 퇴색한 안료와 원형 의식 문양이 있는 정면 신전 벽화
- seal-spider-v1.jpg: 긴 턱과 여덟 다리를 새긴 거미 부조
- seal-clown-v1.jpg: 우스꽝스러운 아이콘 대신 비극적인 광대의 가면 부조
- seal-dice-v1.jpg: 상아색 돌의 주사위와 음각 눈금
- seal-blood-v1.jpg: 핏방울과 고대 장식의 부조
- seal-mirror-v1.jpg: 금속 틀·균열·손잡이가 있는 오래된 거울 부조

생성 원본은 별도로 보존하고, 웹에서는 동일한 그림을 JPEG 품질 88로 압축한 파일을 사용합니다. 이미지 6장 합계 약 2.8MB이며 외부 이미지 URL에 의존하지 않습니다.

## 홈 점등

별도의 작은 불꽃 아이콘을 제거했습니다. 그림의 실제 황금빛 상감 픽셀을 SVG 색상 행렬과 알파 필터로 추출해 발광층으로 사용합니다. 조각에 없는 기하학적 윤곽을 덧그리는 대신 실제 부조의 색과 홈에 발광이 붙습니다. 점등은 아래쪽에서 위쪽으로 차오르고, 토벌하지 않은 문양은 발광하지 않습니다. 모션 감소에서는 완성된 불빛을 즉시 표시합니다.

기존 defeated 기록의 kwon / clown / dice가 해당 부조에 연결됩니다. 혈마법과 거울 그림도 준비했지만 아직 구현하지 않은 보스의 토벌 기록을 새로 만들거나 해제하지 않습니다.

## 적용과 검증

src/journey-art.mjs에서 벽화와 다섯 그림을 합성하고 journey.css에서 점등·가독성·배치를 관리합니다. 중앙 메뉴와 기존 입력, 음악, 저장 규칙은 유지합니다. 캐시가 남은 구버전 아트를 피하도록 메인 부트스트랩과 아트 진입점 및 CSS에 stone-v1 버전을 붙였습니다. 링크는 spider-combat.html?art=stone-v1 입니다.

실제 브라우저에서 그림 로딩, 미토벌 문양, 이권재 토벌 기록으로 점등된 거미 문양과 콘솔 오류 없음을 확인했습니다. 자동 회귀 테스트도 실행합니다. 실제 모바일 기기에서의 GPU 필터 성능은 별도 검증 대상입니다.
