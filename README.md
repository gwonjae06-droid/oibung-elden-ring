# 오든링 — 두상의 서약

Three.js 기반 오리지널 브라우저 3D 소울라이크 보스 러시 프로토타입입니다. 정식 엘든 링과 무관한 창작 게임입니다. 저장소 이름이나 과거 기획 설명만으로 구현 범위를 판단하지 마세요.

## 현재 구현 범위

4번째 보스 **영원한 혈왕 배서준**을 추가했습니다. 성혈 대성당, 혈마법 14종, 혈익 변신과 비행·착지 반격을 포함합니다. 자세한 범위와 한계는 [배서준 구현 기록](docs/blood-boss.md), 기획서 대비 차이는 [구현 현황](docs/design-implementation-status.md)을 참고하세요.

## 메인과 여정

메인에서 무기를 선택해 네 보스를 순서대로 공략합니다. 토벌마다 정화의 불꽃 1개를 얻고, 대장간에서 무기별 두 경로를 각각 최대 2단계까지 영구 각인할 수 있습니다. 불꽃은 부활 대신 **불꽃 사용 → 시련 시작**으로 해금된 마지막 보스까지 건너뛰는 지름길에도 1개를 사용합니다. 미해금 보스는 이동할 수 없으며, 선택 취소·로딩 실패에는 차감하지 않습니다. 지름길 토벌 기록은 전체 연속 클리어 기록과 구분합니다. 메인은 다섯 문양의 고대 신전 벽화와 잔향이 있는 피아노 서곡을 사용하며, 토벌 스토리와 불꽃 확인 뒤 보상 화면을 사슬로 끌어내리고 다음 보스가 등장합니다. 진행 중 이어하기는 없습니다. 자세한 규칙과 검증 범위는 [여정 안내](docs/journey.md)를 참고하세요.

이권재 1장의 성소·서약 기억 확장과 검증 범위: [1장 구현 기록](docs/oath-chapter-one.md).

## 보스

- 긴턱의 이권재: 거대 거미 보스. 타이밍을 읽는 연속 베기와 돌진, 2페이즈에서 직립해 검을 잡습니다. 공격마다 몸 자세가 달라집니다.
- 광대 오슬우: 폭탄, 저글링, 스포트라이트 쇼, 불의 고리, 인간 대포(2페이즈) 등 19개 공연 패턴.
- 거대 주사위 박성원: 거대한 손님들이 내려다보는 룰렛 탁자 위의 주사위. 단단한 상아색·금색 외형을 사용합니다. BGM은 기존 업로드된 MP3를 유지합니다. 돌진, 점프, 연속 구르기, 윗면 숫자만큼 칸이 폭발하는 눈금 폭발, 2페이즈의 연쇄 돌진. 사슬·투사체 공격은 실제 전투에서 꺼져 있습니다(`dice.faceAttacks`).

네 보스 모두 첫 전투에서 건너뛸 수 있는 소개 컷씬이 나옵니다.

박성원전 변경과 근거리 공략: [카지노 룰렛 탁자](docs/park-casino-rework.md).

- 영원한 혈왕 배서준: 7종 혈마법을 사용하며, 절반 체력에서 붉은 구체와 혈익을 드러냅니다. 2페이즈 전용 공격 7종과 착지 반격 기회를 제공합니다.

## 화면 연출

- 보스 소개 컷씬(3.4초, 모션 감소 설정에서는 1.8초).
- 주사위 진입 연출: 주사위가 화면을 굴러 지나가며 기존 화면을 누릅니다.
- 체력 40% 미만이면 가장자리가 심장 박동처럼 붉게 맥동하고, 한 번에 15 이상 회복하면 초록빛이 번집니다.
- 사운드: 리버브, 타격·피격·페이즈 레이어, 바람과 저음 환경음(브라우저가 지원할 때).

## 실행

저장소 루트에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. Three.js와 웹 폰트를 외부 CDN에서 가져오므로 네트워크 연결이 필요합니다. HTML 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

## 조작

- WASD 또는 방향키: 이동
- J / 마우스 좌클릭: 기본 공격
- L / 마우스 우클릭: 무기 스킬
- Space: 회피
- E: 회복약
- Q: 록온 전환
- Esc: 일시정지
- 마우스 휠 클릭 드래그: 시점 조작
- 터치 기기: 화면 조이스틱과 행동 버튼

검·망치·활·카드를 선택할 수 있습니다. 회피 무적은 동작 전체가 아닌 중간 구간에 적용되고, 기본 전투에서 공격·회복 도중에는 행동을 취소할 수 없습니다.

## 코드 지도

- `src/combat.mjs`: 기본 전투, 이권재 패턴과 연속기, 기존 플레이어 API의 호환 진입점
- `src/weapon-data.mjs`: 네 무기의 피해량, 기력 소모와 공격 시간 및 사거리 정의
- `src/player-combat.mjs`, `src/player-tick.mjs`: 네 보스가 공유하는 플레이어 초기 상태, 공격 타이밍, 투사체와 스킬 보상, 자원 회복
- `src/boss-motion-data.mjs`, `src/boss-stance.mjs`: 이권재 공격별 몸 자세
- `src/arena.mjs`: 첫 전투의 입력, 렌더링, 카메라, HUD
- `src/runtime/battle-loop.mjs`: 네 전투의 프레임 예약, 시간 계산, 중복 실행 및 종료 후 콜백 차단
- `src/battle-pause.mjs`: 공통 일시정지·재개 명령과 이동 입력 초기화
- `src/runtime/event-scope.mjs`: 보조 전투의 입력 리스너, DOM 콜백, 타이머 소유권 및 종료 후 실행 차단
- `src/battle-hud.mjs`, `src/runtime/battle-styles.mjs`: 공통 HUD 게이지와 취소 가능한 스타일 준비 처리
- `src/runtime/battle-startup.mjs`: 보조 전투 초기화 실패 시 생성한 자원의 역순 정리와 성공 시 소유권 이전
- `src/clown-combat.mjs`, `src/clown-cartoon.mjs`: 광대 패턴과 몸짓
- `src/clown-battle.mjs`: 광대전 화면과 수명주기
- `src/dice-combat.mjs`, `src/dice-motion-data.mjs`: 주사위 패턴과 모션
- `src/dice-actor.mjs`, `src/casino-data.mjs`: 주사위 모델과 카지노 바닥
- `src/dice-battle.mjs`: 주사위전 화면, 진입 연출
- `src/boss-intro.mjs`, `src/boss-intro-data.mjs`: 보스 소개 컷씬
- `src/screen-fx.mjs`, `src/screen-fx-data.mjs`: 저체력·회복 화면 연출
- `src/game-ui.mjs`: 보스 선택, 공통 UI, 컷씬 연결
- `src/audio.mjs`, `src/skill-fx.mjs`, `src/atmosphere-data.mjs`: 사운드와 입자 효과
- `src/coop-menu.mjs`, `server/`: 협동 관련. 정적 서버만으로 협동 서버가 시작되지는 않습니다.
- `tests/`: Node 기반 로직 및 연결 검사

## 자동 테스트

Node.js 20 이상에서 실행합니다.

```sh
npm test
```

GitHub Actions의 `Node regression tests` 워크플로도 같은 명령을 실행합니다. Node 테스트는 순수 로직과 DOM 대역을 검사하며 WebGL 렌더링, 브라우저 오디오, 모바일 성능, 협동 서버 통신의 성공을 보장하지 않습니다. 결과는 Actions에서 확인하세요.

## 수동 확인 목록

- 네 무기 각각으로 시작, 패배, 재도전, 무기 변경
- 네 보스의 소개 컷씬에 건너뛰기 버튼이 없고, 끝까지 재생한 뒤 전투가 시작되는지
- 광대 승리 후 주사위가 화면을 깔아뭉개며 지나가는 연출이 나오는지
- 주사위전의 눈금 폭발 표시가 초록 펠트 위에서 잘 보이는지, 칸 안내와 실제 피해 범위가 일치하는지
- 카지노 네온 밝기, 모바일 프레임
- 이권재가 자세를 바꿀 때 다리 위치가 어그러지는지
- 저체력·회복 화면 연출이 과하지 않은지
- 일시정지, 탭 전환, 터치 입력 해제
- 중첩된 보스 화면에서 협동 방 참가 시 현재 무기가 전달되는지

자세한 구조와 검증 범위는 [구조 개선 작업 현황](docs/maintenance-roadmap.md)을 참고하세요.

## 알려진 한계

- 이번 변경의 검증과 알려진 기존 실패는 [구현 현황](docs/design-implementation-status.md)과 PR 검증 기록을 참고하세요.
- 협동 서버가 주사위 전투를 따로 쓰는 경우 새 패턴과 연출이 적용되지 않을 수 있습니다.
- 사슬·투사체 코드 파일은 남겨 두었습니다. 완전 삭제는 후속 작업입니다.
- 보스별 처치 연출의 완성도는 다릅니다. 배서준 전용 녹음 BGM·환경음은 아직 없습니다.
- 최규원과 학원·도서관 및 두 엔딩은 아직 구현되지 않았습니다. 배서준은 메시 기반 프로토타입이며 고급 유체·파편 연출과 전용 녹음 음원, 실기기 밸런스 검증이 남아 있습니다.


배서준의 유체 효과·입체 혈익·변신 카메라·실제 MP3 동기화 및 검증 결과: [혈익 시네마틱 고도화](docs/blood-cinematic-quality.md).

보스별 피격 특성과 아이콘 표시·검증 범위: [보스 피격 특성](docs/boss-hit-traits.md).
