# 오든링 — 두상의 서약

Three.js 기반 오리지널 브라우저 3D 소울라이크 보스 러시 프로토타입입니다. 정식 엘든 링과 무관한 창작 게임입니다. 저장소 이름이나 과거 기획 설명만으로 구현 범위를 판단하지 마세요.

## 현재 구현 범위

현재 일반 여정은 이권재 → 오슬우 → 박성원 → 배서준 → 최규원의 다섯 보스로 구성됩니다. `src/boss-registry.mjs`의 다섯 항목은 모두 `implemented: true`이며, 최규원 전투도 여정에 연결되어 있습니다. 과거 문서의 네 보스 구성이나 최규원 미구현 설명은 현재 구현 범위를 나타내지 않습니다.

기획 문서와 과거 구현 기록은 작성 당시의 범위를 설명할 수 있습니다. 실제 진입 가능 여부는 보스 등록부와 여정 연결 코드를 확인하세요. 최규원 전투 구현이 과거 기획의 모든 공간·엔딩·연출 완성을 의미하지는 않습니다.

## 일반 여정 보스 HP

일반 여정 및 해금된 보스를 선택해 시작하는 일반 여정은 아래 고정값을 사용합니다.

| 보스 | ID | HP |
| --- | --- | ---: |
| 긴턱의 이권재 | kwon | 4,822 |
| 광대 오슬우 | clown | 5,076 |
| 거대 주사위 박성원 | dice | 5,711 |
| 영원한 혈왕 배서준 | blood | 6,345 |
| 무두의 사유 최규원 | gyuwon | 7,000 |

정의 위치는 `src/journey-balance.mjs`의 `JOURNEY_BOSS_HP`입니다. `src/journey-state.mjs`의 `configureJourney()`가 전투 시작 시 `boss.hp`와 `boss.maxHp`에 적용합니다. 이 표에 추가로 1.35배를 곱하지 않습니다. 숨겨진 경로와 독립 전투의 HP는 이 변경 범위에 포함하지 않으며, 전투 생성 함수의 초기 HP나 등록부의 기본 HP를 일반 여정의 최종 HP로 해석하지 마세요.

## 메인과 여정

메인에서 시련 시작 · 보스 선택을 눌러 무기와 보스를 선택합니다. 첫 보스는 항상 선택 가능하며, 앞 보스를 순서대로 토벌하면 다음 보스가 해금됩니다. 해금한 보스는 정화의 불꽃 소모 없이 다시 선택할 수 있습니다. 선택한 보스부터 이후 보스까지 순서대로 도전하며, 전체 여정 기록과 중간 보스부터 시작한 기록은 구분됩니다.

보스를 토벌하면 정화의 불꽃 1개를 얻습니다. 불꽃은 대장간에서 영구 무기 각인에 사용합니다. 보스 해금·무기 각인·기록은 저장되지만, 진행 중 여정이나 전투를 새로고침 후 이어하는 기능은 없습니다. 무기 선택과 대장간에는 실제 기본 전투 수치에 연동된 능력치 그래프를 표시합니다. 불꽃 반환은 확인 후 실행됩니다.

## 보스와 주요 규칙

- 긴턱의 이권재: 거미 형태에서 시작해 검을 사용하는 전투와 3페이즈 패턴으로 확장됩니다. 거리 대응·연속기·회복 견제가 있으며, 검격 피격에는 출혈이 붙을 수 있습니다.
- 광대 오슬우: 폭탄·저글링·스포트라이트·불의 고리·돌진과 확장 공연 패턴을 사용합니다. 피격에는 기절이 붙습니다. 과거의 19개 패턴 설명을 현재 전체 패턴 수로 사용하지 마세요.
- 거대 주사위 박성원: 룰렛 탁자에서 구르기·돌진·점프·눈금 폭발 등을 사용합니다. 구르는 본체의 압사는 1페이즈에는 피해를 주고 2페이즈에는 즉사 처리됩니다. 일반 피해의 회피 무적과 압사 처리는 별개입니다.
- 영원한 혈왕 배서준: 성혈 대성당의 혈마법 보스입니다. 절반 체력에서 2페이즈로 전환하며, 비행 중에는 근접·원거리 모두 피해를 줄 수 없습니다. 착지 후 회복 구간이 반격 기회입니다. 피격 시 보스의 흡혈 회복이 발생합니다. 과거의 14종 설명을 현재 전체 패턴 수로 사용하지 마세요.
- 무두의 사유 최규원: 시험 테마의 1페이즈, 백색·암흑 공간의 2페이즈, 앞선 보스들의 기억을 재현하는 3페이즈로 구성됩니다. 백색 공간에서는 보스가 피해를 흡수하며, 예고된 공격은 이후 암흑 공간에서 재현됩니다.

## 조작과 공통 전투

- WASD 또는 방향키: 이동
- J / 마우스 좌클릭: 기본 공격
- L / 마우스 우클릭: 각인 경로에 따른 무기 스킬
- Space: 회피
- E: 회복약
- Q: 록온 전환
- Esc: 일시정지
- 마우스 휠 클릭 드래그: 시점 조작
- 터치 기기: 화면 조이스틱과 행동 버튼

검·망치·활·카드를 선택할 수 있습니다. 회피 무적은 동작 전체가 아닌 중간 구간에 적용됩니다. 현재 공통 전투 코드는 기본 공격을 회피로 취소할 수 있도록 허용합니다. 회복 및 다른 행동은 같은 평타 취소 예외를 사용하지 않습니다. 취소 전에 이미 소모한 기력은 되돌려주지 않습니다.

활은 8회 발사 후 1.4초, 카드는 3장씩 4회 발사 후 1.2초의 장전 시간이 있습니다. 장전은 마지막 공격 동작이 끝난 뒤 시작하며, 회피 등 행동 중에는 진행되지 않습니다. 회복약은 기본 3개이고, 개당 HP 65를 회복합니다.

## 실행

저장소 루트에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. Three.js와 웹 폰트를 외부 CDN에서 가져오므로 네트워크 연결이 필요합니다. HTML 파일을 직접 여는 대신 HTTP 서버를 사용하세요. 정적 서버만으로 협동 서버가 시작되지는 않습니다.

## 그래픽과 화면 연출

기존 메시·재질·조명 위에 코드로 생성하는 PBR 표면·노멀·거칠기 텍스처, 환경반사와 타격 파편을 적용하는 방식입니다. 완전한 포토리얼리즘이나 고해상도 인체·건축 모델 제작을 의미하지 않습니다.

보스 소개·페이즈 전환·주사위 진입, 저체력·회복 화면 효과와 사운드 레이어가 있습니다. 소개 및 전환의 재생·건너뛰기 정책은 해당 컨트롤러 구현을 기준으로 확인하세요.

- [보스별 실사풍 그래픽 표준](docs/cinematic-boss-graphics-standard.md)
- [혈익 시네마틱 고도화](docs/blood-cinematic-quality.md)

## 코드 지도

- `src/boss-registry.mjs`: 다섯 보스의 순서·등록·진입점

- `src/journey-balance.mjs`: 일반 여정의 고정 HP와 약점 배율
- `src/balance.mjs`: 공통 피해·기력 및 등록부 기본 HP 규칙
- `src/weapon-data.mjs`, `src/weapon-stats.mjs`: 무기 공격 수치와 생존·이동 특성
- `src/player-combat.mjs`, `src/player-tick.mjs`: 공통 플레이어 행동·공격·자원 회복
- `src/ranged-reload.mjs`: 활·카드 탄창과 장전
- `src/weapon-abilities.mjs`: 각인별 공격·방어·화상·문양 효과
- `src/combat.mjs`, `src/arena.mjs`: 이권재 전투 로직과 화면
- `src/clown-combat.mjs`, `src/clown-battle.mjs`: 오슬우 전투
- `src/dice-combat.mjs`, `src/dice-battle.mjs`: 박성원 전투
- `src/blood-combat.mjs`, `src/blood-battle.mjs`: 배서준 전투
- `src/gyuwon-combat.mjs`, `src/gyuwon-battle.mjs`: 최규원 전투
- `src/runtime/`, `src/battle-pause.mjs`, `src/battle-session.mjs`: 전투 루프·수명주기·일시정지
- `src/battle-hud.mjs`, `src/game-ui.mjs`: HUD와 공통 UI
- `src/cinematic-graphics.mjs`, `src/cinematic-impact-fx.mjs`: 공통 그래픽·타격 효과
- `src/coop-menu.mjs`, `server/`: 협동 관련 코드
- `tests/`: Node 기반 로직 및 연결 검사

## 검증

Node.js 20 이상에서 실행합니다.

```sh
npm test
```

GitHub Actions의 Node regression tests 워크플로도 같은 명령을 실행합니다. Node 테스트는 WebGL 렌더링·브라우저 오디오·모바일 성능·협동 서버 통신의 성공을 보장하지 않습니다. 이 문서 수정 자체는 테스트 통과나 실기기 검증 완료를 의미하지 않습니다.

수동 확인 항목:

- 일반 여정의 다섯 보스가 표의 HP로 시작하는지
- 해금 보스 선택·패배 후 재도전에서도 같은 일반 여정 HP인지
- 네 무기 각각의 시작·패배·재도전·무기 변경
- 기본 공격 중 회피 취소와 회복 행동 잠금
- 활·카드 장전 및 회피 중 장전 정지
- 박성원 압사 경고와 실제 판정
- 배서준 비행 무적 및 착지 반격
- 최규원 백색 공간 무적과 암흑 공간 재현
- 보스 소개·전환·처치 연출, 장판 표시와 실제 피해 범위
- 일시정지·탭 전환·터치 입력 해제·모바일 프레임
- 협동 방 참가와 무기 전달, 협동 전투의 패턴·HP 차이

## 알려진 한계와 기록

보스별 연출 완성도는 다르며, 실기기 성능·가독성·밸런스 검증이 필요합니다. 협동 서버가 별도 전투 로직을 쓰는 경우 일반 여정의 변경이 자동으로 적용된다고 보장할 수 없습니다. 과거 기획서나 구현 기록은 현재 코드와 차이가 있을 수 있습니다.

- [구조 개선 작업 현황](docs/maintenance-roadmap.md)
