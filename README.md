# 오이붕 — 오슬우의 시련

Three.js 기반 오리지널 브라우저 3D 소울라이크 전투 프로토타입입니다. 정식 엘든 링과 무관한 창작 게임입니다. 저장소 이름이나 과거 기획 설명만으로 구현된 보스 수와 전체 완주 가능 여부를 판단하지 마세요.

## 실행

저장소 루트에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. `index.html`이 `spider-combat.html`로 이동합니다. Three.js와 웹 폰트를 외부 CDN에서 가져오므로 네트워크 연결이 필요합니다. HTML 파일을 직접 여는 대신 HTTP 서버를 사용하세요.

## 조작

- WASD 또는 방향키: 이동
- J / 마우스 좌클릭: 기본 공격
- L / 마우스 우클릭: 무기 스킬
- Space: 회피
- E: 회복약
- Q: 록온 전환
- Esc: 일시정지
- 마우스 휠 클릭 드래그: 시점 조작
- 터치 기기: 화면 조이스틱과 행동 버튼

검·망치·활·카드를 선택할 수 있습니다. 회피 무적은 동작 전체가 아닌 중간 구간에 적용되고, 기본 전투에서 공격·회복 도중에는 행동을 취소할 수 없습니다.

## 코드 지도

- `src/combat.mjs`: 기본 전투 상태, 무기, 첫 보스 패턴 및 판정
- `src/arena.mjs`: 첫 전투의 입력, 렌더링, 카메라, HUD
- `src/boss-transition.mjs`: 첫 보스 처치 후 전환 연출
- `src/transition-data.mjs`: 전환 데이터 및 브라우저 확장 초기화
- `src/clown-battle.mjs`: 광대전 화면과 수명주기
- `src/dice-battle.mjs`: 주사위전 화면과 수명주기
- `src/game-ui.mjs`: 보스 선택 및 공통 UI 확장
- `src/coop-menu.mjs`: 협동 메뉴와 현재 무기 선택 연결
- `server/`: 협동 관련 서버 코드. 정적 서버 실행만으로 협동 서버가 시작되지는 않습니다.
- `tests/`: Node 기반 로직 및 연결 검사

## 자동 테스트

Node.js 20 이상에서 실행합니다.

```sh
npm test
```

GitHub Actions의 `Node regression tests` 워크플로도 같은 명령을 실행합니다. Node 테스트 성공은 WebGL 렌더링, 브라우저 오디오, 모바일 성능, 협동 서버 통신 또는 전체 보스 진행의 성공을 보장하지 않습니다. CI 결과는 Actions에서 별도로 확인하세요.

## 수동 회귀 검증

- 네 무기 각각으로 시작, 패배, 재도전, 무기 변경
- 첫 보스 2페이즈 진입과 승리 후 광대전 무기 확정
- 광대전에서 주사위전으로 진행, 종료 및 재진입
- 보스 선택으로 직접 진입한 뒤 이전 전투 입력·음향이 남지 않는지 확인
- 일시정지, 탭 전환, 창 포커스 복귀, 터치 입력 해제
- 주사위전 중 첫 보스 전용 음향 변형이 적용되지 않는지 확인
- 중첩된 보스 화면에서 협동 방 참가 시 현재 무기가 전달되는지 확인
- 협동 서버 연결 실패와 재접속 처리

## 알려진 검증 과제

보스 전환에는 DOM 관찰 및 사용자 정의 이벤트가 함께 사용됩니다. 게임 상태 중심의 진행 관리자로 통합하는 작업은 후속 과제입니다. 무기 밸런스와 시각적 타격 판정은 실제 플레이 기록을 바탕으로 검증해야 하며, 이 문서는 전체 보스 클리어 또는 모바일 성능 검증 완료를 의미하지 않습니다.
